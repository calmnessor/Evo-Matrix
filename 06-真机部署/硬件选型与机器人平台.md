## 1. 机械臂选型

### 主流机械臂对比

| 机械臂 | 自由度 | 负载 | 力控 | 价格 | 适合场景 | VLA 常用度 |
|--------|--------|------|------|------|---------|-----------|
| **Franka Emika Panda** | 7 | 3kg | ✅ 关节力矩 | ~$25K | 研究首选 | ⭐⭐⭐ |
| **UR5e** | 6 | 5kg | ❌ (需外接) | ~$35K | 工业+研究 | ⭐⭐ |
| **Kinova Gen3** | 7 | 4kg | ✅ 关节力矩 | ~$30K | 移动操作 | ⭐⭐ |
| **xArm 7** | 7 | 3.5kg | ❌ | ~$8K | 性价比之选 | ⭐⭐ |
| **WidowX 250** | 6 | 0.25kg | ❌ | ~$2K | Bridge v2 数据 | ⭐⭐⭐ |
| **越疆 CR5** | 6 | 5kg | ❌ | ~¥30K | 国产入门 | ⭐ |
| **节卡 Zu 7** | 6 | 7kg | ✅ | ~¥80K | 国产力控 | ⭐⭐ |

### 选型核心考量

```
买什么机械臂，取决于你的研究方向:

做 VLA 灵巧操作 (桌面):
  → Franka / Kinova (力控好, 安全性高)
  → 7 DoF 冗余度对复杂姿态有用

做 VLA 移动操作:
  → Kinova (轻, 低功耗, 可装电池)
  → UR5e (重但稳定, ROS 支持好)

做廉价数据收集:
  → WidowX / xArm (低成本, 可多台部署)
  → ALOHA 式的双臂便宜方案

做工业级验证:
  → UR5e / KUKA iiwa (稳定, 精确, 贵)
```

### Franka Panda 快速上手

Franka 是 VLA 研究最常用的机械臂，因为它的力控和 ROS 支持最好。

```python
# Franka 的 Python 控制 (libfranka + frankx)
import frankx

robot = frankx.Robot("172.16.0.2")  # FCI IP 地址

# 关节位置控制
robot.move(joint_motion=frankx.JointMotion([
    0, -0.78, 0, -2.35, 0, 1.57, 0.78
]))

# 末端阻抗控制 (柔顺!)
robot.move(impedance_motion=frankx.ImpedanceMotion(
    target=frankx.Affine(0.5, 0.0, 0.3),  # 目标位姿
    stiffness=[600, 600, 600, 60, 60, 60],  # 刚度
))

# 夹爪控制
gripper = frankx.Gripper("172.16.0.2")
gripper.move(0.02)  # 抓取宽度 (m)
```

### 机器人通信协议

| 协议 | 延迟 | 适用 |
|------|------|------|
| **FCI (Franka)** | <1ms | Franka 专用, 1kHz 控制 |
| **RTDE (UR)** | ~2ms | UR 实时数据交换 |
| **EtherCAT** | <1ms | 工业标准, 多轴同步 |
| **ROS 2 Control** | ~5ms | 通用, 但延迟较高 |

### 吸盘（物流/仓储场景）

- 优点：对扁平物体（盒子、包裹）极好，平面不需要精确位姿
- 缺点：无法抓不规则物体，真空泵有噪音和维护成本
- 代表：Piab 系列、定制吸盘阵列

## 3. 深度相机选型

### 主流 RGB-D 相机

| 相机 | 技术 | 深度范围 | 精度@1m | 帧率 | 适合 |
|------|------|---------|---------|------|------|
| **RealSense D435i** | 主动立体+IMU | 0.3-3m | ±2mm | 90fps | 桌面操作 ⭐⭐⭐ |
| **RealSense D455** | 主动立体 | 0.6-6m | ±2mm | 90fps | 更大范围 |
| **Zed 2i** | 被动立体 | 0.5-20m | ±1% | 100fps | 移动操作 |
| **Kinect Azure** | ToF | 0.5-5m | ±5mm | 30fps | 全身追踪 |
| **Orbbec Femto** | ToF | 0.2-5m | ±5mm | 30fps | 廉价替代 |
| **Luxonis OAK-D** | 主动立体 | 0.3-4m | ±3mm | 60fps | 边缘 AI |

### 选型指南

```
桌面操作 (VLA 主流):
  → RealSense D435i (精度最好, ROS 支持最好)
  → 可配手腕相机 (eye-in-hand) + 第三人称相机 (eye-to-hand)

移动操作:
  → Zed 2i (远距离好, 自带 IMU 和 SLAM)
  → 或 D455 (折中方案)

低成本:
  → OAK-D (带板载 AI 推理) 或二手 Kinect

VLA 多视角:
  → 2-3 台 D435i: 手腕 + 正面 + 顶部
```

### 快速测试相机

```python
import pyrealsense2 as rs
import numpy as np
import cv2

# RealSense 快速采集
pipeline = rs.pipeline()
config = rs.config()
config.enable_stream(rs.stream.color, 640, 480, rs.format.bgr8, 30)
config.enable_stream(rs.stream.depth, 640, 480, rs.format.z16, 30)

pipeline.start(config)

for _ in range(100):
    frames = pipeline.wait_for_frames()
    color = np.asanyarray(frames.get_color_frame().get_data())
    depth = np.asanyarray(frames.get_depth_frame().get_data())

    # 对齐深度到彩色
    cv2.imshow("RGB", color)
    cv2.imshow("Depth", depth / 4000.0)  # 归一化到 0-1
    if cv2.waitKey(1) & 0xFF == ord('q'):
        break

pipeline.stop()
```

| 平台 | GPU | 功耗 | 价格 | 适用 |

### VLA 推理的推荐配置

```
场景 A: 实验室固定工位
  工控机 + RTX 4090
  → 7B VLA 模型 ~100ms 推理
  → ROS 2 通信回机器人

场景 B: 移动操作
  Jetson Orin AGX (机载)
  → 小模型 (1-3B) 或量化模型
  → 或 WiFi → 远程服务器推理

场景 C: 云端推理
  远程 A100 服务器
  → 大模型 (>10B)
  → 延迟敏感任务需要异步推理 (RTC)
```

### 课题组硬件上手 checklist

```
□ 机械臂:
  □ 知道型号、IP 地址、控制器位置
  □ 会用示教器或 Python API 控制关节运动
  □ 知道急停按钮位置和操作方法
  □ 跑通过 python -c "import frankx; ..." → 机器人动了

□ 相机:
  □ 知道型号和分辨率
  □ 能跑通 pyrealsense2 采集 RGB-D
  □ 知道相机安装位置（手腕/头顶/前方）

□ 计算平台:
  □ 知道 IP 地址和 SSH 登录方式
  □ 确认 GPU 型号和 CUDA 版本
  □ 确认已安装必要的 Python 包

□ 网络:
  □ 机器人控制网络 (FCI/RTDE) IP 段
  □ 相机数据网络 IP 段
  □ VLA 推理服务器 IP
```
