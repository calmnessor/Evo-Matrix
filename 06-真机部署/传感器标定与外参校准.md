# 传感器标定与外参校准

> "相机看到的位置"和"机器人坐标系里的位置"怎么对齐——真机部署最容易出问题的环节，也是最需要耐心的一步。

## 为什么标定这么重要？

```
没有标定: 相机说杯子在 (0.5, 0.2, 0.1)
          机器人移动到 (0.5, 0.2, 0.1) → 抓空了
          ← 因为相机坐标系和机器人坐标系没对齐

有标定:   相机说杯子在相机坐标系的 (0.5, 0.2, 0.1)
          经过 T_base←camera 变换 → 在机器人坐标系是 (0.48, 0.23, 0.12)
          机器人移动到 (0.48, 0.23, 0.12) → 抓住了!
```

**标定误差是 VLA 真机部署的头号杀手**——策略在仿真里学了 100% 正确，上真机标定偏了 2cm = 全部归零。

## 标定全景

```
你需要知道的三种标定:

1. 相机内参 (Intrinsic)
   作用: 把像素坐标 (u, v) → 相机坐标系下的 3D 射线
   精度要求: 高 (影响 3D 重建质量)
   频率: 一次安装后很少变 (除非换相机)

2. 手眼标定 (Hand-Eye)
   作用: 把相机坐标系 → 机器人基座坐标系
   精度要求: 极高 (直接决定抓取成功率)
   频率: 相机安装位置变了就需要重新标定

3. 机器人运动学参数
   作用: 关节角 → 末端位姿 是否准确
   精度要求: 中等 (大部分误差在标定中修正)
   频率: 出厂已标定，碰撞后可能需要
```

## 1. 相机内参标定

### 原理（30 秒理解）

相机内参 K 是一个 3×3 矩阵：

```
K = [fx,  0, cx]
    [ 0, fy, cy]
    [ 0,  0,  1]

fx, fy: 焦距 (像素) — 表示"镜头把 3D 点投影到图像上时的缩放"
cx, cy: 主点 (像素) — 光轴与图像平面的交点

有了 K: 像素 (u,v) + 深度 d → 相机坐标系 3D 点 P = d · K⁻¹ · [u,v,1]ᵀ
```

### 实战：用 Kalibr 标定

Kalibr 是目前最准的标定工具，同时标定内参 + 外参 + IMU。

### 简易标定 (OpenCV 单机版)

没有 ROS 也可以用 OpenCV：

```python
import cv2
import numpy as np
import glob

# 1. 准备棋盘格图片 (从不同角度拍摄)
pattern_size = (9, 6)  # 9×6 内角点
square_size = 0.025    # 每格 25mm

obj_points = []  # 3D 点
img_points = []  # 2D 点

# 棋盘格的 3D 坐标
objp = np.zeros((pattern_size[0] * pattern_size[1], 3), np.float32)
objp[:, :2] = np.mgrid[0:pattern_size[0], 0:pattern_size[1]].T.reshape(-1, 2)
objp *= square_size

images = glob.glob("calib_images/*.jpg")
for fname in images:
    img = cv2.imread(fname)
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

    # 找角点
    ret, corners = cv2.findChessboardCorners(gray, pattern_size, None)
    if ret:
        obj_points.append(objp)
        # 亚像素细化
        corners_subpix = cv2.cornerSubPix(
            gray, corners, (11, 11), (-1, -1),
            criteria=(cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001)
        )
        img_points.append(corners_subpix)

# 2. 标定
ret, K, dist, rvecs, tvecs = cv2.calibrateCamera(
    obj_points, img_points, gray.shape[::-1], None, None
)
print(f"相机矩阵 K:\n{K}")
print(f"畸变系数: {dist.ravel()}")

# 3. 验证: 重投影误差
mean_error = 0
for i in range(len(obj_points)):
    img_points_proj, _ = cv2.projectPoints(obj_points[i], rvecs[i], tvecs[i], K, dist)
    error = cv2.norm(img_points[i], img_points_proj, cv2.NORM_L2) / len(img_points_proj)
    mean_error += error
print(f"重投影误差: {mean_error / len(obj_points):.4f} px (应该 < 0.5)")
```

### 标定技巧

```
✅ 拍 20-30 张不同角度/距离的照片
✅ 标定板覆盖图像的四角和中心
✅ 包含不同倾斜角度 (±30°)
✅ 棋盘格在图像中至少占 30%
✅ 避免模糊 → 用三脚架或高速快门
❌ 不要全在同一个角度拍 → 信息冗余
❌ 棋盘格不要太远 (<2m for 桌面相机)
```

## 2. 手眼标定 (Eye-in-Hand)

### 两种手眼配置

```
Eye-in-Hand (相机在机械臂上，随臂运动):
  [相机] ─棒─ [机器人末端]
  适合: 灵活视角、VLA 手腕相机
  
  数学: AX = XB
    A: 末端位姿的变化 (从机器人正运动学)
    B: 相机位姿的变化 (从标定板图像)
    X: 相机在末端坐标系中的位姿 (我们要求的!)

Eye-to-Hand (相机固定在外部，不随臂运动):
  [相机]
     ↓ 看着
  [机器人] ← 标定板在末端
  
  数学: 同样 AX = XB，但 A/B 含义不同
```

### 实战：Eye-in-Hand 标定

```python
import numpy as np
import cv2
from scipy.spatial.transform import Rotation as R

def collect_hand_eye_data(robot, camera, pattern_size=(6, 6)):
    """
    收集手眼标定数据。
    流程: 移动机械臂到不同姿态 → 拍标定板 → 记录机器人末端位姿
    """
    robot_poses = []  # list of [R | t] in robot base frame
    board_poses = []  # list of [R | t] in camera frame

    joint_configs = [
        # 15-20 个不同的关节配置，确保标定板始终在视野内
        [0, -0.3, 0, -2.0, 0, 1.0, 0],
        [0.3, -0.5, 0.1, -1.8, 0, 1.2, 0],
        # ... 更多配置
    ]

    for joints in joint_configs:
        # 1. 移动机器人
        robot.move_joints(joints)

        # 2. 拍照 + 检测标定板
        img = camera.capture()
        ret, corners = cv2.findChessboardCorners(img, pattern_size, None)
        if not ret:
            continue

        # 3. 解 PnP → 标定板在相机中的位姿
        ret, rvec, tvec = cv2.solvePnP(
            board_3d_points, corners, K, dist
        )
        board_pose_in_cam = np.eye(4)
        board_pose_in_cam[:3, :3] = R.from_rotvec(rvec.flatten()).as_matrix()
        board_pose_in_cam[:3, 3] = tvec.flatten()

        # 4. 读机器人末端位姿
        ee_pose = robot.get_ee_pose()  # 末端在基座坐标系

        robot_poses.append(ee_pose)
        board_poses.append(board_pose_in_cam)

    return robot_poses, board_poses

def solve_hand_eye(robot_poses, board_poses):
    """
    AX = XB 求解。

    在 eye-in-hand 中:
      A = robot_poses[i]⁻¹ @ robot_poses[j]  (末端运动)
      B = board_poses[i]⁻¹ @ board_poses[j]   (相机看到的标定板运动)
      X = camera在末端中的位姿 (要求解!)

    对每对 (i, j) 有 AX = XB，多对数据用最小二乘求解。
    """
    # 构建 A 和 B 序列
    R_gripper2base = []
    t_gripper2base = []
    R_target2cam = []
    t_target2cam = []

    for i in range(len(robot_poses)):
        # robot_poses[i] = 末端在基座中的位姿 = base_T_ee
        R_gripper2base.append(robot_poses[i][:3, :3])
        t_gripper2base.append(robot_poses[i][:3, 3])
        # board_poses[i] = 标定板在相机中的位姿 = cam_T_board
        R_target2cam.append(board_poses[i][:3, :3])
        t_target2cam.append(board_poses[i][:3, 3])

    # OpenCV 内置的手眼标定求解器
    R_cam2gripper, t_cam2gripper = cv2.calibrateHandEye(
        R_gripper2base, t_gripper2base,
        R_target2cam, t_target2cam,
        method=cv2.CALIB_HAND_EYE_TSAI  # Tsai 方法, 经典好用
    )

    cam_in_ee = np.eye(4)
    cam_in_ee[:3, :3] = R_cam2gripper
    cam_in_ee[:3, 3] = t_cam2gripper.flatten()

    return cam_in_ee

# 使用结果: 把相机坐标系下的点转到机器人基座坐标系
def cam_to_base(point_in_cam, ee_pose_in_base, cam_in_ee):
    """相机坐标系 → 机器人基座坐标系"""
    point_in_ee = cam_in_ee[:3, :3] @ point_in_cam + cam_in_ee[:3, 3]
    point_in_base = ee_pose_in_base[:3, :3] @ point_in_ee + ee_pose_in_base[:3, 3]
    return point_in_base
```

### 标定误差诊断

```python
# 对标定结果做留一验证 (leave-one-out)
errors = []
for i in range(len(robot_poses)):
    # 用除 i 外的所有数据重新标定
    train_idx = [j for j in range(len(robot_poses)) if j != i]

    R_cam2gripper, t_cam2gripper = cv2.calibrateHandEye(
        [R_gripper2base[j] for j in train_idx],
        [t_gripper2base[j] for j in train_idx],
        [R_target2cam[j] for j in train_idx],
        [t_target2cam[j] for j in train_idx],
        method=cv2.CALIB_HAND_EYE_TSAI,
    )

    # 在留出的第 i 个数据上验证
    # AXB 理论上应该是单位阵，实际上会有误差
    A = robot_poses[i]
    X = np.eye(4); X[:3,:3] = R_cam2gripper; X[:3,3] = t_cam2gripper.flatten()
    B = board_poses[i]

    err = np.linalg.norm(A[:3,:3] @ X[:3,:3] - X[:3,:3] @ B[:3,:3])
    errors.append(err)

print(f"手眼标定验证误差: {np.mean(errors):.4f} rad (越小越好, <0.01 优秀)")

# 位置误差的快速估计:
# 如果机器人末端到标定板距离 ~0.5m，旋转误差 0.01 rad
# → 位置误差 ≈ 0.5 × 0.01 = 5mm
```

```
□ 第 1 步: 用 OpenCV 标定相机内参 (10 分钟)
  □ 打印棋盘格 → 拍 20 张图 → 跑 calibrateCamera
  □ 重投影误差 < 0.5px

□ 第 2 步: 理解坐标系变换链 (20 分钟)
  □ 画一张图: 基座→末端→相机→标定板
  □ 写出每个变换的符号 (base_T_ee, ee_T_cam, cam_T_board)

□ 第 3 步: 手眼标定 (30 分钟)
  □ 移动机械臂 15-20 个不同姿态
  □ 每个姿态拍照 + 记录末端位姿
  □ 跑 hand-eye calibration → 得到 ee_T_cam

□ 第 4 步: 验证标定精度 (15 分钟)
  □ 放一个物体在已知位置
  □ 用相机看→计算位置→机器人去碰
  □ 误差应 < 1cm
```
