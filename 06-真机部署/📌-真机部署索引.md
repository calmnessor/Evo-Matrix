# 真机部署索引

> 从训练好的模型到真机跑通——仿真与现实的"最后一公里"，也是新人最需要动手实践的一环。

## 部署全链路

```
┌─────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 训练好的  │ →  │ 模型优化  │ →  │ 系统集成  │ →  │ Sim2Real │ →  │  真机运行 │
│ VLA 模型 │    │ 推理加速  │    │ ROS 2  │    │  渐进部署  │    │  安全监控 │
└─────────┘    └──────────┘    └──────────┘    └──────────┘    └──────────┘
     ↑                                                               │
     └───────────────── 数据收集 (遥操作) ←──────────────────────────┘
                                 (真机数据回传，持续改进模型)
```

## 学习路径（由浅入深）

```
第 1 周: 认识硬件
  ├─ 了解课题组有哪些机器人/传感器/计算机
  ├─ 学会安全操作（急停、上电、关节释放）
  └─ 跑通一个简单的"关节运动"demo

第 2 周: 数据收集
  ├─ 学习遥操作（用 SpaceMouse/VR 控制机器人）
  ├─ 收集 10 条高质量演示数据
  └─ 学会 ros2 bag 录制和回放

第 3 周: 模型部署
  ├─ 把训练好的模型部署到真机
  ├─ 调试推理延迟和动作质量
  └─ 排查 Sim2Real Gap

第 4 周: 综合实践
  ├─ 完整 pipeline: 收集数据 → 训练 → 真机评估
  ├─ 记录失败 case，分析原因
  └─ 完成一个端到端真机任务
```
