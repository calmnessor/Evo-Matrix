# 仿真与工具索引

> 机器人仿真器和开发工具链——没有真机时的"虚拟实验室"。本索引覆盖具身智能和 VLA 研究中最常用的仿真环境、基准测试、开发工具。

## 仿真器全景对比

| 仿真器 | 物理引擎 | 渲染质量 | 速度 | VLA 适配 | 适合场景 |

### 仿真器选择决策树

```
你的需求是什么?
│
├─ 快速 RL 训练 (不需要视觉)
│  └─ MuJoCo (gymnasium 接口，极快)
│
├─ 视觉策略训练 (需要真实渲染)
│  ├─ 有 NVIDIA GPU → Isaac Sim / Isaac Lab
│  └─ 无 GPU → Habitat (快速室内) 或 PyBullet (简单场景)
│
├─ VLA 模型评估
│  ├─ 标准基准测试 → LIBERO (最全面) / CALVIN / RLBench
│  ├─ 快速验证 → robosuite
│  └─ 自定义任务 → MuJoCo + 自定义 MJCF
│
├─ 关节物体操作 (门/抽屉/柜子)
│  └─ SAPIEN / ManiSkill
│
├─ 移动操作 (导航 + 操作)
│  ├─ 室内 → Habitat
│  └─ 交互式 → AI2-THOR
│
├─ 工业/ROS 集成
│  └─ Gazebo / Isaac Sim
│
└─ 流体/柔体/复杂物理
   └─ ThreeDWorld / SoftGym
```

## 学习路径

### 新手入门 (第 1-2 周)

```
1. MuJoCo + gymnasium: 跑通第一个 RL 环境 (HalfCheetah)
2. PyBullet: 加载一个机械臂 URDF，用 IK 控制末端
3. 用 HuggingFace Datasets 加载 Bridge v2 数据
```

### 仿真进阶 (第 3-4 周)

```
4. robosuite: 运行 VLA benchmark 评估
5. Isaac Sim: 熟悉 UI 和基本场景搭建
6. Blender: 创建自定义物体并导入仿真器
```

### 综合应用 (第 5-8 周)

```
7. 用 MuJoCo + robomimic 训练 BC 策略
8. 用 Isaac Lab 搭建 RL 训练 pipeline
9. 用 LIBERO 做 VLA 模型性能评估
10. 用 Docker 封装完整实验环境
```
