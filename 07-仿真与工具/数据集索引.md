## VLA 常用基准

### LIBERO — VLA 标准基准

```
LIBERO = robosuite 环境 + 130 任务 + 标准评估协议

LIBERO-100:  100 个任务，见/未见场景各 50
  训练: 50 个场景的演示
  测试: 另 50 个未见场景 → 测泛化

LIBERO-90:   90 个任务，长期任务
LIBERO-10:   10 个任务，快速原型
LIBERO-OBJECT/GOAL/SPATIAL: 特定泛化维度
```

### CALVIN — 语言条件长周期基准

```
CALVIN 协议:
  - 4 个不同环境 (A/B/C/D)
  - 训练: A+B+C
  - 测试: D → 测泛化
  - 多步语言指令链: "打开抽屉 → 拿起积木 → 放入抽屉 → 关上抽屉"
  - 评价指标: 连续完成步数
```

### RLBench — 100 任务大规模基准

```
RLBench 特点:
  - 100 个定义好的操作任务
  - 每个任务有自然语言描述
  - 支持变体 (物体位置/颜色/形状)
  - 支持多视角渲染
  - 内置 waypoint 和 motion planner
```

## 数据格式与处理

### RLDS 格式 (OXE 标准)

```python
import tensorflow_datasets as tfds

# OXE 数据的标准结构
builder = tfds.builder_from_directory("gs://gresearch/robotics/bridge_v2/1.0.0")
dataset = builder.as_dataset(split="train")

for episode in dataset.take(1):
    for step in episode["steps"].take(5):
        image = step["observation"]["image"]
        state = step["observation"]["state"]       # 本体感知
        action = step["action"]                     # 动作 (7-dof delta)
        lang = step["language_instruction"].numpy().decode()
        # 此外还有:
        #   step["observation"]["wrist_image"]      # 腕部相机
        #   step["is_first"] / step["is_last"]      # episode 边界
        #   step["discount"]                         # 0/1 表示完成
```

### 多数据集混合训练的预处理

```python
def normalize_action_space(datasets):
    """统一不同数据集的动作空间"""
    for ds in datasets:
        if ds.action_space == "joint_delta":
            ds.actions = (ds.actions - ds.action_mean) / ds.action_std
        elif ds.action_space == "ee_delta":
            # 末端空间 → 关节空间 (需要 IK)
            ds.actions = ee_to_joint(ds.actions)
        # 统一到 [mean=0, std=1] 范围
    return datasets

def resize_images(dataset, target_size=(224, 224)):
    """统一图像尺寸"""
    dataset = dataset.map(
        lambda x: {"image": tf.image.resize(x["image"], target_size)}
    )
    return dataset
```

### 数据采样策略

```python
# 1. 按数据集平衡采样
def balanced_sampling(datasets, batch_size):
    weights = [1.0 / len(ds) for ds in datasets]
    chosen = random.choices(datasets, weights=weights, k=batch_size)
    return [ds.sample(1) for ds in chosen]

# 2. 按任务难度加权采样
def curriculum_sampling(dataset, step, total_steps):
    # 前期多采样简单任务，后期多采样难任务
    easy_weight = max(0.1, 1.0 - step / total_steps)
    hard_weight = min(1.0, step / total_steps)
    return sample_with_weights(dataset, easy=easy_weight, hard=hard_weight)

# 3. 失败数据重采样 (RECAP 风格)
def recap_sampling(dataset, replay_buffer):
    # 混合原始演示 + 自主收集的 (成功+失败) 数据
    return mix(dataset.sample(0.7), replay_buffer.sample(0.3))
```
