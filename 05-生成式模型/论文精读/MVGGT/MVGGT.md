## 一句话总结

MVGGT 在 VGGT 的几何重建能力之上，增加了**自然语言引导的 3D 目标分割**——双分支架构：冻结的 VGGT 几何分支提供 3D 先验，可训练的多模态分支通过交叉注意力注入语言语义。

## 核心动机：为什么需要 MVGGT？

| 方法 | 能做 | 不能做 |
|------|------|--------|
| VGGT | 3D 重建 | 不懂语言，无法定位目标 |
| LERF / OpenNeRF | 语言→3D | 需要稠密训练视图 |
| 3D-LLM | 语言+3D | 依赖已有完整 3D 模型 |
| 2D Referring Seg | 语言→2D 分割 | 无 3D 空间信息 |
| **MVGGT** | **稀疏视图 3D 重建 + 语言定位** | — |

MVGGT 是首个在**稀疏视图**条件下联合做 **3D 重建 + 语言引导 3D 分割**的方法。

## 传统思路

**<font style="color:#F8B881;">两阶段</font>**：先重建密集点云，再进行分割。

**<font style="color:#01B2BC;">缺点</font>**：1.真实具身场景会产生低质量的几何结构，导致目标区域粗糙，无法泛化

2.运行速度较慢（分割之前执行完整重建引入显著延迟，限制了实际部署）

:::success
在稀疏视角下会彻底崩溃，因为稀疏重建出的点云往往充满噪声、结构扭曲且不完整。

**无法泛化**：

 传统的3DRES模型（如基于ScanRefer等数据集训练的模型）是在**绝对完美的高质量点云**上进行训练的。  

所以在真实的具身场景下，得到的是稀疏RGB图像，重建效果不够完美，无法使用

:::



**<font style="color:#F8B881;">本文创新点</font>**：在稀疏 RGB 多视角下直接完成 3D 场景重建与语言指代分割任务。

作者提出了 MV-3DRES** ****(Multi-view 3D Referring Expression Segmentation)**

+ **输入**：极少量的稀疏 RGB 图像 $ I=\{I_{i}\}_{i=1}^{N} $ （通常为8帧）和一句自然语言描述 $ T $。
+ **输出**：重建的 3D 点云 和对应的3D二进制目标掩码。
+ **难点**：模型必须在没有完整的 3D 先验的情况下，跨越不一致的视角来解决遮挡问题和空间关系（比如“在杯子后面”） 。

:::color1
输入文本指令 “拿起杯子后面的橘子”的情况下：

传统方法有完整的点云，有全局的视角，可以很好判断

无 3D 先验：二维图像没有物体的大小、深度距离。在某些视角下目标图像被完全遮挡，在某些视角下空间位置看起来发生巨变（ 从侧面看过去，橘子似乎是在水杯的“右侧”，而不是“后面”  ）。

<font style="color:#2F4BDA;">模型不能依靠某一张图片来下结论，它必须在隐式特征空间中，把这8张碎片化的 2D信息“脑补”并拼接起来，才能还原出真实的物理场景。  </font>

:::

##  MVGGT 架构解析：双分支的精妙解耦  
1. **<font style="color:#F3BB2F;">冻结的几何分支</font>**

 	**作用**：提供稳定的几何支架，它由$ L $ 个Transformer Block组成，交替进行帧内自注意力和全局跨视角注意力计算。

**细节**：该分支负责预测相机位姿和深度图，进而反投影出粗糙的点云。这个分支是冻结的，意味着模型不需要在稀疏数据上重新学习 3D 几何，从而保证了特征空间的稳定。

2. **<font style="color:#F3BB2F;">可训练的多模态分支</font>**

目的：将文本提示注入到视觉特征中，但它必须依赖几何信息来理解空间关系。作者使用了三分之一的深度（$ L/3 $ 块）来完成特征融合。

:::color1
 论文在 Table 5 的消融实验中证实，晚期融合（Late Fusion）效果最好 。这符合一个基本直觉：空间感知应该首先被建立，随后由语言提供细化的指导（spatial perception should be established first, with language providing later refinement）。这种顺序保证了跨视角表征更加稳定和具有判别性 。、



**注意力机制的脆弱性：** 论文在 Table 6 中对层数进行了消融。当层数扩展到 16 层时，性能出现了急剧下降（sharp decline），原因是在稀疏监督下，过深的交叉注意力机制变得非常不稳定（unstable attention）。



使用三分之一的深度，实际上是在给模型下达一个明确的归纳偏置（Inductive Bias）：语言只是用来“引导”（guide）几何特征进行聚合和消解歧义的，而不是用来“替代”几何特征的 。

这两个实验后续仔细研究一下！

:::

+ 几何特征注入：采用了零初始化的$ 1\times1 $ 卷积 $ \mathcal{Z} $。这种设计在不破坏预训练权重的前提下，将高层几何特征平滑地过度到多模态特征空间：

<!-- 这是一张图片，ocr 内容为：FPU+2(FGEO) FYN -->
![](https://cdn.nlark.com/yuque/0/2026/png/43210750/1776131436729-f6977dd5-6159-4a11-8c8c-7d82584bb02c.png)

:::info
$ F_{l^{\prime}}^{in} $：代表第 $ l^{\prime} $ 个多模态 Transformer 块（Multimodal Block）的**输入特征**。

$ F_{l^{\prime}-1}^{out} $：代表上一层（第 $ l^{\prime}-1 $ 层）多模态块经过视觉注意力和交叉注意力计算后的**输出特征**。这部分承载着逐渐融合了语言信息的视觉特征。

$ F_{l}^{geo} $：代表冻结的几何重建分支（Reconstruction Branch）中第 $ l $  层的**几何特征**。由于两个分支深度不同，这里是将重建分支最后 $ L/3 $ 层的特征，按顺序一一对应地“喂”给多模态分支 

$ \mathcal{Z}(\cdot) $：这是一个**零初始化的 **$ 1 \times 1 $** 卷积层**（Zero-initialized $ 1 \times 1 $ convolution） 。它的作用是将几何特征投影到多模态特征的空间维度中 。



这是一个带有特殊门控机制的**残差连接（Residual Connection）**。它的核心目的是：**在不破坏已有特征表达的前提下，平滑、渐进地引入空间几何先验**。

这里最精妙的设计在于这个零初始化卷积 $ \mathcal{Z} $：

+ **训练初始阶段的“隐身”：** 因为 $ \mathcal{Z} $ 的权重初始化为 0，所以在模型刚开始训练的第一步，$ \mathcal{Z}(F_{l}^{geo}) = 0 $。此时公式退化为 $ F_{l^{\prime}}^{in} = F_{l^{\prime}-1}^{out} $。这意味着多模态分支在一开始就像一个普通的、没有几何干扰的 Transformer 一样运作。
+ **训练过程中的“渐进引导”：** 随着梯度的反向传播，$ \mathcal{Z} $ 的权重逐渐被更新（不再是 0）。多模态分支开始像海绵吸水一样，**平滑地、自适应地**吸收来自 $ F_{l}^{geo} $ 的高阶几何线索（比如深度、边缘、视角几何） 。
+ **保护预训练骨干：** 这种设计允许多模态分支逐步结合几何线索，而不会因为一开始就强行注入未对齐的跨模态特征，导致预训练的视觉或语言特征空间崩溃 。这个技巧在很多引入额外控制条件的生成模型（比如 Stable Diffusion 的 ControlNet）中非常常见。

:::

+ 语言特征注入：在多模态块内，通过标准的交叉注意力（Cross-attention）将文本特征（Query、Key、Value）融合进视觉特征中，使得文本线索能够引导跨视角的特征聚合 。

:::info
 在标准的 Transformer 中，最常见的是**自注意力（Self-Attention）**。在自注意力中，Q、K、V 全部来自同一个模态（比如一句话内部的词互相看）  

 而在**交叉注意力（Cross-Attention）中，Q、K、V 来自不同的模态**。  

在 MVGGT 论文中：

+ Q 是"视觉特征"：图像上的一个个 Patch（图像块）
+ Key 和 Value 是"文本特征"：用户输入的那句话的一个个 Word

:::

+ **消融结论：** 实验证明，**晚期融合（Late Fusion）** 效果最好 。这符合直觉：模型应当先建立起稳定的空间几何感知，然后再用语言去进行细粒度的语义区分和修正 。

### 核心痛点与数学解法：FGD 与PVSO
整篇论文优化层面的核心。在极度稀疏的 3D 重建空间中，模型遇到了严重的梯度消失问题。

痛点：前景梯度稀释（ FGD - Foreground Gradient Dilution  ）

在稀疏重建中，点云规模极大，但目标物体（比如一个水杯的把手或杯身）往往只占不到 2% 的点 。

如果直接在 3D 空间计算  Dice Loss：

![](https://cdn.nlark.com/yuque/0/2026/png/43210750/1776132558835-49173288-28a7-4887-ba39-34dc9f5187ff.png)

其对预测概率 $ p_j $  的梯度为：

<!-- 这是一张图片，ocr 内容为：2(I-GJU) OLDICE U2 OPJ -->
![](https://cdn.nlark.com/yuque/0/2026/png/43210750/1776132577762-2ec3a7f9-caa8-43eb-9d44-6c7a555bcd83.png)

在训练初期，预测值较小，交集$ I \approx 0 $。因为背景点极其庞大，分母的并集项 $ U $ 会膨胀几个数量级 。导致前景点（$ g_j=1 $）的梯度近似为 $ -\frac{2}{U} $，幅度极其微小（落入 $ 10^{-9}-10^{-11} $ 级别） 。这导致优化陷入局部极小值，模型根本学不到东西 。

:::success
早期预测不好，导致交集极小；同时，由于是在庞大的 3D 场景中找极小的部件，导致并集分母极其庞大。分子极小、分母极大，两者共同作用，导致前景点的梯度被海量的背景"稀释"到了几乎为零，模型失去更新动力



之前的方法提供了完整的3D场景，它不会像稀疏重建出现大量的噪声点，且用完整的3D场景去预测效果比较好一些

:::

**解法**： 单视角无目标抑制优化 (PVSO)  

既然 3D 空间的背景太大，作者选择把监督信号拉回到 2D 图像平面计算

+ **<font style="color:#F3BB2F;">2D 梯度浓缩</font>**： 在选定的带有目标的 2D 视角中，目标像素占比可以达到 10-15%，远大于 3D 空间中的 <2% 。此时 $ U_{2D} \ll U_{3D} $，前景梯度被放大了 1 到 3 个数量级，有效激活了模型的早期训练 。
+ **<font style="color:#F3BB2F;">无目标视角抑制</font>**： 由于是稀疏抓拍，很多视角里根本没有目标（比如机械臂移动时背对目标） 。PVSO 会对这些“空视角”进行权重归一化 ($ w_s = \frac{1}{|\mathcal{V}_n|} $)，避免海量的 trivial negatives 淹没损失函数 。

:::color1
视角级别的极度不平衡：围绕物体拍了 8 张图，只有两张拍到了目标物体，其它照片都是空视角

6张空视角图片，在模型训练的时候预测的标签是 0 ，计算的损失在反向传播时，会影响 2 张带目标物体的图像输出 1 的结果

解决：

计算总损失的时候，对空视角的损失加上一个权重，减少它的影响力

:::

## 方法
**<font style="color:#F8B881;">输入编码器</font>**：给定 N 输入图像  和 指令 T，每张图像通过 ViT 编码，生成块嵌入（P × D），其中 P 表示块的数量，D 为特征维度

文本被分词并由语言编码器吃力，生成词嵌入（W × D）。其中 W 表示 token 数量。

**<font style="color:#F8B881;">冻结重构分支</font>**：是一个几何感知的 Transformer，包括 L 个块。每个块交替使用帧级自注意力和全局跨视图注意力，逐步构建视觉一致的结构线索。 。令 Fgeo ℓ 表示第ℓ∈{1,...,L} 个块的特征  。这些特征被输入到一个重构解码器中，**<font style="color:#DF2A3F;">用于预测相机位姿和深度图，随后将其反投影为粗略点云</font>**

:::success
该分支所有参数冻结，确保训练过程中几何先验的稳定性。

 并消除从稀疏图像中重新学习三维几何的需求。  

:::

**<font style="color:#F8B881;">可训练的多模态分支</font>**：多模态分支包含  Lmulti=L/3   变换块。其目标是将几何线索与文本条件视觉特征融合。由于两个分支的深度不同，我们通过将重构狗分支最后的 L/3 块中的几何特征注入到多模态分支的所有 Lmulti 块中，以对齐它们之间的交互。 



### 几何注入
**几何注入**： 核心要解决的问题：一条深层的、被冻结的“纯视觉几何网络”，如何与一条较浅的、需要动态学习的"多模态网络"进行完美对接？

**一、36层如何对接12层**

MVGGT的架构面临一个"长短脚"的问题：

+ 冻结的重构分支**（Reconstruction Branch）**：非常深，总共有 L 个 Transformer Block（在官方实现中通常是 36 层） 。它的任务极其繁重，需要从稀疏 2D 图像一步步推导相机位姿和深度。
+ 可训练的多模态分支（Multimodal Branch）：较浅，只有$ L_{multi} = L/3 $个 Block（即 12 层）。

为了对齐这两个深度的分支，作者指定了"尾部对齐"映射：

多模态分支的 12 个 Block，只接受重建分支最后 12 个 Block提取的特征。

具体的映射关系是：对于第 $ l' $ 个多模态块（$ l' $ 范围从 1 到 12），它提取来自第 $ l $ 个重建块的几何特征 $ F_l^{geo} $，这里的 $ l $ 按顺序覆盖重建分支的最后 $ L_{multi} $ 层 。  
用具体的层数来算（$ L=36, L_{multi}=12 $）：

+ 多模态的 第 1 层，接收重建分支的 第 25 层（$ 36 - 12 + 1 = 25 $）的特征 。
+ 多模态的 第 2 层，接收重建分支的 第 26 层的特征。
+ ...依此类推...
+ 多模态的 第 12 层，接收重建分支的 第 36 层（最后一层）的特征。

**二、为什么要取"最后三分之一"的几何特征？**

1. 浅层几何太"低级"：在重建分支的前24层，网络可能还在艰难地识别 2D 边缘、提取局部纹理或刚开始建立。这些特征对于需要进行高级空间语义推理（比如理解“在...左边”）的多模态分支来说，太过原始，充满了局部视角的偏见。
2. **深层几何才具备“全局 3D 共识”**：只有经过了大量的帧内（Frame-level）和跨视角全局（Global）的交替注意力计算后，重建分支在最后 12 层才真正建立起了稳定、具有一致性的三维空间结构线索（Higher-level geometric cues） 。把这些成熟的高级结构信息喂给多模态分支，多模态分支才能在此基础上进行准确的跨模态语义对齐。

### **MVRefer 基准**
**MVRefer 基准**是作者为了系统性评估 **MV-3DRES（多视角3D指代表达分割）** 这一全新任务，而专门构建的首个标准化评估体系和数据集 。

由于传统的 3DRES 任务都假设拥有完美的致密点云，现有的评测体系完全不适用于仅输入几张稀疏图片的场景。为了填补这个空白，作者设计了 MVRefer，其核心目的是极其逼真地模拟具身智能体（如机器人或 AR 眼镜）在真实物理世界中的视觉感知限制 。

我们可以从以下三个核心维度来深入理解这个基准：

#### 1. 数据来源与场景模拟（抓拍与可见性验证）
MVRefer 是建立在经典的 ScanRefer 数据集和 ScanNet  原始视频流基础之上的。

+ **模拟稀疏抓拍：** 对于每一个“语言-物体”对，基准不再提供完美点云，而是从视频流中以均匀的时间间隔抽取 **8 帧 RGB 图像（**$ N=8 $**）**，以此来模拟设备在移动过程中随意、即时（on-the-fly）的稀疏观察 。
+ **可见性兜底机制：** 随机抽取 8 帧带来了一个致命问题——可能这 8 张图全都没拍到文本描述的那个目标（任务变得无解） 。为此，MVRefer 引入了可见性验证：如果初始的 8 张图里没有目标，它会随机把其中一张“空视角”替换为包含目标的帧 。这种机制既保证了模型至少有一点正样本线索，又保留了极高比例的“空视角”以维持稀疏感知的真实难度 。

#### 2. 多维度评估指标（解耦重建与分割）
这是 MVRefer 非常有价值的设计。由于 MV-3DRES 任务要求模型从零开始，同时自己重建 3D 结构并输出 3D 掩码，如果只在 3D 空间评估，由于点云本身就是粗糙的，重建的误差会严重掩盖模型真实的“语言定位能力” 。因此，基准采用了两套指标：

+ **传统的全局 3D 指标（**$ mIoU_{global} $**）：** 衡量最终预测的 3D 掩码与真实掩码（投影在重建点云上）的重合度 。
+ **多视角诊断指标（**$ mIoU_{view} $**）：** 为了剥离 3D 重建误差，基准利用已知的相机内外参，把预测的 3D 掩码**反向投影回那 8 张 2D 照片里**进行评估 。这其中不仅包含整体的投影 IoU，还精细地拆分出了：
    - $ mIoU_{pos} $**（正样本指标）：** 评估在拍到了目标的画面里，模型抠得准不准 。
    - $ mIoU_{neg} $**（负样本指标）：** 评估在没拍到目标的“空视角”里，模型是否能成功抑制误报 。

#### 3. 难度分级（衡量稀疏度的极限）
为了测试模型应对“前景梯度稀释（FGD）”的鲁棒性，基准根据目标物体在 2D 图像中的像素占比，将数据划分为两个难度等级 ：

+ **Hard（困难样本）：** 目标在所有可见视图中占用的像素均**低于 5%**。在这种情况下，正样本监督信号极其微弱，是对模型特征聚合能力的极限测试。
+ **Easy（简单样本）：** 至少有一个视图中目标像素占比达到 **5% 以上**。

总结来说，MVRefer 并不只是一个简单的数据集，它是一套严密的“体检标准”，逼着模型放弃对完美 3D 几何的幻想，去学会在杂乱、局部不可见且充满歧义的稀疏视界中寻找答案。

基于 ScanNet（室内场景数据集） 和 ScanRefer（3D 语言指代数据集） 进行二次构建的。

+ **语言描述**：直接服用 ScanRefer 数据集中新城的"自然语言 - 3D物体"对应关系（例如："靠墙放置的木制钢结构书桌"对应场景中的物体 ID）。
+ **图像来源**：用 ScanNet 数据集的原始 RGB 视频流 中去提取 2D 图片，而不是使用它已经建好的 3D 点云。

| --- | --- | --- |

| **object_id** | ScanRefer 中的物体实例 ID | ScanRefer |

## MVGGT能否在场景存在遮挡的情况下识别出某个物体的掩码
MVGGT的架构应对遮挡有优势：

1. 跨视角全局注意力

如果只看单一视角，一旦物体被遮挡，2D 分割网络会判断错误。

MVGGT的重建分支中设计了全局跨视角注意力。这使得网络能够在高维特征空间中，把不同视角的信息"缝合"起来。依靠底层的几何一致性推断出它的完整 3D 轮廓。

2. 利用语义消解视觉残缺

在严重遮挡下，物体的视觉几何特征会变得极其碎片化。单纯依靠视觉，很难判断这块露出来的边缘属于谁。

MVGGT 的多模态分支通过交叉注意力机制，将文本指令（例如“被挡在书本后面的红色杯子”）注入到视觉特征中。语言在这里起到了强大的“消歧”作用，它引导网络跨越遮挡物的干扰，强行将注意力集中在那些符合语义描述的碎片化视觉线索上。

3.  PVSO  对空视角的抑制





## 将affordance工作应用到grasp上
Rekep + graspNet也是类似的思路

**为什么不直接构建一个图像/3D到抓取位姿（6-DoF）的端到端数据集**

1.意图模糊：端到端习惯于找唯一的正确答案。但在现实任务中，同一个物体在不同任务下的抓取位姿是不同的

+ 例如：一个bottle，任务是"喝水"，需要抓取bottle的瓶身。如果任务是"打开"，需要操作bottle的瓶盖

2.陷入"死机硬背"

端到端模型对训练集中的特定物体实例过拟合。它记住的不是“具备这种曲率的边缘可以被抓取”，而是“这套特定的 RGB 像素纹理应该对应这组 XYZ 坐标”。一旦遇到形状稍有改变的未见物体（OOD），模型就会彻底崩溃。

**先预测Affordance的好处（A+B模式）**

将抓取拆分为“预测 Affordance（寻找功能部件）”和“生成 Grasp（执行物理抓取）”两步，实际上是构建了一种极其强大的解耦架构。

1.**空间剪枝**：先预测部件级的 Affordance，相当于给底层的抓取算法提供了一个精确的空间注意力掩码

2.**解耦**：先通过 Affordance 模型（模块 A）确定“去哪抓、抓哪个部件”，再将这个局部几何区域交给成熟的通用抓取生成网络（模块 B）去解决“怎么抓稳、怎么不发生碰撞”。这种“A+B”的架构既保留了传统抓取网络在杂乱场景下的物理鲁棒性，又赋予了机器人高级的意图理解能力。

:::color1
Rekep + AnyGrasp存在问题 Rekep预测的点是像素级的（像素点）

而Affordance + AnyGrasp ，Affordance预测的是一整个部件的区域，把 affordance 概率 × AnyGrasp 置信度选抓

affordance保证意图可行性，AnyGrasp保证物理可行性

:::

**3. 关键的可解释性与 Debug 能力** 端到端网络如果抓空了，就是一个**<font style="color:#DF2A3F;">黑盒</font>**，你根本不知道怎么优化。 但如果采用 Affordance + Grasp 的两段式结构，一旦失败，你可以清晰地排查：

+ 是 Affordance 预测错了？（例如把门轴当成了把手） -> _去优化你的 3DGS 特征提取和语义对齐。_
+ 还是 Affordance 预测对了，但抓取位姿与环境发生了干涉？ -> _去优化底层抓取网络的碰撞检测。_

## 实验结果

### MVRefer 基准

| 方法 | Overall mIoU | Hard mIoU |
|------|-------------|-----------|
| 2D 方法 + 后投影 | ~12% | ~5% |
| 最佳 3D 基线 | 18.5% | 8.1% |
| **MVGGT** | **39.9%** | **24.4%** |

### 消融实验

| 配置 | mIoU |
|------|------|
| VGGT 分支冻结 (无语言) | 15.2% |
| + 语言注入 | 28.7% |
| + PVSO (完整 MVGGT) | **39.9%** |

- PVSO 从 28.7% → 39.9%（**+11.2 个点**），是最大的单项提升
- 验证了 FGD 确实是核心瓶颈

### 定性优势

MVGGT 在以下场景比基线显著更好：
- 小物体（如杯子 vs 整张桌子）
- 严重遮挡（抽屉里的物品）
- 与背景颜色相似的物体
- 罕见物体（语言理解的泛化）
