# 生成式模型方向综述：3D 重建与场景生成

> Generative Models for 3D Vision — 从多张 2D 图片直接推理出 3D 世界。本文为科研新手提供该方向的完整学术地图。

## 1. 定义与直觉

### 什么是 3D 生成式模型？

```
2D 图像 (有限信息)  →  3D 生成模型  →  3D 场景 (完整几何)

输入:   几张照片 (稀疏视图)
输出:   相机位姿 + 深度图 + 3D 点云 + 密集体素/高斯球
```

核心能力：**从稀疏观测中恢复完整 3D**——这正是具身智能机器人最需要的能力。机器人只有几个相机视角，却需要理解整个 3D 工作空间。

### 为什么对具身智能至关重要？

| 具身需求 | 3D 生成模型的贡献 |
|----------|------------------|
| **物体定位** | 从 RGB 图像重建物体 3D 位置和形状 |
| **场景理解** | 恢复完整工作空间的几何结构 |
| **抓取规划** | 精确 3D 模型支持抓取点计算 |
| **Sim2Real** | 生成的 3D 场景可直接导入仿真器 |
| **语言引导** | 根据自然语言描述定位 3D 目标（MVGGT） |

## 2. 技术路线图

```
传统几何方法                       深度学习方法                        前馈式大模型
[SfM, MVS]  ──────────→  [NeRF, 3DGS]  ──────────→  [DUSt3R, VGGT, MVGGT]
   ↓                          ↓                              ↓
 需要大量视图             需要每场景优化                  单次前向，< 1 秒
 慢（分钟级）             中等（分钟级训练）              快（秒级推理）
 精确但不鲁棒             鲁棒但计算密集                  又快又准
```

### 五条技术路线

| 路线 | 代表方法 | 核心思想 | 推理速度 | 适合场景 |
|------|---------|---------|---------|---------|
| **1. 经典多视图几何** | COLMAP, SfM, MVS | 特征匹配 + 几何优化 | 分钟级 | 离线重建 |

| **5. 语言引导 3D 理解** | **MVGGT**, LERF, OpenNeRF | 语言条件化 3D 重建 | 秒级 | 人机交互、指令理解 |

## 3. 核心技术方法

### 路线 1: 经典多视图几何

```
输入: N 张不同视角的图像
  ↓
特征提取 (SIFT/SuperPoint)
  ↓
特征匹配 + 几何验证 (RANSAC)
  ↓
SfM: 恢复相机位姿 + 稀疏点云
  ↓
MVS: 稠密化点云 → 网格 → 纹理贴图
  ↓
输出: 3D 模型 + 相机参数
```

**代表工具**：[COLMAP](https://colmap.github.io/) (经典)，[HLoc](https://github.com/cvg/Hierarchical-Localization) (学习特征版)

**局限**：需要大量重叠视图、纹理丰富的表面、静态场景。

### 路线 2: Neural Radiance Fields (NeRF)

```python
# NeRF 核心思想（伪代码）
def nerf(x, y, z, θ, φ):
    """用 MLP 隐式表示 3D 场景"""
    # 输入: 3D 坐标 + 视角方向
    pos_enc = positional_encoding(x, y, z)
    view_enc = positional_encoding(θ, φ)

    # MLP 预测该点的颜色和密度
    h = relu(Linear(pos_enc))
    σ = Linear(h)          # 体密度（与视角无关）
    c = Linear(h, view_enc) # 颜色（与视角有关）
    return σ, c

# 体渲染: 沿光线积分
def volume_rendering(camera_ray, nerf_model):
    samples = sample_along_ray(camera_ray)
    colors, densities = [], []
    for point in samples:
        σ, c = nerf_model(point)
        colors.append(c)
        densities.append(σ)
    return accumulate(colors, densities)  # 像素颜色
```

**关键改进**：
- **InstantNGP** (NVIDIA): 多分辨率哈希编码 → 训练加速 1000×
- **ZipNeRF**: 抗锯齿 NeRF → 更清晰
- **3D Gaussian Splatting**: 用显式高斯球替代 MLP → 训练快 + 渲染快

### 路线 3: 3D Gaussian Splatting (3DGS)

```
场景表示: N 个 3D 高斯球
每个高斯: {μ (中心), Σ (协方差), c (颜色), α (不透明度)}
         ↓
可微光栅化 (differentiable rasterizer)
         ↓
从任意视角渲染图像
         ↓
Loss = |渲染 - 真实| → 反向传播 → 优化高斯参数
```

**代码示例** (从多视图图像重建 3DGS)：

```python
import torch
from gaussian_splatting import GaussianModel, render

# 初始化: 从 SfM 稀疏点云出发
gaussians = GaussianModel.from_colmap(sparse_pc)

# 优化: 可微渲染 + L1 loss
for step in range(30_000):
    for viewpoint in training_views:
        rendered = render(gaussians, viewpoint)
        loss = (rendered - viewpoint.image).abs().mean()
        loss.backward()
        gaussians.optimizer.step()
        gaussians.densify_and_prune()  # 自适应控制高斯数量

# 推理: 实时 60fps 渲染
novel_view = render(gaussians, test_viewpoint)
```

### 路线 4: 前馈式 3D 重建 — VGGT (CVPR 2025 Best Paper)

VGGT 是该方向的**里程碑工作**——首次实现纯前馈式全属性 3D 推理。

```
输入: 1~N 张任意视点图像
       ↓
  DINOv2 编码 (每帧独立)
       ↓
  Alternating-Attention (24 层)
  ├─ Frame-wise Attention: 每帧内 token 交互
  └─ Global Attention: 跨帧 token 交互
       ↓
  4 个预测头:
  ├─ 相机位姿 (intrinsics + extrinsics)
  ├─ 深度图 (每像素深度值)
  ├─ 点云图 (每像素 3D 坐标)
  └─ 3D 点轨迹 (跨帧对应点)
       ↓
  全部输出在 < 1 秒内完成！
```

**核心创新**：不需要 Bundle Adjustment 等后处理——模型学到了隐式几何推理能力（后续研究发现 attention 层中自发涌现了极线约束）。

**与之前方法的对比**：

| | DUSt3R | MASt3R | VGGT |
|------|------|------|------|
| 输入 | 图像对 | 图像对 | **任意数量图像** |
| 后处理 | 全局对齐 | 全局对齐 + 匹配 | **无需后处理** |
| 相机 | ✓ | ✓ | ✓ |
| 深度 | — | ✓ | ✓ |
| 点轨迹 | — | — | ✓ |
| 推理时间 | 秒级 | 秒级 | **< 1 秒** |
| CVPR 奖项 | — | — | **Best Paper** |

### 路线 5: 语言引导 3D — MVGGT (CVPR 2026)

MVGGT 在 VGGT 基础上增加了**自然语言 → 3D 目标分割**能力。

```
输入: N 张稀疏 RGB + 自然语言描述
        "把桌上的红色马克杯拿起来"
       ↓
  双分支架构:
  ├─ 冻结几何分支 (VGGT): 相机 + 深度 + 粗糙点云
  └─ 可训练多模态分支: 语言交叉注意力注入视觉特征
       ↓
  PVSO 优化策略 (解决前景梯度稀释)
       ↓
  输出: 3D 目标掩码 + 完整场景重建
```

**关键挑战与解决**：
- **前景梯度稀释 (FGD)**：稀疏点云中前景物体点极少 → 梯度被背景淹没
- **PVSO 方案**：将 3D 预测投影回 2D 监督 → 放大前景梯度 + 抑制无目标视图

## 5. VGGT 核心洞察

### 架构：Alternating-Attention

```
层 1: Frame-wise Self-Attention  ← 每帧内部: "这幅图里有什么特征?"
层 2: Global Cross-Attention     ← 帧间通信: "另一幅图的对应点是哪里?"
层 3: Frame-wise Self-Attention
层 4: Global Cross-Attention
...
层 24: → 4 个预测头
```

这个设计让模型**交替进行**局部特征提取和全局几何匹配——模拟了传统 SfM 的特征提取→匹配的循环过程。

### 涌现的几何理解

VGGT 最令人震惊的发现来自后续分析论文（arXiv:2512.11508）：

> **模型从未被显式教过极线几何，但它在第 12 层 attention 中自发学会了极线约束！**

- 可以从中间层恢复基础矩阵 F
- 对遮挡和外观变化更鲁棒（vs 经典匹配）

### 对具身智能的意义

# VGGT 在机器人感知 pipeline 中的位置
def robot_perception_pipeline(images):

## 6. MVGGT 核心洞察

### 问题：机器人语言指令理解

```
人: "把水槽里的蓝色盘子放到洗碗机里"
     ↓
需要理解:
1. "蓝色盘子"是什么样子？→ 视觉语义
2. "水槽"在哪里？→ 场景几何
3. 盘子在 3D 空间的位置？→ 3D 定位
4. 只有有限的相机视角 → 稀疏视图
```

MVGGT 的任务定义：**MV-3DRES** = 给定 N 张稀疏视图 + 语言描述 → 输出 3D 目标分割掩码。

### 双分支架构

```
语言: "把蓝色盘子拿起来"
  ↓
CLIP 文本编码 → 语言特征
  ↓
交叉注意力 ←→ 视觉特征 (可训练多模态分支)
  ↓                    ↓
VGGT 冻结分支 (几何先验: 相机、深度、点云)
  ↓
融合特征 → 3D Segmentation Head
  ↓
3D 点级目标掩码
```

### PVSO：解决前景梯度稀释

```python
# 问题: 稀疏点云中，前景物体只有 50 个点，背景有 100000 个点
# → 损失函数被背景主导 → 模型学不到区分前景

# PVSO 方案:
for each view_i:
    # 1. 将 3D 预测投影到 view_i 的 2D 图像
    mask_2d_pred = project_3d_to_2d(pred_3d_mask, view_i)

    # 2. 只在有目标物体的 view 中计算 loss
    if target_in_view(view_i):
        loss += DiceLoss(mask_2d_pred, mask_2d_gt)
    else:
        # 抑制: 无目标视图中预测应为全 0
        loss += suppression_loss(mask_2d_pred, zeros)
```

**效果**：mIoU 从 18.5% (最佳基线) → 39.9% (MVGGT)，困难样本更是从 8.1% → 24.4%。
