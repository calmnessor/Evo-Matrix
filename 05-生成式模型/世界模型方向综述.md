# 世界模型方向综述：从视频预测到物理推理

> World Models for Embodied AI — 让机器人"在脑中想象做动作的后果"，在行动之前先预测。本文为科研新手提供该方向的完整学术地图。

## 1. 定义与直觉

**一句话**：世界模型 = 一个可以预测"如果执行动作 A，世界会变成什么样"的神经网络。

**生活化类比**：你要穿过拥挤的走廊——你不是盲目地每走一步都实时反应，而是在脑中快速模拟："我从这个间隙挤过去，那个人会稍微侧身，然后我可以通过"。这种心理模拟 (mental simulation) 就是你大脑中的世界模型。机器人同样需要这种能力。

```
没有世界模型的机器人:
  观测 → [黑盒策略] → 动作 → 执行 → 看到结果 → 发现不对 → 已经晚了

有世界模型的机器人:
  观测 → [世界模型: 如果做 A 会怎样? 如果做 B 会怎样?]
       → 在想象中尝试多个方案
       → 选最好的方案 → 执行
       → (同时用实际结果更新世界模型)
```

### 为什么叫"世界"模型？

因为它的目标是建模 agent 所处环境的物理规律——物体如何运动、接触后如何反应、动作的长期后果。好的世界模型隐式编码了常识物理（重力、碰撞、摩擦、物体恒存性等）。

## 2. 为什么重要

| 维度 | 没有世界模型 | 有世界模型 |
|------|-----------|-----------|
| **样本效率** | 需要真机成千上万次尝试 | 在"想象中"低成本试错 |
| **安全性** | 做了才知道会不会撞 | 先模拟→安全动作再执行 |
| **长周期规划** | 无法评估 10 步后的结果 | 在潜空间中推演未来 |
| **反事实推理** | "如果刚才从左边抓会怎样?" 无法回答 | 可以回溯模拟 |
| **数据效率** | 每一步真机交互都很昂贵 | 世界模型可以脱离真机自训练 |
| **泛化** | 没见过 = 无法推理 | 可以从已知物理规律泛化 |

## 3. 技术演进时间线

```
前深度学习时代 (1950s-2010s): 基于物理方程
├─ 经典控制理论: 状态空间模型, Kalman Filter (1960)
├─ 物理引擎: MuJoCo, Bullet, ODE → 手工定义的"世界模型"
└─ 问题: 手工建模费时, 无法处理复杂场景

深度学习探索期 (2015-2020): 从像素学习
├─ 2015: [关键] 变分自编码器 (VAE) 成熟 → 学习紧凑状态表示
├─ 2018: World Models (Ha & Schmidhuber)
│        → 里程碑! VAE 编码 + RNN 预测 + 进化策略控制
│        → RNN 在 64-dim 潜空间中"做梦"训练
├─ 2018: PlaNet (Hafner et al.)
│        → RSSM (Recurrent State Space Model) 诞生
│        → 从像素学习动力学, MPC 规划
└─ 2019: Dreamer v1 → RSSM + Actor-Critic → 在潜空间 Imagination 中训练策略

像素级预测时代 (2020-2023): 视频预测+潜变量动力学
├─ 2021: Dreamer v2 → 离散潜变量 + KL balancing → 大幅提升稳定性
├─ 2022: Dreamer v3 → 固定超参, 适用各种领域 (游戏+机器人)
├─ 2022: IRIS → 离散自编码 + GPT → 可扩展的世界模型
├─ 2023: TWM (Transformer World Model) → 纯 Transformer 做世界模型
├─ 2023: UniSim → 大规模通用世界模型 (Google)
└─ 2023: GAIA-1 → 自动驾驶世界模型 (Wayve)

现代世界模型 (2024-2025): 视频生成+VLA融合
├─ 2024: SORA → 视频生成的巨大进步 → 启发世界模型 (OpenAI)
├─ 2024: Genie → 从互联网视频学习交互式世界模型 (Google DeepMind)
├─ 2024: Genie 2 → 从单张图片生成可交互的 3D 世界
├─ 2024: 扩散世界模型 → Diffusion 替代 RSSM
│        → 更好的长视频预测质量
├─ 2025: 多模态世界模型 → 视觉+语言+动作的联合预测
├─ 2025: π₀.₅+ego → 人类视频 → VLA 的"世界理解"涌现
└─ 2025: Cosmos (NVIDIA) → 物理世界的基础模型 (WPFM)
```

## 4. 方法分类学

```
世界模型
│
├── 路线 A: RSSM 系列 (Recurrent State Space Model)
│   思路: VAE 编码→RNN 动力→解码预测
│   代表: Dreamer v1/v2/v3, PlaNet
│   核心公式: p(s_{t+1}|s_t, a_t) 在潜空间 + p(o_t|s_t) 解码
│   优势: 长期 rollout 稳定, 样本效率极高
│   劣势: RNN 瓶颈, 难以并行化, 潜空间可解释性差
│   适用: RL 训练, 需要高样本效率的场景
│
├── 路线 B: Transformer 世界模型
│   思路: 用 Transformer 直接建模 (o_t, a_t) → o_{t+1}
│   代表: TWM, IRIS, STORM
│   优势: 可并行训练, 长程建模好, 与 LLM 生态兼容
│   劣势: 计算开销大, rollout 时自回归推理慢
│   适用: 大规模预训练, 多领域通用
│
├── 路线 C: 扩散世界模型
│   思路: 用扩散模型生成未来帧 → 视频预测质量极高
│   代表: Diffusion World Model, UniSim, Genie
│   优势: 生成质量最好, 多模态分布, 支持条件控制
│   劣势: 推理极慢 (多步去噪), 计算极其昂贵
│   适用: 离线规划, 高质量数据生成, 视频预测
│
├── 路线 D: 游戏引擎式 (Game-Engine-Like)
│   思路: 不是从零预测, 而是学习渲染引擎参数
│   代表: 3D Gaussian Splatting + 动力学, 隐式神经表示
│   优势: 物理一致性更好, 3D 结构可解释
│   劣势: 依赖几何重建质量, 泛化有限
│   适用: 已知物理规律的精确仿真
│
└── 路线 E: 基础世界模型 (World Foundation Model)
    思路: 在超大规模数据上预训练通用世界动力学
    代表: Cosmos (NVIDIA), UniSim (Google), Genie (DeepMind)
    优势: 跨场景泛化, 从视频数据学习, zero-shot
    劣势: 训练成本天文数字, 评估困难, 早期
    适用: 作为下游机器人任务的预训练基础
```

## 6. 当前 SOTA 与趋势 (2025)

### 已解决的问题
- ✅ 在已知任务上的样本高效 RL → Dreamer v3 只需几百分之一的样本
- ✅ 短期 (1-3 秒) 视觉预测质量 → 扩散模型已能做到较逼真

### 正在突破的方向
- 🔥 **视频生成即世界模型** (SORA/Cosmos/Genie)：视频生成质量正在逼近"照片级"→ 作为世界模型使用
- 🔥 **大规模预训练** (Cosmos)：在 2000 万小时视频上预训练物理基础模型
- 🔥 **3D 世界模型** (Genie 2)：不只预测 2D 图像，而是可交互的 3D 环境
- 🔥 **VLA + 世界模型融合**：π₀.₅+ego 显示人类视频 → VLA 的内部表示有"世界理解"涌现
- 🔥 **潜空间规划** (Dreamer 后续)：在紧凑的潜空间做规划，比像素空间快 100×

### 三大趋势
1. **从任务特定到通用**：不在单个任务上训练，而在物理世界规模的视频数据上预训练
2. **从 2D 到 3D**：世界模型开始融入 3D 结构（Gaussian Splatting, NeRF）
3. **从独立到融合**：世界模型逐渐成为 VLA 架构的一部分而非独立模块

## 7. 关键挑战与开放问题

| 挑战 | 现状 | 可能突破方向 |
|------|------|------------|
| **长期一致性** | >10 秒预测迅速退化 | 分层预测 (高层语义 + 底层细节) |
| **物理精度** | 视频生成好看但不精确 | 3D 约束, 物理 loss, 力觉反馈 |
| **因果理解** | 学的是相关性而非因果 | 因果关系学习 + 干预实验 |
| **训练成本** | 基础世界模型需要数千 GPU | 高效架构 + 蒸馏 + 知识共享 |
| **评估方法** | 没有公认的世界模型评估标准 | 标准化 benchmark 建设 |
| **不确定性和多模态** | 未来有多种可能，模型常只捕捉一种 | 扩散/Flow + 更强的概率建模 |
| **与 VLA 集成** | 世界模型和 VLA 分开训练 | VLA 内部隐式学习世界模型 (π₀方向) |
| **物体级理解** | 不能分离和追踪单个物体 | 物体中心的世界模型 (slot attention) |

## 8. 与其它方向的关系

```
                    世界模型
                       │
          ┌────────────┼────────────┐
          ↓            ↓            ↓
    [潜空间想象]  [视频预测]    [物理仿真]
          │            │            │
          └────────────┼────────────┘
                       ↓
              ┌─────────────────┐
              │      VLA        │
              │  (决策+执行)    │
              └────────┬────────┘
                       │
          ┌────────────┼────────────┐
          ↓            ↓            ↓
     [Affordance]   [Grasp]    [Motion]
      "哪能做动作"   "怎么抓"    "怎么移动"
          │            │            │
          └────────────┼────────────┘
                       ↓
              真实世界执行 → 反馈 → 更新世界模型
```

- **世界模型 → VLA**: 世界模型为 VLA 提供"想象能力"——在规划时模拟不同动作的后果
- **世界模型 ← Affordance**: 世界模型预测"做动作 X 后物体会怎样"→ 自动生成 affordance 训练标签
- **世界模型 ← 仿真**: 仿真器是完美的世界模型（但需要手工建模），学习的世界模型追求同等精度但无需手工建模
- **世界模型 → RL**: Dreamer 证明世界模型可以替代真实环境做 RL，把样本效率提升 100-1000×

## 10. 新手学习路径

### 第 1 周：建立核心概念
- Day 1-2: 读 "World Models" (2018), 理解 VAE+MDN-RNN 的基本架构
- Day 3-4: 读 PlaNet, 理解 RSSM 和潜空间规划的直觉
- Day 5-7: 在 CarRacing 环境上跑 Dreamer v2 代码

### 第 2 周：理解潜空间动力学
- Day 1-3: 读 Dreamer v3, 理解固定超参的设计
- Day 4-5: 在 DMControl 上跑 Dreamer v3
- Day 6-7: 理解 reward prediction 和值函数如何从世界模型中学习

### 第 3 周：跟上现代方法
- Day 1-3: 读 TWM, 理解 Transformer 世界模型
- Day 4-5: 读 Genie, 理解从视频学习可交互世界
- Day 6-7: 读 Cosmos 论文, 理解基础世界模型的 scaling

- Day 1-3: 在自己的机器人任务上训练 Dreamer v3
