# 生成式模型 — 3D 重建与场景生成

> 从多张 2D 图像直接推理完整 3D 世界——具身智能的"空间感知引擎"。

## 方向定位

```
具身智能的感知金字塔:
┌──────────────────────────────────────┐
│  VLA (决策行动)         ← 最上层     │
├──────────────────────────────────────┤
│  Affordance / Grasp (任务理解)       │
├──────────────────────────────────────┤
│  生成式模型 (3D 空间感知) ← 基础层   │
└──────────────────────────────────────┘
```

## 核心能力

| 能力 | 描述 | 代表方法 |
|------|------|---------|
| 相机位姿估计 | 从图片推断拍摄位置 | VGGT, DUSt3R |
| 深度估计 | 每像素的 3D 距离 | VGGT, DepthAnything |
| 3D 点云重建 | 稀疏视图 → 稠密点云 | VGGT, COLMAP |
| 新视角合成 | 从已知视角渲染新视角 | 3DGS, NeRF, ZipNeRF |
| 语言→3D 定位 | 自然语言指代 3D 目标 | MVGGT, LERF |

## 学习路径

```
第 1 周: 几何基础
  ├─ 相机模型 (内参/外参、投影)
  ├─ 多视图几何 (对极几何、三角化)
  └─ 读: COLMAP 论文

第 2 周: 神经表示
  ├─ NeRF 原理
  ├─ 3D Gaussian Splatting
  └─ 读: NeRF + 3DGS 论文

第 3 周: 前馈式方法
  ├─ DUSt3R / MASt3R
  ├─ VGGT 精读
  └─ 跑通 VGGT demo

第 4 周: 语言 + 3D
  ├─ MVGGT 精读
  ├─ LERF / OpenNeRF
  └─ 思考: 如何把 3D 重建用到自己的研究？
```
