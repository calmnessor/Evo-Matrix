# Hi Robot: Open-Ended Instruction Following with Hierarchical Vision-Language-Action Models

> 让机器人学会"自言自语"——用 System-1 + System-2 认知架构处理复杂开放式指令。

## 论文信息

- **标题**: Hi Robot: Open-Ended Instruction Following with Hierarchical Vision-Language-Action Models
- **日期**: 2025 年 2 月
- **arXiv**: [2502.19417](https://arxiv.org/abs/2502.19417)
- **机构**: Physical Intelligence
- **发表**: ICML 2025

## 一句话总结

Hi Robot 借鉴 Kahneman 的"双系统"认知理论，用 **System-2 (VLM 高层推理)** 将复杂任务拆解为原子指令，再由 **System-1 (VLA 底层执行)** 生成动作，中间通过"自言自语"机制实现实时推理和纠错。

## 核心动机

### 扁平 VLA 的局限

标准 VLA (如 π₀, OpenVLA) 直接"指令→动作"。这在简单任务上有效，但面对复杂场景就暴露问题：

```
用户: "帮我做一个三明治，但不要加生菜，因为我不爱吃生菜。"

扁平 VLA:
  理解"做三明治" → 但"不加生菜"是什么？生菜在哪？为什么不爱吃？
  → 迷失在多层次的语义中 → 输出错误动作

Hi Robot:
  System-2: "用户要三明治，不加生菜。三明治通常有面包/肉/生菜/酱。
            用户明确说了不要生菜。那我需要的材料是面包/肉/酱。
            先拿面包，再放肉..."
  System-1: 听 System-2 的每个简单指令 → 执行具体动作
```

## 架构：双系统设计

```
用户输入: "清理桌面，但小心不要打碎杯子"
    ↓
┌──────────────────────────────────────┐
│ System 2: 高层推理 (VLM)             │
│ - 频率: 低频 (~1Hz 或事件触发)       │
│ - 功能: 解析指令、分解任务、         │
│   处理反馈、生成子任务序列           │
│ - 输出: 原子指令序列                 │
│   "1. 识别杯子位置"                  │
│   "2. 把杯子移到安全区域"            │
│   "3. 清理桌面其余物品"              │
└──────────────────┬───────────────────┘
                   ↓
┌──────────────────────────────────────┐
│ System 1: 底层执行 (VLA = π₀)        │
│ - 频率: 高频 (50Hz 动作)             │
│ - 功能: 接收原子指令 → 生成动作块    │
│ - 输出: 连续动作序列                 │
│                                     │
│ "把杯子移到安全区域" → [dx,dy,dz,...]│
└──────────────────────────────────────┘
                   ↓
              机械臂执行
```

### System-2 的"自言自语"机制

System-2 不只是"翻译"，而是模拟人类的推理过程：

```
用户: "冰箱里有牛奶吗？如果有的话帮我倒一杯"

System-2 自言自语:
  "让我分析一下：
   1. 用户想知道冰箱里有没有牛奶
   2. 我需要先打开冰箱看一看
   3. 用视觉确认是否有牛奶盒
   4. 如果有：打开牛奶盒，倒入杯子
   5. 如果没有：告知用户没有"
  → 输出子任务序列
  → 执行过程中持续监控状态
  → 如有异常 (杯子打翻了) → 重新推理 → 生成恢复方案
```

### 合成数据：解决"谁来对话"的问题

Hi Robot 的一个关键创新是**用合成数据训练 System-2**：

```
原始数据: (观测序列, 动作序列) ← 来自遥操作演示

合成过程:
  VLM 看整个 episode → 生成"假设的用户指令"
  "如果用户当时说'帮我把桌上的垃圾扔掉'，这个轨迹就是合理的"
  
  VLM 看每一步 → 生成"假设的用户反馈"
  "如果此时用户说'等等，那个不是垃圾!'，agent 应该停止并确认"
  
→ 大规模(指令, 反馈, 正确行为)数据 → 训练 System-2
```

## 关键特性

### 实时用户交互闭环

系统执行过程中持续监听：

```
System-1: 正在抓杯子...
用户打断: "不对，我要那个红色的杯子!"
    ↓
System-2: 重新分析 → "红色杯子在左边"
    ↓
System-1: 换目标 → 抓红色杯子
```

### 跨平台验证

| 平台 | 任务示例 |
|------|---------|
| 单臂 (Franka) | 清理桌面、整理餐具 |
| 双臂 (ALOHA 式) | 制作三明治、折叠衣物 |
| 双臂+移动底盘 | 超市购物、多房间整理 |

## 关键结果

### 指令跟随准确率

| 方法 | 准确率 |
|------|--------|
| GPT-4o (纯语言) | ~35% |
| 扁平 VLA (无分层) | ~55% |
| **Hi Robot** | **~78%** (比 GPT-4o 高 40%+) |

### 复杂任务成功率

- **清理桌面** (含"小心不要打碎杯子"等约束)：~75%
- **制作三明治** (8 步骤，含修正)：~65%
- **超市购物** (多房间导航+操作)：~50%

### 消融实验

- 去掉 System-2 → 只剩 System-1：成功率下降 ~30%
- 去掉合成数据 → 只用少量人工标注：成功率下降 ~20%
- 去掉实时反馈 → 只初始指令执行：处理异常的能力大幅下降

## 贡献与影响

1. **分层 VLA 可行性验证**：System-1/2 设计在实际机器人上可行且有效
2. **合成数据方案**：用 VLM 自动生成训练数据，绕过了交互数据稀缺的瓶颈
3. **开放式指令处理**：首次展示 VLA 能处理含约束、偏好、条件判断的复杂指令
4. **实时交互**：用户在任务中可随时纠正，"人在回路"变得更自然

## 局限

- 两个大模型 (System-2 VLM + System-1 VLA) → 计算开销大
- System-2 推理延迟 (~1s) 在某些场景下可能太慢
- 合成数据生成的指令质量依赖 VLM 能力
- 尚未处理极长周期 (>30 分钟) 的任务
