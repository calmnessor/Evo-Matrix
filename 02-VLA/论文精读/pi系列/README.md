## 技术演进脉络

```
阶段 1: 基础 VLA (π₀)
  Flow Matching + MoE → 首次统一多具身形态的通用策略

阶段 2: 效率提升 (π₀-FAST, RTC)
  动作 token 压缩 + 实时推理算法 → 更快训练、更低延迟

阶段 3: 泛化突破 (π₀.₅, π₀.₅-KI)
  异构数据协同训练 + 知识绝缘 → 开放世界零样本泛化

阶段 4: 自进化 (π*₀.₆, π₀.₅+ego)
  RL 从经验中学习 + 人类视频迁移 → 策略持续自我改进
```

## 核心技术主线

1. **Flow Matching 动作生成**：替代扩散/VAE/离散 token，成为 PI 的技术标志
2. **MoE 架构**：VLM expert + Action expert 分离 → 保护语义 + 高效控制
3. **大规模预训练**：10K+ 小时机器人数据 → 泛化的基础
4. **知识绝缘 (KI)**：阻断梯度污染 → 同时实现快训练、快推理、强泛化
5. **RECAP RL**：Advantage Conditioning → VLA 的第一套通用 RL 方案

3. 然后 **π*₀.₆** — 理解 VLA 如何从经验中自进化
4. 按兴趣选读其余论文
