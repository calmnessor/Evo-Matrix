## 摘要翻译

### 英文摘要
In order for robots to be useful, they must perform practically relevant tasks in the real world, outside of the lab. While vision-language-action (VLA) models have demonstrated impressive results for end-to-end robot control, it remains an open question how far such models can generalize in the wild. We describe π₀.₅, a new model based on π₀ that uses co-training on heterogeneous tasks to enable broad generalization. π₀.₅ uses data from multiple robots, high-level semantic prediction, web data, and other sources to enable broadly generalizable real-world robotic manipulation. Our system uses a combination of co-training and hybrid multi-modal examples that combine image observations, language commands, object detections, semantic subtask prediction, and low-level actions. Our experiments show that this kind of knowledge transfer is essential for effective generalization, and we demonstrate for the first time that an end-to-end learning-enabled robotic system can perform long-horizon and dexterous manipulation skills, such as cleaning a kitchen or bedroom, in entirely new homes.

### 中文翻译
为了使机器人真正有用，它们必须在实验室之外的真实世界中执行具有实际意义的任务。尽管视觉-语言-动作（VLA）模型在端到端机器人控制方面取得了令人印象深刻的成果，但这类模型在野外环境中的泛化极限仍然是一个悬而未决的问题。我们描述了 π₀.₅，一个基于 π₀ 的新模型，它通过在异构任务上的协同训练来实现广泛的泛化。π₀.₅ 使用来自多种机器人、高层语义预测、网络数据和其他来源的数据，使真实世界的机器人操作具有广泛的可泛化性。我们的系统结合了协同训练和混合多模态样本，将图像观察、语言命令、物体检测、语义子任务预测和底层动作融为一体。实验表明，这种知识迁移对有效泛化至关重要，我们首次展示了一个端到端学习驱动的机器人系统能够在全新的家庭中执行长时间跨度且灵巧的操作技能，例如清洁厨房或卧室。

### 核心要点提炼
- **研究背景**：VLA 模型展示了强大的端到端控制能力，但能否泛化到全新环境（open-world）仍是未知
- **研究动机**：人类可以从多种经验来源中学习泛化（直接经验、他人经验、书本知识等），机器人也应如此
- **核心方法**：异构数据源的协同训练（co-training）——包括多种机器人数据、高层子任务预测、网络多模态数据、语言指令等
- **主要结果**：首次实现端到端 VLA 在全新家庭中执行长时间（10-15分钟）灵巧操作任务，如清洁厨房和卧室
- **研究意义**：证明了通过多源异构数据协同训练，VLA 可以实现超出训练数据分布的 open-world 泛化

## 研究背景与动机

### 领域现状
- VLA 模型（如 π₀、RT-2、OpenVLA）在端到端机器人控制上取得了令人印象深刻的成果
- 然而，大多数 VLA 模型仅在接近训练分布的环境中评估，泛化能力有限
- 实现 open-world 泛化（在完全未见过的环境中执行复杂任务）仍是机器人学习的核心挑战
- 简单任务（如抓取、开门）可以通过扩大数据分布来泛化，但复杂的长时间跨度任务（如清理厨房）无法靠暴力扩展数据解决

### 现有方法的局限性
1. **数据覆盖的局限性**：为复杂任务（如清理厨房）收集覆盖所有可能场景的数据完全不现实
2. **知识来源单一**：大多数 VLA 仅使用来自同一机器人平台的操作数据训练
3. **缺乏语义理解**：需要理解"哪个是晾碗架"、"哪个抽屉应该打开"等需要语义知识才能泛化

### 研究动机
类比人类的泛化能力：人类可以从多种来源获取知识——直接经验、他人经验、口头指令、书本知识。机器人学习系统应同样能够从异构数据源中迁移知识：
- 其他机器人的经验（cross-embodiment transfer）
- 高层语义推理（high-level subtask prediction）
- 网络知识（web data: captioning, VQA, object localization）
- 语言指导（verbal instructions from human supervisors）

## 研究问题

### 核心研究问题
如何设计一个 VLA 的训练配方，使其能够通过多源异构数据的协同训练，在全新的真实世界环境中（如未见过的新家）执行复杂的长时间跨度灵巧操作任务？

## 方法概述

### 核心思想
π₀.₅ 的核心思想是 **异构数据源的协同训练（co-training）**——通过将不同来源的数据（机器人动作数据、高层语义预测、网络多模态数据、语言指令等）统一投射到 VLA 的序列建模框架中，使模型能够从多种知识来源中学习，从而实现对全新环境的泛化。

架构上采用**层级推理**：先预测高层语义子任务（如"拿起盘子"），再基于子任务预测底层动作 chunk。同一模型同时执行高层和底层推理。

### 方法框架

#### 整体架构

![[final_fig2.pdf|800]]

> 图1：π₀.₅ 模型概览。系统整合了多模态数据源：子任务命令、物体检测、多模态网络数据、多种机器人数据。通过层级推理（高层语言预测 → 底层动作专家），π₀.₅ 可以在全新家庭中开箱即用地执行清洁任务。

![[Figure_3.pdf|800]]

> 图3（详情）：训练分为两阶段。**预训练阶段**：将所有数据源用离散 token 表示（FAST tokenizer），训练模型进行 next-token prediction。**后训练阶段**：特化到移动操作场景，加入 flow matching 动作专家生成连续动作。推理时先预测高层子任务（文本），再基于子任务预测底层动作。

**两阶段训练**：

1. **预训练阶段（Pre-training）**：280k 步
   - 使用离散 token 表示所有输出（文本 + FAST 动作 token）
   - 标准自回归 next-token prediction
   - 覆盖五种数据源（MM + ME + CE + HL + WD）

2. **后训练阶段（Post-training）**：80k 步
   - 特化到移动操作 + 多样环境
   - 添加 flow matching 动作专家（300M 参数，随机初始化）
   - 同时训练：next-token prediction（保留文本能力）+ flow matching（动作生成）
   - 数据：MM + ME + WD + HL（对应部分）+ VI（语言指令）

#### 各模块详细说明

**模块1：数据源（Data Sources）**

![[data_vs_generalization.png|800]]

> 图4：预训练和后训练的数据源示例。

五种数据源：

| 数据源 | 缩写 | 描述 | 量级 |
|--------|------|------|------|
| 多样移动操作数据 | MM | 约400小时，约100个家庭 | 中等 |
| 多样环境非移动机器人 | ME | 各类家庭中的固定臂数据 | 大 |
| 跨形态实验室数据 | CE | 实验室环境、多种任务和机器人 | 大 |
| 高层子任务预测 | HL | 手动标注的子任务标签 + bounding boxes | 中 |
| 多模态网络数据 | WD | Captioning, VQA, Object Localization | 极大 |

后训练阶段额外加入：

| 语言指令 | VI | 专家用语言"遥操作"机器人，示范子任务选择 | 小（占HL的11%） |

> 关键：97.6% 的训练样本不来自移动操作器执行家务任务，而是来自其他数据源。

**模块2：层级推理架构**
- **高层推理（High-Level Inference）**：低频运行，给定高层指令（如"clean the bedroom"），输出语义子任务（如"pick up pillow"），类似于 chain-of-thought
- **底层推理（Low-Level Inference）**：50Hz 运行，给定子任务标签，输出动作 chunk
- **统一架构**：同一模型执行两级推理，高层输出文本 token，底层输出动作 token（由 action expert 处理）

**模块3：机器人硬件**
- 双臂移动操作器：2×6 DoF 臂 + 平行爪夹爪，3 DoF 全向底座，1-2 DoF 升降机构
- 总计 18-19 DoF 状态和动作空间
- 4 个摄像头（前后 + 双腕）
- 控制频率：50 Hz（动作 chunking）
- 控制器：简单 PD 追踪，无轨迹规划，端到端

### 训练配方详解

**预训练阶段**：
- Backbone: PaliGemma (400M SigLIP + Gemma 2.6B)
- 所有输出使用离散 token（FAST 动作 tokenizer）
- 标准自回归 next-token prediction
- 双向注意力机制
- 280k 梯度步

**后训练阶段**：
- 添加 flow matching 动作专家（300M，随机初始化）
- 混合训练目标：next-token prediction + flow matching
- 损失权重 β = 10.0
- 80k 梯度步
- 只使用成功的 episodes + 过滤长的 episodes

## 实验结果

### 实验目标
验证 π₀.₅ 在全新家庭环境中的泛化能力，并系统回答五个核心研究问题：
1. 能否泛化到全新的真实家庭？
2. 泛化如何随训练环境数量变化？
3. 各协同训练成分的贡献？
4. 与 π₀ 等 VLA 相比如何？
5. 高层推理的重要性？

### 主要结果

#### 结果1：泛化到真实家庭

在 3 个真实家庭（3 个厨房 + 3 个卧室）中评估 `dishes in sink`、`items in drawer`、`laundry basket` 三个任务。π₀.₅ 能够一致地完成这些多阶段任务（每个任务约 2-5 分钟）。

关键发现：在模拟家庭中的表现与真实家庭一致，验证了模拟评估的有效性。

#### 结果2：泛化随环境数量扩展

![[env_scaling.png|800]]

> 图8：随训练地点数量增加的性能扩展。在 4 个测试任务上的平均性能随训练环境数量（3→12→22→53→82→104）稳步提升。104 个地点的模型达到与在测试家庭上直接训练的模型（绿色虚线）可比的性能，充分证明了协同训练的泛化效果。

![[env_scaling_results0.png|800]]

> 图9：语言跟随能力。随训练地点增加，分布内（ID）和分布外（OOD）物体的语言跟随率和成功率均稳步提升。OOD 需要更强的语义泛化。

#### 结果3：协同训练成分的消融

![[overall_breakdown.png|800]]

> 图10：训练配方消融（模拟家庭端到端评估）。

![[language_vs_model.png|800]]

> 图11：训练配方消融（语言跟随）。

关键结论：
- **移除跨形态数据（ME 或 CE）**：性能显著下降 → cross-embodiment transfer 至关重要
- **移除两者（no ME + CE）**：性能进一步恶化
- **移除 Web Data（no WD）**：端到端任务评估中不明显，但在 OOD 语言跟随上显著变差 → WD 对语义泛化关键
- **未使用协同训练的基线**（只训练移动操作数据）：性能远差于完整配方

#### 结果4：与 π₀ 对比

π₀.₅ 显著优于 π₀ 和增强版 π₀-FAST+Flow：
- π₀.₅ 额外使用 HL + WD 数据 + 混合训练过程
- 即使 π₀ 获得更长训练（300k 步），π₀.₅ 仍明显更优
- 使用 FAST token 训练比纯扩散训练更有效（收敛更快）

#### 结果5：高层推理的重要性

![[HL_breakdowns.png|800]]

> 图13：高层推理过程评估。

各方法对比：
- **π₀.₅（完整）**：最佳
- **implicit HL**（训练时包含 HL 但在推理时不使用显式 HL）：第二好，说明即使隐式的高层知识也对性能有巨大帮助
- **no HL**（训练中无 HL）：显著下降
- **no VI**（无语言指令数据）：显著下降（VI 仅占 11% 的 HL 数据但影响巨大）
- **no WD**（无网络数据）：显著下降（WD 对高层策略的语义理解至关重要）
- **GPT-4 as HL**：最差——通用 VLM 未在机器人数据上微调，无法替代训练的高层策略

惊人发现：π₀.₅ 的完整模型甚至**略优于人类 oracle 作为高层策略**——说明 co-training 不仅补偿了人类能做到的，还能在某些方面超越。

## 深度分析

### 研究价值评估

#### 理论贡献
- **贡献1：异构数据协同训练的泛化理论**
  - 创新点：首次系统性地证明多种异构数据源（机器人、网络、语言、检测）可通过协同训练产生 open-world 泛化
  - 学术价值：为 VLA 的泛化能力提供了新的理论框架和数据配方
  - 影响范围：VLA、机器人学习、迁移学习、多模态学习

- **贡献2：数据源重要性的量化分析**
  - 创新点：通过系统的消融实验量化了每种数据源对泛化的贡献
  - 学术价值：为未来 VLA 数据收集策略提供了实践指南

#### 实际应用价值
- **应用场景**：家用服务机器人、通用操作机器人
  - 优势：只需约 400 小时的移动操作数据 + 大量其他低成本数据源，即可实现 open-world 泛化
  - 潜在影响：大幅降低部署家用机器人的数据采集成本

#### 领域影响
- **短期**：为 VLA 训练提供了经过验证的多源数据配方
- **中期**："只需少量目标任务数据 + 大量辅助数据"的范式可能成为标准
- **长期**：真正实现泛化到任意新环境的通用机器人

### 方法优势详解

1. **异构数据源的统一框架**：将所有数据（动作、文本、检测、图像）统一到 VLA 的序列建模中
2. **简单的层级推理**：不需要分开的高层和底层模型，同一个模型同时做两件事
3. **语言指令（VI）作为监督**：人类可以通过语言而非遥操作来"训练"机器人选择正确子任务——这是一种全新且高效的监督范式
4. **数据效率**：97.6% 的训练数据不来自目标平台，却实现了强大的泛化

### 局限性分析

1. **仍有失败情况**：
   - 不熟悉的抽屉把手或难以打开的柜门
   - 部分可观测性（臂遮挡 spill）
   - 高层推理容易被干扰（如反复开关抽屉）
2. **Prompt 复杂度有限**：只能处理相对简单的指令
3. **上下文长度有限**：缺乏跨房间导航或记忆物体位置的丰富上下文
4. **未探索更多数据源**：存在更多可能的辅助数据源

### 适用性与场景分析

**适用场景**：
- 家用机器人在新环境中的部署
- 目标平台数据获取昂贵但可从其他平台获取大量数据的场景
- 需要语义理解和物理操作结合的复杂长序列任务

**不适用场景**：
- 极简数据预算（仍需要至少约 400 小时目标平台数据）
- 实时性要求极高的场景（层级推理增加延迟）

## 技术路线定位

### 所属技术路线
本文属于 **VLA open-world 泛化** 技术路线，核心特点是：
- 异构数据源的协同训练而非单纯扩展单一数据源
- 层级推理实现长时间跨度任务
- 97.6% 训练数据来自辅助源

### 技术路线发展历程
```
RT-2 (VLA 诞生) → π₀ (flow matching VLA) → π₀.₅ (co-training 泛化) → π₀.₆ (更大模型) → π*₀.₆ (RL 自我改进)
```

### 本文在技术路线中的位置
- **承上**：继承了 π₀ 的 VLA 架构和 flow matching 方法
- **启下**：为 π₀.₆ 和 π*₀.₆ 提供了 co-training 基础和数据配方
- **关键节点**：首次证明 VLA 可以实现 open-world 泛化到全新家庭

### 重点关注

- **异构数据协同训练是泛化的关键**：这是论文最核心的信息，97.6% 非目标任务数据创造了强大的泛化
- **语言指令（VI）作为新监督范式**：仅占 11% 数据但产生巨大影响，值得深入研究
- **层级推理 vs 隐式 HL**：显式 HL 比隐式 HL 好但差距不大，说明 co-training 本身的贡献可能比架构更重要
- **Web Data 的语义作用**：对 OOD 物体的语言理解和语言跟随至关重要
- **训练环境数量与泛化的关系**：数据点提供了真实的 scaling curve

> - 高层推理可被干扰（如反复开关抽屉），存在稳定性问题
> - 评估主要限于厨房和卧室清洁场景
