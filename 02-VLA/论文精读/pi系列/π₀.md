# π₀: A Vision-Language-Action Flow Model for General Robot Control

> Physical Intelligence 的开山之作——首次提出基于 Flow Matching 的 VLA 模型，在 7 种机器人形态上统一控制。

## 论文信息

- **标题**: π₀: A Vision-Language-Action Flow Model for General Robot Control
- **日期**: 2024 年 10 月
- **arXiv**: [2410.24164](https://arxiv.org/abs/2410.24164)
- **机构**: Physical Intelligence
- **发表**: RSS 2025

## 一句话总结

π₀ 是第一个大规模机器人基础模型，用 **Flow Matching** 替代扩散/VAE/离散 token 来生成连续动作，结合 **MoE** 架构分离视觉语言理解和动作控制，在 7 种不同机器人形态的 68 个任务上预训练，统一了"通用语义理解"和"精细运动控制"。

## 核心动机

### VLA 的根本矛盾

```
VLM (通用):       理解复杂语言指令、常识推理 → 强大但输出"文字"
Robot Policy (专用): 输出高频连续动作 → 精确但与语言脱节

矛盾: 如何在同一个模型中融合"理解和生成 token 的能力"与"输出精确连续动作的能力"？
```

### 为什么不用现有方案？

| 方案 | 问题 |
|------|------|
| RT-2 式离散 token | 256 bins × 7 dims → 精度损失，bin 数指数爆炸 |
| Diffusion Policy | 推理慢（多步去噪），不适合大规模 VLM backbone |
| ACT 式 CVAE | VAE prior 对复杂分布欠拟合 |

**π₀ 的答案**：**Flow Matching** —— 一个更灵活、更快的连续生成框架。

## 架构

### 整体设计：稀疏 MoE

```
                    输入
                      ↓
            ┌─────────┴─────────┐
            ↓                   ↓
    VLM Expert                Action Expert
    (PaliGemma 3B)            (~300M)
    - 视觉理解                 - 本体感知状态
    - 语言理解                 - 动作序列
    - 高层语义推理             - Flow Matching 去噪
            ↓                   ↓
            └─────────┬─────────┘
                      ↓
              Attention Masking
          (Action expert attends to VLM, not vice versa)
                      ↓
                动作输出 (连续，50Hz)
```

### VLM Expert (PaliGemma 3B)

- 预训练 VLM，负责处理图像和语言
- 保持预训练权重的大部分完整性
- 输出语义丰富的特征表示
- 处理速度较低 (~3-5 Hz) 的视觉-语言理解

### Action Expert (~300M)

- 从零训练的 Transformer
- 输入：本体感知 (关节角/末端位姿) + VLM 特征 + 噪声动作
- 输出：Flow Matching 向量场 → 沿向量场积分 → 干净动作序列
- 支持 50Hz 高频控制

### 关键设计：Attention Masking

```
VLM Expert: 可以看到图像、文本、自己的输出
Action Expert: 可以看到 VLM Expert 的输出 + 自己的输入
               但不能反向传播梯度到 VLM Expert (知识绝缘的雏形!)
```

这保证了 VLM 不会因为动作训练的梯度而"遗忘"语言理解能力。

## Flow Matching 动作生成

### 与扩散模型的对比

| | DDPM (扩散策略) | Flow Matching (π₀) |
|------|------|------|
| 训练目标 | 预测噪声 ε | 预测向量场 v |
| 前向过程 | 加噪声 | 线性插值 x_t = (1-t)x_0 + tε |
| 反向过程 | 逐步去噪 | 沿向量场 ODE 积分 |
| 推理速度 | 10-100 步 | 5-10 步 (更快) |
| 灵活性 | 固定于 Gaussian prior | 可选任意 prior |

### Flow Matching 数学

**训练**：在干净动作 $x_0$ 和纯噪声 $x_1 = \epsilon$ 之间做线性插值：

$$x_t = (1-t) \cdot x_0 + t \cdot \epsilon$$

目标向量场（真实梯度方向）：
$$u_t(x_t|x_0) = \epsilon - x_0$$

模型预测向量场 $v_\theta(x_t, t, c)$，训练 loss：
$$\mathcal{L} = \mathbb{E}_{t, x_0, \epsilon} \left[ \| v_\theta(x_t, t, c) - (\epsilon - x_0) \|^2 \right]$$

**推理**：从 $t=1$ (纯噪声) 开始，沿预测向量场积分：

$$\frac{dx}{dt} = v_\theta(x_t, t, c)$$

$$\hat{x}_0 = x_1 + \int_1^0 v_\theta(x_\tau, \tau, c) \, d\tau$$

可以用 Euler 或 RK4 等 ODE solver，5-10 步足够。

### 为什么 Flow Matching 更好？

1. **灵活的 prior**：不限于 Gaussian，可以用任务相关的分布
2. **更直的路径**：线性插值=最优传输，比扩散的随机游走更短
3. **更少步骤**：路径更直=更少积分步骤=更快推理
4. **统一框架**：扩散 (VE/VP) 是 Flow Matching 的特例

## 训练方案

### 两阶段训练

```
阶段 1: 大规模预训练
  - 10,000+ 小时机器人数据
  - 7 种机器人形态 (单臂/双臂/移动)
  - 68 个任务
  - 包含 OXE、DROID、Bridge 等开源数据集
  - 目标: 学到通用的视觉-语言-动作表示

阶段 2: 后训练 (Post-training / Fine-tuning)
  - 高质量特定任务数据
  - 少量数据 (每任务数百条)
  - 目标: 适应特定任务的精细动作
```

### 数据组成

| 数据来源 | 类型 | 规模 |
|---------|------|------|
| PI 自采 | 移动操作、双臂、桌面 | ~数千小时 |
| OXE | 多实验室联合 | ~1M 轨迹 |
| DROID | 跨校园泛化 | ~100K 轨迹 |
| Bridge v2 | 桌面操作 | ~60K 轨迹 |

### 跨具身形态 (Cross-Embodiment) 训练

π₀ 统一训练在不同机器人上的数据：
- **单臂**：Franka, UR5, WidowX
- **双臂**：ALOHA 式双臂桌面操作
- **移动操作**：移动底盘 + 臂 (Hello Stretch 等)

## 关键结果

### 灵巧操作能力

| 任务 | 成功率 | 说明 |
|------|--------|------|
| 叠衣服 (Laundry Folding) | ~70% | 长周期精细任务 |
| 清理桌面 (Table Bussing) | ~85% | 多物体识别+操作 |
| 组装纸盒 (Box Assembly) | ~65% | 需要精确空间推理 |
| 购物打包 (Bag Packing) | ~80% | 多步骤顺序操作 |

### 泛化能力

- 在预训练未见过的物体上保持良好表现
- 对光照变化和背景变化鲁棒
- 能理解复杂的自然语言指令（非模板化）

## 贡献与影响

1. **Flow Matching for Robotics**: 首次大规模验证 Flow Matching 在机器人控制中的优势
2. **MoE for VLA**: 分离语义理解和动作控制，成为后续 PI 系列的标准架构
3. **Cross-Embodiment 预训练**: 证明多机器人联合训练优于单机器人训练
4. **10K 小时规模**: 证明了"机器人数据 scaling"的可行性

## 局限

- 推理延迟仍然较高 (VLM 3B + Action Expert 300M)
- Flow Matching 的理论优势在实际中不一定完全兑现
- 需要大量高质量数据（10K+ 小时）
- 未开源模型权重

## 与后续工作的关系

- → π₀-FAST: 用离散 tokenizer 替代 Flow Matching，实现 5× 训练加速
- → Hi Robot: 在 π₀ 上方加分层推理
- → π₀.₅: 扩展数据多样性 → 开放世界泛化
- → π₀.₅-KI: 修复梯度干扰问题，"知识绝缘"概念正式提出
