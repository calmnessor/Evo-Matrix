# π₀.₅: A Vision-Language-Action Model with Open-World Generalization

> 当 VLA 走进陌生人的家——用异构协同训练实现开放世界零样本泛化。

## 论文信息

- **标题**: π₀.₅: a Vision-Language-Action Model with Open-World Generalization
- **日期**: 2025 年 4 月
- **arXiv**: [2504.16054](https://arxiv.org/abs/2504.16054)
- **机构**: Physical Intelligence
- **发表**: CoRL 2025 (PMLR 305:17-40)
- **开源**: [openpi](https://github.com/Physical-Intelligence/openpi)

## 一句话总结

π₀.₅ 通过**异构协同训练**（机器人数据 + 网络数据 + 语言指令数据 + 规划数据），让 VLA 首次实现在**从未见过的真实家庭环境**中完成 10-15 分钟的灵巧操作任务。

## 核心动机

### 从"见过才能做"到"没见过也能做"

π₀ 的局限：在 ~100 个家庭收集的 ~400 小时数据上训练，但评估时看到的是**同一个家庭的不同变体**——本质上仍在训练分布内。

π₀.₅ 的野心：让模型在**完全不同的新家庭**（不同城市、不同装修、不同物品）中也能正常运行。

```
π₀:  训练数据 = 家庭 A/B/C 的厨房 → 测试 = 家庭 A 的厨房（换个角度/物品）
π₀.₅: 训练数据 = 100 个家庭的厨房 → 测试 = 家庭 Z 的厨房（从未见过）
```

### 关键洞察：多样性即泛化

泛化能力的瓶颈不是"机器人数据不够"，而是"机器人数据**类型不够多**"——引入**非机器人数据**（网络图片、VQA、图像描述等）作为辅助训练信号，让 VLM 学到的视觉语义知识不退化。

## 架构：两阶段设计

```
阶段 1: 预训练 (Pre-training)
┌────────────────────────────────────────────┐
│  输入                                        │
│  ├─ 图像 (多视角)                            │
│  ├─ 语言指令                                 │
│  ├─ 本体感知 (关节角/末端位姿)               │
│  └─ 高层语义子任务标签                       │
│              ↓                               │
│  VLM Backbone (Gemma 2.6B)                  │
│  + FAST 离散动作 tokenizer                   │
│  → 自回归预测离散动作 token                  │
│                                              │
│  训练数据混合:                                │
│  ├─ 机器人遥操作 (400 hrs, ~100 homes)       │
│  ├─ 非移动机器人操作数据                     │
│  ├─ 多具身实验室数据                         │
│  ├─ 网络图文数据 (VQA, captioning)           │
│  └─ 语言指令跟随数据                         │
└────────────────────────────────────────────┘
                    ↓
阶段 2: 后训练 (Post-training)
┌────────────────────────────────────────────┐
│  在预训练基础上加入 Flow Matching 动作专家   │
│  → 从离散 token 升级到连续动作生成           │
│  → 提升精细操作的准确性                      │
└────────────────────────────────────────────┘
```

### "Think then Act" 推理流程

```
用户指令: "帮我把厨房台面擦干净"
    ↓
Step 1 — Think (高层语义推理):
  VLM 预测子任务序列:
  "1. 找到抹布"
  "2. 拿起抹布"
  "3. 移动到水槽边"
  "4. 弄湿抹布"
  "5. 擦拭台面"
    ↓
Step 2 — Act (底层动作生成):
  对每个子任务，Flow Matching 动作专家生成
  50Hz 连续动作块 → 50 步/秒执行
```

这种 "Think then Act" 的链式推理类似于 CoT，但每一步 Think 结果都条件化为下一步 Act 的输入，而不是无约束的自由推理。

## 训练数据：异构协同训练

### 数据组成

| 数据类型 | 内容 | 作用 |
|---------|------|------|
| **机器人遥操作** | ~400 小时移动操作，~100 个家庭 | 核心技能 learning |
| **非移动机器人数据** | 固定基座机器人操作 | 丰富操作模式 |
| **多具身实验室数据** | 不同机器人类型、任务 | 跨具身迁移 |
| **高层语义子任务标签** | 每段轨迹的语义子任务标注 | 教会 "Think" |
| **语言指令数据** | 人类自然语言指令 + 对应轨迹 | 指令跟随能力 |
| **多模态网络数据** | 图像描述、VQA、目标检测 | 视觉语义泛化 |

### 消融实验：每类数据都重要

| 移除的数据类型 | 性能影响 |
|-------------|---------|
| 移除跨具身数据 | 分布外泛化大幅下降 |
| 移除网络数据 | 未见过的物体泛化能力崩溃 |
| 移除语言指令数据 | 指令跟随准确率显著下降 |
| 只用机器人数据 | 开放世界泛化远不如完整混合 |

**关键**: 网络数据对物体泛化最重要——如果 VLM 从没见过 "意大利浓缩壶" 的图片，即使遥操作中有一个轨迹涉及它，VLA 看到也认不出来。

## 关键结果

### 开放世界泛化

在 **从未见过的真实家庭** 中测试：

| 任务 | 成功率 | 说明 |
|------|--------|------|
| 清理厨房 | ~72% | 10-15 分钟长周期任务 |
| 清理卧室 | ~68% | 多种物品类型 |
| 整理桌面 | ~75% | 多物体识别与操作 |

**核心发现**：用 ~100 个训练家庭的数据，性能接近**在测试家庭中直接训练**的模型——泛化几乎 "不付代价"。

### 与基线对比

| 方法 | 成功率 |
|------|--------|
| π₀ | ~35% (开放世界) |
| π₀ + 微调 | ~50% |
| π₀.₅ | **~72%** |

### 步态 (Gait) 分析

π₀.₅ 在执行过程中表现出 **"聪明地犹豫"**——当碰到不确定的物体时，它会先 "观察一会儿"（微小的末端移动但不操作），等视觉确认后再行动。这是训练数据中的人类 "不确定就再看一眼" 的行为被 BC 学进去了。

## 贡献与影响

1. **首个开放世界 VLA**：在完全陌生的家庭中完成长周期灵巧操作
2. **异构协同训练范式**：证明网络数据 + 规划数据 + 机器人数据的混合训练是可行的且必要的
3. **Think then Act**：高层语义推理指导底层动作生成，成为后续 PI 模型的标准推理流程
4. **开源**: 模型权重、训练代码、微调示例全部开源 (openpi)

## 局限

- 仍然需要大量机器人数据（~400 小时），不是 "零样本"
- 两阶段训练流程复杂（先 FAST 自回归，再 Flow Matching 微调）
- Gemma 2.6B 推理延迟仍然不低
- 对极度罕见物体（训练中从未出现的概念）仍然可能失败
