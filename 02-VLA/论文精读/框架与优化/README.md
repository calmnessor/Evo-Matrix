```
VLA 研究的三个层次：

  ┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐

  │ Tokenizer 创新  │    │ 分层融合        │    │ 部署鲁棒性      │

  └─────────────────┘    └─────────────────┘    └─────────────────┘

```

## 核心关注点

1. **分布一致性** — $P_\text{train}$、$Q_\text{model}$、$P_\text{test}$ 三者的系统性对齐
2. **资源效率** — 有限数据和 GPU 下达成生产级鲁棒性
3. **训练稳定性** — 长期部署中策略不退化
4. **可复现性** — 方法模块化，每个组件独立验证
