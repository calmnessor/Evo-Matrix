# 扩散策略 (Diffusion Policy)

> 2023 年机器人学习最大突破之一——用扩散模型生成机器人动作。天然多模态、动作平滑、表达力强。

## 核心思想

```
传统 BC:     观测 → 直接回归 → 动作（单峰，确定性，选"平均轨迹"）
             
扩散策略:    观测 + 纯噪声 → 逐步去噪 → 动作
             ↑ 可表达多模态分布：同一观测下可以有不同的有效动作
```

**为什么多模态对机器人至关重要？**

同一观测下，机器人通常有多种正确动作：
- 避开障碍物：从左边绕 **或** 从右边绕
- 抓取杯子：抓杯柄 **或** 从上方抓杯身
- BC 的 MSE Loss 会学出"从中间穿过去"——这是最差的答案

扩散模型天然建模概率分布 $p(a|o)$，可以表达任意复杂的多峰分布。

## 扩散模型三要素

### 1. 正向扩散：从动作到噪声

从真实动作 $x_0$ 开始，逐步加高斯噪声：

$$q(x_t | x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t} \cdot x_{t-1}, \beta_t \mathbf{I})$$

直接计算任意时间步（重参数化技巧）：

$$q(x_t | x_0) = \mathcal{N}(x_t; \sqrt{\bar{\alpha}_t} \cdot x_0, (1-\bar{\alpha}_t) \mathbf{I})$$

其中 $\bar{\alpha}_t = \prod_{s=1}^t (1-\beta_s)$。

即：$x_t = \sqrt{\bar{\alpha}_t} \cdot x_0 + \sqrt{1-\bar{\alpha}_t} \cdot \epsilon$，$\epsilon \sim \mathcal{N}(0, I)$

**噪声调度 (Noise Schedule)**：
- $\beta_t$ 从 $10^{-4}$ (t=1) → $0.02$ (t=T) 线性增加
- 前几步加很少噪声（保留结构），后几步加很多噪声（完全随机化）
- Cosine schedule 比 linear 更好（更平滑的 SNR 变化）

### 2. 反向去噪：从噪声到动作

$$p_\theta(x_{t-1} | x_t, o) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t, o), \sigma_t^2 \mathbf{I})$$

其中 $\mu_\theta$ 是一个神经网络（U-Net 或 Transformer），$o$ 是观测条件。

### 3. 训练目标：预测噪声

$$\mathcal{L} = \mathbb{E}_{x_0, \epsilon, t, o} \left[ \| \epsilon - \epsilon_\theta(x_t, t, o) \|^2 \right]$$

**关键简化**：不直接预测 $x_0$（太难），也不预测 $\mu_\theta$（需要知道 $\bar{\alpha}_t$），而是预测"加了什么噪声" $\epsilon$。一旦知道 $\epsilon$，就可以还原：

$$\hat{x}_0 = \frac{1}{\sqrt{\bar{\alpha}_t}}(x_t - \sqrt{1-\bar{\alpha}_t} \cdot \epsilon_\theta(x_t, t, o))$$

## 扩散策略架构

### CNN-based (U-Net 风格)

```
观测 (多帧图像) ──→ FiLM 条件注入
                          ↓
噪声动作 x_t [H, act_dim] → U-Net (1D Conv) → 预测噪声 ε̂ [H, act_dim]
                          ↑
时间步 t ──→ Sinusoidal Embedding
```

- 适合视觉输入（U-Net 的 encoder-decoder 结构天然提取多尺度特征）
- FiLM 是最常用的条件注入方式
- 1D Conv 沿时间轴 → 天然适合 Action Chunking

### Transformer-based (DiT 风格)

```
噪声动作 x_t [H, act_dim]  →  Linear Proj  →  [H, d_model]
观测 [N_obs, d_obs]        →  Linear Proj  →  [N_obs, d_model]
时间步 t                   →  AdaLN 调制
                 ↓
    Transformer Blocks × N (Self-Attn + Cross-Attn + AdaLN)
                 ↓
            Linear → 预测噪声 ε̂
```

- 适合多模态观测（图像 token + state + language embedding）
- AdaLN 注入时间步条件
- Cross-Attention 注入观测条件

## 关键特性对比

| 特性 | BC (MSE) | Diffusion Policy |
|------|---------|-----------------|
| 多模态 | ❌ 学单峰均值 | ✅ 天然多模态 |
| 动作平滑 | 可能不连贯、抖动 | **天然平滑**（逐步去噪） |
| 推理速度 | 1 step (极快) | N steps (DDIM 可加速) |
| 训练稳定性 | 极高 | 高（但需要注意噪声调度） |
| 时序建模 | 逐步预测 | Action Chunk (一次生成 H 步) |
| 表达能力 | 弱 | **强**（全局最优时渐近最优） |

## Action Chunking in Diffusion Policy

一次去噪生成未来 H 步动作（如 H=16）：

```
输入: 2 帧观测历史 + 纯噪声 [16, act_dim]
去噪: T 步逐步去噪 (DDPM: T=100, DDIM: T=10)
输出: 干净动作序列 [16, act_dim]
执行: 取前 K 步 (K=8)，执行完后重新预测

观测窗口 ← 2 帧 → | 预测窗口 ← 16 步 → |
████████          ████████████████████
                  执行 ████████████ 前 8 步
                        滑动 →
      ████████        ████████████████████ 下一轮
```

**和 ACT Chunking 的异同**：
- 相同：都是一次预测多步
- 不同：Diffusion Policy 用扩散生成多步动作，ACT 用 VAE Decoder 生成

## DDIM 加速：让扩散策略实时可用

标准 DDPM 需要 ~100 步去噪（对于 50Hz 控制完全不可行）。

**DDIM (Denoising Diffusion Implicit Models)** 的核心：把随机采样改为确定性推理。

$$x_{t-1} = \sqrt{\bar{\alpha}_{t-1}} \cdot \hat{x}_0 + \sqrt{1-\bar{\alpha}_{t-1}} \cdot \epsilon_\theta(x_t, t, o)$$

只需在推理时用 $\{\tau_1, \tau_2, ..., \tau_S\}$ 的子序列（S << T），每一步都确定性跳一大步。

| 方法 | 去噪步数 | 推理时间 (H=16) |
|------|---------|----------------|
| DDPM | 100 | ~3.3s (太慢) |
| DDIM (S=50) | 50 | ~1.6s |
| DDIM (S=10) | 10 | ~330ms ✅ |
| DDIM (S=5) | 5 | ~165ms ✅ |

> 实验上，10 步 DDIM 通常不会有明显质量损失。

## 代码骨架

```python
class DiffusionPolicy(nn.Module):
    def __init__(self, obs_dim, act_dim, horizon=16, n_diffusion_steps=100):
        super().__init__()
        self.horizon = horizon
        self.n_diffusion_steps = n_diffusion_steps
        
        # 噪声预测网络 (CNN 1D 版本)
        self.noise_pred_net = ConditionalUnet1D(
            input_dim=act_dim,
            global_cond_dim=obs_dim,
            diffusion_step_embed_dim=128
        )
        
        # 噪声调度
        self.betas = self._make_beta_schedule(n_diffusion_steps)
        self.alphas = 1 - self.betas
        self.alphas_cumprod = torch.cumprod(self.alphas, dim=0)
    
    def _make_beta_schedule(self, T, beta_start=1e-4, beta_end=0.02):
        return torch.linspace(beta_start, beta_end, T)
    
    def add_noise(self, x0, t, eps=None):
        """正向加噪: x0 → xt"""
        if eps is None:
            eps = torch.randn_like(x0)
        alpha_bar = self.alphas_cumprod[t]  # [B]
        alpha_bar = alpha_bar.reshape(-1, 1, 1)
        xt = torch.sqrt(alpha_bar) * x0 + torch.sqrt(1 - alpha_bar) * eps
        return xt, eps
    
    def forward(self, obs, actions=None):
        """训练时: 预测噪声"""
        B = obs.shape[0]
        # 随机采样时间步
        t = torch.randint(0, self.n_diffusion_steps, (B,), device=obs.device)
        # 加噪声
        xt, noise = self.add_noise(actions, t)
        # 预测噪声
        noise_pred = self.noise_pred_net(xt, t, global_cond=obs)
        # MSE Loss
        loss = F.mse_loss(noise_pred, noise)
        return loss
    
    @torch.no_grad()
    def sample(self, obs, use_ddim=False, ddim_steps=10):
        """推理时: 从噪声逐步去噪生成动作"""
        B = obs.shape[0]
        device = obs.device
        
        # 从纯噪声开始
        xt = torch.randn(B, self.horizon, self.act_dim).to(device)
        
        if use_ddim:
            timesteps = self._ddim_timesteps(ddim_steps, device)
        else:
            timesteps = reversed(range(self.n_diffusion_steps))
        
        for t in timesteps:
            t_batch = torch.full((B,), t, device=device, dtype=torch.long)
            noise_pred = self.noise_pred_net(xt, t_batch, global_cond=obs)
            
            # DDPM 去噪一步
            alpha = self.alphas[t]
            alpha_bar = self.alphas_cumprod[t]
            beta = self.betas[t]
            
            # 预测 x0
            x0_pred = (xt - torch.sqrt(1 - alpha_bar) * noise_pred) / torch.sqrt(alpha_bar)
            
            if t > 0:
                noise = torch.randn_like(xt)
                xt = torch.sqrt(alpha) * x0_pred + torch.sqrt(beta) * noise
            else:
                xt = x0_pred
        
        return xt  # [B, horizon, act_dim]
```

## 训练技巧

| 问题 | 可能原因 | 解决 |
|------|---------|------|
| 生成动作噪声大 | 去噪步数不够 | 增加 DDPM 步数或增大模型 |
| 推理太慢 | 全 100 步去噪 | 用 DDIM 加速 (S=10) |
| 动作不准确 | 观测条件注入太弱 | 用 Cross-Attention 替代 FiLM |
| loss 震荡 | noise schedule 不合适 | 换 Cosine schedule |
| 生成动作"保守" | 模型容量不够 | 增大 U-Net channel 或换 Transformer |
