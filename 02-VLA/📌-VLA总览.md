# VLA 研究方向

> Vision-Language-Action — 让机器人看、理解、行动。VLA 是具身智能的核心技术范式，目标是构建从感知到动作的端到端映射。

## 方向简介

VLA 回答具身智能最核心的问题：**给定视觉观测和语言指令，机器人应该执行什么动作？**

```
摄像头看到 → "把红色方块推到蓝色圆圈上"
                    ↓
          VLA 模型推理
                    ↓
          末端移动 + 夹爪闭合 → 完成
```

VLA 的三个字母对应三大组件：
- **V (Vision)**：通过摄像头感知场景 → ViT/SigLIP/DINOv2
- **L (Language)**：理解自然语言指令 → LLM (LLaMA/PaLM-E)
- **A (Action)**：生成机器人动作 → 离散 token / 连续回归 / 扩散去噪

## 为什么 VLA 是当前主流范式？

| 对比维度 | 传统方法 (规则/FSM) | 模块化方法 (感知→规划→控制) | VLA (端到端) |
|---------|-------------------|--------------------------|------------|
| 新任务适应 | 重写规则 | 重新训练各模块 | 改 prompt 或少量数据微调 |
| 泛化能力 | 几乎为零 | 有限 | 强 (来自 LLM 的常识) |
| 开发成本 | 高（每任务人工编码）| 中 | 低（数据驱动） |
| 可解释性 | 高 | 中 | 低（黑盒） |

## 核心研究问题

1. **架构设计**：视觉 token 如何高效注入 LLM？用什么生成动作？（离散 token / 扩散 / Flow Matching）
2. **数据问题**：机器人数据极稀缺 → 如何利用 OXE 大规模混合数据？如何做数据增强？
3. **泛化能力**：训练时见过的物体/场景 → 没见过的物体/场景，策略还管用吗？
4. **推理效率**：7B+ 参数模型如何在嵌入式设备上实时（>10Hz）推理？
5. **Sim-to-Real**：仿真训练的 VLA 能否直接部署到真实机器人？
6. **安全性**：LLM 的"幻觉"在物理世界中可能是灾难性的

## 三大技术路线

```
路线 1: LLM + 动作 Token 化
  RT-2 → OpenVLA → ...
  优势: LLM 常识推理 + 多任务泛化
  劣势: 推理慢、离散化精度损失

路线 2: 扩散策略
  Diffusion Policy → RDT → ...
  优势: 多模态分布、平滑轨迹
  劣势: 多步去噪推理慢

路线 3: 条件 VAE 生成
  ACT → ...
  优势: 一次推理出多步动作 (chunking)
  劣势: VAE prior 可能欠拟合
```

## 新手学习路线

### 第一阶段：建立全局认知（2-3 天）
1. 读 [[VLA模型总览]]，理解 VLA 的发展脉络和三大技术路线
2. 看 RT-2 博客（Google DeepMind 的非技术性介绍），建立"动作变成 token"的直觉
3. 理解：V + L + A 各自用了什么技术，怎样拼在一起

### 第二阶段：理解基础方法（3-5 天）
1. 跑通 [[行为克隆]] 的代码 —— 理解最简单的 VLA 训练
2. 读 [[ACT]] 论文/代码，理解 CVAE + Action Chunking
3. 读 [[扩散策略]] 论文/代码，理解扩散模型生成动作

### 第三阶段：动手实践（5-7 天）
1. 在 MuJoCo/IsaacSim 中用 BC 训练一个简单的 reach/grasp 策略
2. 尝试用 OpenVLA 在仿真中做推理（即使不训练）
3. 阅读 OpenVLA 源码，理解 LoRA 微调的完整流程
