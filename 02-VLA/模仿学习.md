# 模仿学习 (Imitation Learning, IL)

> 从人类演示中学习策略——机器人不需要 reward 函数，直接"看人怎么做"。

## 什么是模仿学习？

模仿学习是机器人从专家（人类）演示中学习行为的方法。它位于监督学习和强化学习之间：输入是观测，输出是动作，但数据的收集方式和泛化问题不同于标准监督学习。

```
监督学习:      (数据, 标签) → 学到映射 f: x → y
模仿学习 (BC):  (观测, 专家动作) → 学到策略 π: o → a
强化学习:      (s, a, r, s') → 学到最优策略 π*: s → a
```

## 为什么机器人首选模仿学习而非 RL？

| | 模仿学习 (IL/BC) | 强化学习 (RL) |
|------|------|------|
| 需要 reward 函数？ | ❌ 不需要 | ✅ 需要（人工设计，很难） |
| 数据来源 | 人类演示（几十到几百条） | 环境交互（上千到百万条） |
| 安全性 | 高（离线数据） | 低（在线试错） |
| 性能上限 | ≤ 专家水平 | 可超越专家 |
| 训练稳定性 | 高（标准监督学习） | 中低（不稳定） |
| 当前 VLA 使用 | **主流** | 补充（BC → RL fine-tune） |

## 行为克隆 (BC) 的三大问题

BC 简单好用，但有根本性局限。理解这些才能理解为什么需要 ACT、扩散策略等进阶方法。

### 问题 1: 分布漂移 (Distribution Shift) — 最致命

```
训练分布: π_θ 在专家引导下 → 看到的都是"好"的观测

测试分布: π_θ 自己走一步 → 出现小误差
         → 进入训练时没见过的观测
         → 不知道怎么做 → 更大误差
         → 进入更陌生的观测 → 崩溃

"误差复合 —— 越走越偏，越快越偏"
```

**数学直觉**：BC 的误差界是 $O(T^2 \cdot \epsilon)$，其中 $T$ 是时间步数，$\epsilon$ 是单步误差。误差随任务长度**平方增长**。长任务 >100 步 → BC 理论上有界但在实践中几乎必定失败。

### 问题 2: 因果混淆 (Causal Confusion)

模型可能学到伪相关：
- "专家总是在杯子前面放右手 → 右手位置预测杯子位置"
- 但杯子位置才是原因，手是结果
- 测试时手不在预想位置 → 模型不知杯子在哪儿

### 问题 3: 多模态坍缩 (Multi-modal Collapse)

前面 [[扩散策略]] 已详细讨论。MSE Loss 强制学"平均"动作 → 在有多种选择时学出最差的折中。

## 进阶 IL 方法

### DAGGER (Dataset Aggregation)

在线收集"策略会访问的观测"→ 让专家标注 → 加入训练 → 减少分布漂移。

```
Loop for iteration i:
  1. 用当前策略 π_i 跑任务 → 收集观测序列 {o_1, o_2, ...}
  2. 让人类专家对每个 o_t 标注正确动作 a_t*
  3. D = D ∪ {(o_t, a_t*)}
  4. 在扩充的 D 上重训 π_{i+1}

效果: 训练分布 → 策略分布 (匹配了!)
代价: 需要在线人类标注，昂贵
```

### IRL (Inverse Reinforcement Learning)

从专家演示中**推断 reward 函数**，再用 RL 优化。好处是 reward 比策略更泛化。

```
专家演示 → IRL → reward 函数 R(s, a)
                       ↓
               RL → 策略 π (在新环境中也有效)

经典方法: MaxEnt IRL, GAIL, AIRL
现代方法: IQL (offline RL, 不需要在线交互)
```

### GAIL (Generative Adversarial Imitation Learning)

用 GAN 框架做 IL：

- **Discriminator**: 区分"专家状态-动作对"vs"策略状态-动作对"
- **Generator (Policy)**: 生成越来越像专家的行为
- 对抗训练 → 策略逐渐匹配专家分布

比 BC 更鲁棒，但训练不稳定（GAN 的老问题）。

### RL Fine-tuning (BC 初始化 + RL 微调)

当前最实用的范式：
```
1. BC 在演示数据上训练 → 学到基本行为（安全、合理）
2. 在仿真中用 RL (PPO/SAC) 从 BC 策略开始继续训练
3. 奖励函数驱动策略超越人类水平
```

## 实现一个简单的数据收集 + BC 训练

```python
# === 数据收集 (遥操作模式) ===
import numpy as np

class DataCollector:
    def __init__(self):
        self.episodes = []
        self.current_episode = []
    
    def record_step(self, obs, action):
        self.current_episode.append({
            'observation': obs,
            'action': action
        })
    
    def end_episode(self):
        self.episodes.append(self.current_episode)
        self.current_episode = []
    
    def save(self, path):
        np.savez_compressed(path, episodes=self.episodes)

# === BC 训练 ===
import torch
from torch.utils.data import Dataset, DataLoader

class RobotDataset(Dataset):
    def __init__(self, episodes):
        self.pairs = []
        for ep in episodes:
            for step in ep:
                self.pairs.append((
                    torch.tensor(step['observation'], dtype=torch.float32),
                    torch.tensor(step['action'], dtype=torch.float32)
                ))
    
    def __len__(self):
        return len(self.pairs)
    
    def __getitem__(self, idx):
        return self.pairs[idx]

# 训练
def train_bc(policy, dataset, epochs=100):
```
