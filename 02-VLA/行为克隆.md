# 行为克隆 (Behavior Cloning, BC)

> VLA 最基础也最核心的学习方法——从人类演示中"抄作业"。RT-1、RT-2、OpenVLA 本质上都在做 BC。

## 核心思想

```
人类遥操作机器人做任务 → 记录 (观测, 动作) 对 → 监督学习 → 模仿人类
```

**一句话**：BC = 把机器人控制转化为标准监督学习问题。

## 数学形式

$$\theta^* = \arg\min_\theta \mathbb{E}_{(o, a) \sim \mathcal{D}} \left[ \ell(\pi_\theta(o), a) \right]$$

- 连续动作：$\ell$ = MSE（均方误差），$\| \pi_\theta(o) - a \|^2$
- 离散动作：$\ell$ = Cross-Entropy（交叉熵）
- $\mathcal{D}$ = 人类演示数据集

## 为什么 BC 这么简单却有效？

BC 简单到令人怀疑——连 RL 的 reward 函数都不需要，直接监督学习就够？

**BC 有效的三个前提**（缺一不可）：

1. **专家数据足够好**：人类遥操作的质量 > 策略要学习的目标
2. **覆盖足够广**：数据覆盖了任务的主要变化（光照/物体位置/初始状态）
3. **任务不太长**：短任务（<50 步）的分布漂移可控，长任务会累积崩溃

## 最小可运行 BC 训练

import torch
import torch.nn as nn
import torch.nn.functional as F
from torch.utils.data import Dataset, DataLoader

class Policy(nn.Module):
    def __init__(self, obs_dim, act_dim):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(obs_dim, 256), nn.ReLU(),
            nn.Linear(256, 256), nn.ReLU(),
            nn.Linear(256, act_dim),
        )
    
    def forward(self, obs):
        return self.net(obs)

# 2. 加载演示数据
class DemoDataset(Dataset):
    def __init__(self, data_path):
        data = np.load(data_path)
        self.observations = torch.tensor(data['obs'], dtype=torch.float32)
        self.actions = torch.tensor(data['actions'], dtype=torch.float32)
    
    def __len__(self):
        return len(self.observations)
    
    def __getitem__(self, idx):
        return self.observations[idx], self.actions[idx]

# 3. BC 训练循环
def train_bc(policy, dataloader, epochs=100, lr=1e-3):
    optimizer = torch.optim.Adam(policy.parameters(), lr=lr)
    
    for epoch in range(epochs):
        total_loss = 0
        for obs, act in dataloader:
            pred_act = policy(obs)
            loss = F.mse_loss(pred_act, act)
            
            optimizer.zero_grad()
            loss.backward()
            optimizer.step()
            
            total_loss += loss.item()
        
        if epoch % 20 == 0:
            print(f"Epoch {epoch:3d} | Loss: {total_loss/len(dataloader):.6f}")
    
    return policy

## 核心问题：分布漂移 (Distribution Shift)

```
训练时的数据分布:
  观测 ← 专家的动作 → 观测 ← 专家的动作 → 观测
  
  每一步的观测都来自"专家动作导致的结果"
  所以观测分布 = "专家行为下的状态分布"

测试时的数据分布:
  观测 ← 策略的动作 → 观测' ← 策略的动作 → 观测''
        ↑ 策略的动作和专家不完全一样
        ↑ 观测' 进入了训练时从没见过的区域
        ↑ 策略不知道怎么办 → 动作更差 → 观测'' 更离谱 → 崩溃!
```

**数学上**：BC 的累积误差界是 $O(T^2 \cdot \epsilon)$。
- 10 步任务 (T=10)：$100 \cdot \epsilon$
- 100 步任务 (T=100)：$10000 \cdot \epsilon$
- 这就是为什么 BC 对长任务不可靠

### 四种缓解方法

| 方法 | 原理 | 代表 | 效果 |
|------|------|------|------|
| **DAGGER** | 在线收集"策略访问到的观测"让专家标注 → 加入训练 | DAGGER (2011) | ⭐⭐⭐ 有效但费专家 |
| **Action Chunking** | 一次预测多步 → 减少推理步数 → 减少 T | [[ACT]], [[扩散策略]] | ⭐⭐⭐ VLA 标配 |
| **数据增强** | 对观测加噪声/变换 → 扩大训练分布覆盖 | 颜色抖动/视角变换 | ⭐⭐ 几乎免费 |
| **多任务训练** | 在多个任务/环境的混合数据上训练 | OXE 多数据集联合 | ⭐⭐⭐ 但需大规模数据 |

## BC vs 进阶方法

| 方法 | Loss | 本质 | 分布漂移缓解 |
|------|------|------|------------|
| **Plain BC** | MSE(act_pred, act_gt) | 确定性回归 | 无 |
| **BC + ACT** | MSE(recon, act_gt) + β·KL | CVAE + Action Chunking | Chunking 减少推理次数 |
| **BC + Diffusion** | MSE(noise_pred, noise) | 扩散去噪 + Chunking | Chunking + 多模态 |
| **BC + DAGGER** | MSE on mixed data | 在线数据扩充 | 对齐训练和测试分布 |
| **RL fine-tune** | PPO/SAC (reward-driven) | BC 初始化 + RL 微调 | RL 主动适应自身分布 |

## VLA 模型中的 BC

| 模型 | BC 类型 | 动作 Loss | 关键差异 |
|------|---------|----------|---------|
| **RT-1** | Plain BC | MSE (连续) | 多任务大规模 BC |
| **RT-2** | Plain BC | Cross-Entropy (离散 token) | 把 BC 变成语言建模 |
| **OpenVLA** | Plain BC | Cross-Entropy (256 bins × 7 dims) | BC + LoRA 微调 |
| **ACT** | BC + VAE | MSE(recon) + β·KL | CVAE 增加动作多样性 |
| **Diffusion Policy** | BC + Diffusion | MSE(noise) | 扩散增加多模态建模 |
| **π₀** | BC + Flow Matching | 向量场匹配 | 新一代 BC 变体 |

## 训练前/训练中的检查清单

```
训练前:
  □ 数据量是否足够? (>50 条高质量演示)
  □ 数据覆盖了任务的主要变化吗? (光照/物体位置/初始状态)
  □ 数据包含失败恢复吗? (专家卡住了怎么处理)
  □ 数据有噪声吗? (检查几条轨迹的 smoothness)
  □ 观测和动作是否已经归一化? ([-1, 1] 或 z-score)

训练中:
  □ Loss 在下降吗? (不降 = 模型太小/数据太差/学习率不对)
  □ 验证集 Loss 是否和训练集接近? (不接近 = 过拟合)
  □ rollout 一下看看: 动作平滑吗? 有没有抖动?
  □ 有没有"发呆"(action → 0) 的情况?

训练后:
  □ 在仿真中 rollout evaluation (就算最终要上真实机器人)
  □ 和 BC baseline 对比 (不要一上来就调复杂方法)
  □ 记录失败 case: 是漂移问题? 多模态坍缩? 还是数据不足?
```

## 优缺点总结

**优点**：
- 极简：就是监督学习，不需要 reward 函数（RL 最难的部分）
- 训练稳定：loss 几乎总是平稳下降
- 入门门槛低：一个 MLP + MSE Loss 就能开始
- 配合多任务大规模数据 → 泛化能力惊人（OXE + BC = RT-X 的成功）

**缺点**：
- 分布漂移 → 长任务会累积崩溃
- 只能模仿，无法超越专家（$\pi_{BC}$ 的理论上限 ≤ $\pi_{expert}$）
- 对数据质量极度敏感（垃圾数据 → 垃圾策略）
- 不鲁棒：没见过的情况 = 随机动作
