## 复现优先级建议

1. **OpenVLA** — 开源最完整，社区活跃，适合首次复现
2. **ACT** — 架构简洁，代码开源，适合理解 CVAE + Chunking
3. **Diffusion Policy** — 理解扩散模型在机器人中的应用
4. **RT-1** — 历史意义重大，但需自行补全部分代码
5. **RT-2** — 未完全开源，适合理解架构后简化复现
