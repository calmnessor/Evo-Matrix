## 每个项目应包含

```
project_name/
├── README.md         # 项目说明
├── train.py          # 训练脚本
├── eval.py           # 评估脚本
├── inference.py      # 推理脚本
├── config.py         # 配置文件
├── requirements.txt  # 依赖列表
└── results/          # 结果输出
    ├── checkpoint.pt
    ├── training_curves.png
    └── notes.md      # 实验笔记
```
