## 模块 5: 面试模拟（1.5 小时）

### 5.1 高频面试题 — 60min

对每道题，先自己口头回答 3 分钟，然后看答案补充。

---

**Q1: 请解释 VLA 模型的完整 pipeline，从输入到输出**

```
期望回答框架:
1. 图像进入视觉编码器（如 SigLIP ViT）→ 视觉 token
2. 指令进入 Tokenizer → 文本 token
3. 视觉 token 和文本 token 拼接
4. 一起送入 LLM（如 Llama-2）
5. 从特殊位置提取 hidden state
6. Action Head 映射为动作值或动作 token

加分项:
- 提到视觉投影层（把视觉维度映射到 LLM 维度）
- 提到 Action Tokenization（RT-2 风格）
- 提到推理时可以用 KV cache 加速
```

---

**Q2: RT-2 如何将互联网知识迁移到机器人控制？**

```
期望回答框架:
1. RT-2 用 VLM (如 PaLI-X/PaLM-E) 作为 backbone
2. VLM 在互联网图文数据上预训练，学到了:
   - 物体识别（什么是可乐罐、什么是照片）
   - 常识推理（"旁边"是什么意思）
   - 符号理解（Taylor Swift 是谁）
3. 通过 co-fine-tuning:
   - 同时在互联网数据和机器人数据上微调
   - 保留了互联网知识，同时学会控制
4. 涌现能力: 模型自发地结合视觉理解和语言推理
   → "把可乐罐移到 Taylor Swift 照片旁"
```

---

**Q3: 什么是分布漂移（Distribution Shift）？VLA 中怎么解决？**

```
期望回答框架:
1. 定义:
   - 训练时: 模型看到的观测来自专家分布
   - 推理时: 模型看到的观测来自自己的策略分布
   - 两个分布不同 → 模型进入未知状态 → 误差累积

2. 解决方案:
   - Action Chunking: 预测多步，减少重规划频率
   - DAGGER: 在线让专家标注模型的失败状态
   - 数据增强: 加噪声扩大训练分布
   - Temporal Ensemble: 对多次预测加权平均
   - 预训练 VLM: 利用 commonsense 处理未知场景
```

---

**Q4: LoRA 的原理和配置建议**

```
期望回答框架:
1. 原理:
   - 冻结原始权重 W，添加低秩分解: Wx + BAx
   - B: [d_out, r], A: [r, d_in], r << min(d_in, d_out)
   - 只训练 A 和 B

2. 配置建议:
   - r: 8~64，16 是 sweet spot
   - alpha: 通常是 r 的 2 倍
   - target_modules: Attention 的 QKV + FFN 层
   - 训练 lr: 1e-4 ~ 2e-4（比全量微调大）

3. 优势:
   - 显存降低 ~70%
   - 训练速度 2-3x
   - checkpoint 只有 ~30MB
```

---

**Q5: 自回归动作生成 vs 扩散动作生成，各自的优劣？**

```
期望回答框架:
1. 自回归 (RT-2/OpenVLA):
   优点: 利用 LLM 推理能力, 语言理解强
   缺点: 误差累积, 推理慢(逐 token 生成), 多模态表达能力弱

2. 扩散 (Diffusion Policy):
   优点: 全局一致性, 天然平滑, 多模态表达强
   缺点: 需要多步去噪(慢, 但一次生成所有步), 语言理解弱

3. 选型:
   - 语言推理重要 → 自回归
   - 精细动作重要 → 扩散
   - 未来: 融合 (π₀ 的 VLM + Flow Matching)
```
