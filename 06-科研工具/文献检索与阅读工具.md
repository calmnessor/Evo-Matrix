# 文献检索与阅读工具

> 找得快、读得懂、管理好——文献工作的三层效率

## 检索

### Google Scholar
- 打开引用提醒（Citation Alert）
- 用 `site:arxiv.org` 限定范围
- 追踪核心作者的最近发表

### Semantic Scholar
- 比 Google Scholar 更好的 AI 推荐
- TLDR 自动摘要
- 引文图谱更直观

### arXiv
- 订阅日更邮件: `cs.RO` (机器人) + `cs.CV` (视觉) + `cs.LG` (ML)
- 用 [arxiv-sanity](https://arxiv-sanity-lite.com/) 筛选热门论文

### Connected Papers
- 输入一篇论文 → 生成相关论文图谱
- 适合发掘"引用链"

## 阅读

### 三遍阅读法

| 遍 | 目的 | 时间 |
|----|------|------|
| 第一遍 | 分类（值得读？） | 5-10min |
| 第二遍 | 理解内容，不看细节 | ~1h |
| 第三遍 | 深入推导，虚拟复现 | 2-4h |

### 第一遍: Abstract + Figures
快速判断: 这论文和我相关吗？

### 第二遍: Method + Results
理清: 输入/输出、核心创新、和已有方法的关系

### 第三遍: 数学 + 实现细节
能自己推一遍公式，甚至看开源代码

## 管理

### Zotero（推荐）
- 免费开源
- 浏览器一键保存
- 与 Obsidian 联动（Zotero Integration 插件）
- 自动提取引用信息

### Obsidian 论文笔记
用 `templates/论文笔记模板` 记录每篇精读论文。

### 标签体系
```
#待读   — 收集但还没读
#略读   — 读过 abstract + figures
#精读   — 三遍都读完
#复现中 — 正在跑代码
#已复现 — 代码跑通
```
