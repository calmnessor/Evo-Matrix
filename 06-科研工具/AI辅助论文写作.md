# AI 辅助论文写作

> 用 AI 提效论文写作的各个环节——不是代写，是增强

## 文献综述

### 找相关论文
```
Prompt 示例:
"以下论文列表是我的核心工作。请推荐近两年相关的 10 篇论文，
并说明每篇与我工作的关联: [贴入论文标题和摘要]"
```

### 快速理解论文
```
Prompt 示例:
"帮我总结这篇论文的核心贡献、方法和实验结果，用 200 字以内"
```

## 写作辅助

### 段落润色
- 用 AI 检查语法和流畅度
- 让 AI 建议更学术化的表达
- **底线**: 用自己的思路写初稿，AI 只做 polish

### 公式推导验证
```
Prompt 示例:
"我推导的梯度是 ∇L = 2(XW - Y)X^T，帮我验证是否正确"
```

### 图表描述
```
Prompt 示例:
"根据以下实验结果，帮我用简洁的英文写一段 figure caption:
[贴入结果数据]"
```

## Abstract 打磨

### 结构化检查
对照这几条逐一检查你的 abstract：
1. 问题是什么？（1 句）
2. 现有方法的局限？（1 句）
3. 我们的方法？（2-3 句）
4. 关键结果？（1-2 句）

可以用 AI 帮你检查是否遗漏要素。

## 回复审稿意见

### 心态词
- 先自己读三遍 comments → 整理回复策略 → 再用 AI 帮忙润色
- AI 可以帮写"客气版"回复，但技术内容必须自己把关

## 伦理红线

- AI 是辅助工具，不是代写工具
- 所有数据和结论必须由你来确保正确性
- 如果你的导师/期刊禁止 AI 辅助，请遵守
- 检查学校/期刊的 AI 使用政策
