# Evo-Matrix — 具身智能课题组知识库

> 一个基于 [Obsidian](https://obsidian.md) 的结构化知识库，服务于具身智能/VLA（Vision-Language-Action）方向的课题组协作学习与科研追踪。

## 这是什么？

Evo-Matrix 是课题组共享的"第二大脑"——用双向链接和知识图谱组织具身智能领域的理论知识、论文笔记、实验记录和科研工具。新人可以按学习路线图快速入门，进行中课题的研究员可以追踪论文、记录实验、建立知识之间的交叉链接。

## 快速开始

```bash
git clone https://github.com/calmnessor/Evo-Matrix.git
```

用 [Obsidian](https://obsidian.md) 打开克隆的文件夹 → "Open folder as vault"。

入门路径：
1. 从 `00-入口/🏠-总览.md` 了解全局结构
2. 新成员读 `00-入口/🚀-新人指南.md` 搭建环境
3. 按 `00-入口/🗺️-学习路线.md` 开始 14 天速通 + 30 天深入学习

## 知识库结构

```
Evo-Matrix/
├── 00-入口/               ← MOC 导航、新人指南、学习路线
├── 01-基础理论/            ← 深度学习、Transformer、CV、LLM、运动学、RL、3D 视觉
├── 02-VLA与策略/           ← RT-1/RT-2/OpenVLA/π₀、BC、IL、扩散策略、ACT、多模态融合
├── 03-仿真与工具/           ← MuJoCo、HuggingFace、Blender、数据集索引
├── 04-论文精读/             ← 论文索引 + 精读笔记模板
├── 05-项目实验/             ← 实验记录 + 项目追踪
├── 06-科研工具/             ← Claude Code、LaTeX、Git、Python 环境、文献检索
└── templates/              ← 论文笔记、实验记录、费曼笔记模板
```

## 核心特性

- **MOC（内容地图）**: 每个目录的索引页作为该领域的导航入口
- **双向链接**: 知识节点之间通过 `[[wiki-link]]` 互相连接，形成可跳转的知识图谱
- **学习路线**: 14 天速通 + 30 天深入，从零基础到能独立部署和微调 VLA 模型
- **费曼学习法**: 每个知识点都要能"用自己的话讲出来"，模板内置费曼检查清单
- **论文追踪**: 统一的论文笔记模板，通过标签和链接关联到相关方法/实验
- **实验可复现**: 实验记录模板包含环境配置、关键指标、踩坑记录

## VLA 模型覆盖

| 模型 | 年份 | 核心贡献 |
|------|------|----------|
| RT-1 | 2022 | 首次大规模 Transformer 用于机器人控制 |
| RT-2 | 2023 | VLM 输出动作 token（VLA 范式诞生） |
| ACT | 2023 | 动作分块 + 条件 VAE |
| Diffusion Policy | 2023 | 扩散模型生成动作序列 |
| Octo | 2024 | 通用机器人基座模型 |
| OpenVLA | 2024 | 开源 VLA（7B 参数） |
| π₀ | 2024 | Physical Intelligence 大规模通用策略 |
| GR00T | 2024 | NVIDIA 工业级基础模型 |

## 协作方式

- **新人**: Fork → 在本地按学习路线推进 → 用费曼模板写笔记 → PR 到主仓库
- **课题组成员**: 直接在仓库中编辑 → 论文笔记、实验记录实时同步 → 定期 PR review
- **外部贡献**: 欢迎通过 Issue/PR 补充论文、修正错误、添加工具教程
