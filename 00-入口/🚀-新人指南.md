# 新人指南

> 欢迎加入课题组！按以下步骤完成环境搭建和入门。

## 1. 硬件与软件环境

- [ ] 安装 [Miniconda](https://docs.conda.io/en/latest/miniconda.html)
- [ ] 创建 VLA 环境: `conda create -n vla python=3.10 -y`
- [ ] 安装 PyTorch: `pip install torch torchvision torchaudio`
- [ ] 安装核心依赖: `pip install transformers datasets accelerate peft`
- [ ] 安装仿真: `pip install gymnasium mujoco robosuite`
