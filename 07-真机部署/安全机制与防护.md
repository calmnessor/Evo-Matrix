# 安全机制与防护

> 机器人可以伤人的。以下内容**必须**在第一次操作机器人前读完。

## 安全第一原则

```
物理世界的三条铁律:

1. 机器人永远可能做出意料之外的动作
   → VLA 是黑盒, 没有数学保证安全
   → 永远假设它下一步可能乱动

2. 速度和质量 = 危险
   → 即使夹爪碰到人, 低速时可能只是淤青
   → 全速碰撞 → 骨折
   → 速度上限是第一道安全防线

3. 你比机器人聪明
   → 感觉不对劲 → 立刻急停
   → 不要想 "再观察一下"
   → 宁可多停, 不可少停
```

## 1. 硬件安全机制

### 急停按钮

```
位置: 每个机器人工作站必须有 2+ 个急停:
  1 个在操作台面板 (随手可及)
  1 个在房间门口 (进入的人可以按)

类型:
  - 机械急停 (直接断电) ← 最可靠
  - 软件急停 (ROS 2 /kill) ← 有延迟, 不可依赖

新人任务: 找到课题组的急停按钮 → 按一下 (确认有效) → 复位
```

```python
def safe_move_ee(target, max_speed=0.3):
    """安全移动末端"""
    current = robot.get_ee_pose()[:3]
    delta = target - current
    distance = np.linalg.norm(delta)

    if distance > max_speed * 0.02:  # 20ms 内移动不超过 max_speed*dt
        # 截断
        delta = delta / distance * max_speed * 0.02

    robot.move_ee_delta(delta)
```

## 2. 软件安全层

### 安全动作范围

```python
class SafetyChecker:
    """动作安全检查 —— 发动作前必须过这一层"""

    def __init__(self):
        # 工作空间边界 (Franka 示例)
        self.workspace_bounds = {
            "x": (0.2, 0.8),   # 米
            "y": (-0.5, 0.5),
            "z": (0.05, 0.7),  # 不要低于桌面
        }

        # 关节限位 (比物理限位更严格)
        self.joint_limits = [
            (-2.5, 2.5),      # j1
            (-1.5, 1.0),      # j2 (更严格)
            (-2.5, 2.5),      # j3
            (-2.5, 0.5),      # j4 (更严格)
            (-2.5, 2.5),      # j5
            ( 0.0, 3.5),      # j6
            (-2.5, 2.5),      # j7
        ]

        # 危险区域 (如桌面以下)
        self.forbidden_zones = [
            # {"x": (0, 0.5), "y": (-0.5, 0), "z": (0, 0)},  # 桌子腿
        ]

    def check_ee_pose(self, pose, tolerance=0.01):
        """检查末端位姿是否安全"""
        x, y, z = pose[:3]

        # 工作空间检查
        if not (self.workspace_bounds["x"][0] - tolerance <= x <= self.workspace_bounds["x"][1] + tolerance):
            return False, f"X 超出工作空间: {x:.3f}"

        if not (self.workspace_bounds["y"][0] - tolerance <= y <= self.workspace_bounds["y"][1] + tolerance):
            return False, f"Y 超出工作空间: {y:.3f}"

        if z < self.workspace_bounds["z"][0] - tolerance:
            return False, f"Z 太低 (可能碰桌面): {z:.3f}"

        # 禁区检查
        for zone in self.forbidden_zones:
            if (zone["x"][0] <= x <= zone["x"][1] and
                zone["y"][0] <= y <= zone["y"][1] and
                zone["z"][0] <= z <= zone["z"][1]):
                return False, f"进入禁区!"

        return True, "OK"

    def check_joint_positions(self, q):
        """检查关节角是否在限位内"""
        for i, angle in enumerate(q):
            low, high = self.joint_limits[i]
            if angle < low or angle > high:
                return False, f"关节 {i+1} 超限: {angle:.3f} ([{low:.1f}, {high:.1f}])"

        return True, "OK"

    def check_action(self, action, current_q):
        """综合安全检查"""
        # 1. 检查动作幅值是否合理
        if np.any(np.abs(action) > 1.0):  # 1 rad / 1m per step
            return False, "动作幅值异常"

        # 2. 预测下一步关节角
        next_q = current_q + action[:7]
        ok, msg = self.check_joint_positions(next_q)
        if not ok:
            return False, f"预测关节超限: {msg}"

        return True, "OK"


# 使用: 每个动作发出前必须通过安全检查
safety = SafetyChecker()

def safe_step(robot, action, safety_checker):
    """带安全检查的动作执行"""
    current_q = robot.get_joint_positions()

    ok, msg = safety_checker.check_action(action, current_q)
    if not ok:
        print(f"⚠ 安全拦截: {msg}")
        robot.emergency_stop()
        return False

    robot.execute(action)
    return True
```

### 力传感器监控

```python
class ForceMonitor:
    """实时力/力矩监控 → 超阈值自动停止"""

    def __init__(self, robot, force_threshold=50.0):
        self.robot = robot
        self.force_threshold = force_threshold
        self.running = False

    def monitor(self):
        """后台监控线程"""
        import threading
        self.running = True

        def _loop():
            while self.running:
                force_data = self.robot.get_ee_wrench()
                force_magnitude = np.linalg.norm(force_data[:3])

                if force_magnitude > self.force_threshold:
                    print(f"🚨 力超阈值! {force_magnitude:.1f}N > {self.force_threshold}N")
                    self.robot.emergency_stop()

                time.sleep(0.002)  # 500Hz 检查

        self.thread = threading.Thread(target=_loop, daemon=True)
        self.thread.start()

    def stop(self):
        self.running = False
```

## 3. 操作规范

### 首次操作前

```
□ 读完本文件全文
□ 找到所有急停按钮的位置
□ 在有经验的师兄师姐监督下操作
□ 确保工作区域无杂物 (不会被机器人扫到的东西)
□ 确保周围人员站在安全距离外 (>1m)

禁止:
  ❌ 站在机器人工作范围内
  ❌ 把身体部位 (手/头) 放在机器人下方
  ❌ 边传东西边操作机器人
  ❌ 操作时戴耳机 (听不到异常声音)
  ❌ 远程 SSH 操作时不确认现场无人
```

### 操作中

```
✅ 手指始终放在急停按钮附近
✅ 速度从低速开始 (10% 全速)
✅ 感觉不对劲 → 立即急停
✅ 先空跑 (无物体) → 再加物体
✅ 先固定物体位置 → 再随机化

🟡 首次测试新策略时:
  1. 降低速度到 20%
  2. 用软物 (海绵/泡沫) 代替硬物
  3. 只跑 3-5 步, 观察 → 确认安全 → 再跑全程
```

## 4. VLA 特有的安全风险

| 风险 | 原因 | 缓解 |
|------|------|------|
| **动作跳变** | VLA 推理步间动作不连续 | 动作平滑滤波 |
| **幻觉动作** | LLM 推理错误 → 乱动 | 动作幅值 clamp |
| **奇异点** | 机械臂姿态接近奇异点 → 微动大响应 | 奇异点检测 + 截断 |
| **自碰撞** | 动作导致机械臂撞到自己 | 自碰撞检测 |
| **物体飞出** | 抓取失败 → 物体被弹飞 | 低速验证 → 再加速 |
| **死锁** | 策略反复做无效动作 | 超时 + 人工干预 |

### 动作平滑滤波

```python
# 防止 VLA 输出不连续动作
class ActionSmoother:
    def __init__(self, smooth_factor=0.3):
        self.prev_action = None
        self.alpha = smooth_factor  # 越大越平滑 (0=不滤波, 1=不动)

    def smooth(self, action):
        if self.prev_action is None:
            self.prev_action = action
            return action

        # EMA 滤波
        smoothed = self.alpha * self.prev_action + (1 - self.alpha) * action

        # 截断最大变化
        max_delta = 0.02  # 最大步间增量
        delta = smoothed - self.prev_action
        if np.any(np.abs(delta) > max_delta):
            delta = np.clip(delta, -max_delta, max_delta)
            smoothed = self.prev_action + delta

        self.prev_action = smoothed
        return smoothed
```

## 5. 紧急情况处理

```
场景 1: 机器人撞到人了
  1. 按急停
  2. 确认人员伤势
  3. 如有受伤 → 急救 → 校医院
  4. 记录事故 (时间/原因/后果)
  5. 分析原因 → 改进安全措施 → 才能重新开机

场景 2: 机器人撞到物体 (物体飞出去了)
  1. 按急停
  2. 确认无人员受伤
  3. 捡回物体, 清理碎片
  4. 检查机器人有无损坏
  5. 分析原因 → 调整速度/力限 → 重试

场景 3: 机器人发出异常响声
  1. 按急停
  2. 检查关节有无松动
  3. 手动慢速运动 → 确认响声位置
  4. 报修 → 不要强行继续

场景 4: 软件崩溃 / 通信断开
  1. 通信断开通常不会导致机器人失控 (有看门狗)
  2. 手动急停 + 重启
  3. 检查网络连接
```

---

> **记住**: 你做的是研究，不是生产。失败很正常。慢一点、稳一点，安全永远是第一优先级。如果因为安全顾虑需要降低速度/简化任务——那就这样做。好的研究不急于一时。
