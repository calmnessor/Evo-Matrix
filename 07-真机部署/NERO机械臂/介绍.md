## 简介
NERO 是松灵机器人（Agilex Robotics）推出的 7 自由度、3 kg 末端负载轻量化机械臂
机械臂采用<mark style="background: #FF5582A6;">模块化</mark>设计，便于维护和升级。
![[Pasted image 20260601092841.png]]
**主控板指示灯**:
开机后，指示灯亮绿色，表示机械臂状态可用，亮红灯表示机械臂状态存在异常，可以在 web 的首页查看机械臂状态。
> **注意事项**：
> - 关节零应设置在机械臂直立的默认位置，否则重力补偿功能可能无法正常运行。
> - 使用夹爪主从控制时，需要在自定义控制器栏中选择"夹爪"类型，并将夹爪使能后，方可正常使用。
> **特别注意：机械臂供电电压不可超过25V，否则会损坏电路，若使用外部供电方式，需额外保证电压稳压且电流不小于10A。

### 4.2 以太网连接
控制器与电脑连接，用网线一端连接控制器网络接口，另一端连接电脑或局域网网络接口，此时若连接成功，网口指示灯会频繁闪烁，出场机械臂控制器默认 ip 是 10.90.0.150，与机械臂通讯时，所有电脑 ip 要和机械臂控制器在同一网段。
修改电脑 ip 示例
IP 地址：10.90.0.153
子网掩码: 255.255.255.0
默认网络: 空着
DNS：8.8.8.8
**注意：机械臂的 IP 为静态 IP，使用有线连接时需要****手动设置****同一网段下的静态 IP。
配置完电脑 ip 后，网页浏览器地址栏输入 10.90.0.150，即可进入到 web 端上位机。


## STL
STL（Stereolithography）是一种 **三维模型文件格式**。
描述机械臂外壳零件长什么样子
它只描述：
- 点
- 三角面片
- 几何外形
不描述：
- 电机
- 关节
- 质量
- 运动学
## URDF
URDF（Unified Robot Description Format）是 ROS 的机器人描述文件。
描述机械臂怎么动
它是一个 XML 文件。
例如：
```xml
<robot name="nero">
  <link name="base_link"/>
  <joint name="joint1" type="revolute">
      ...
  </joint>
</robot>
```

## CAN 
一种专门用于设备之间通信的总线协议
对于 NERO 机械臂来说，***CAN 用于控制器与各个关节电机之间的实时通信***。
```
Python命令
    ↓
TCP数据包
    ↓
NERO控制器
    ↓
CAN报文
    ↓
关节驱动器
    ↓
电机运动
```
我的电脑通过 TCP/IP 与 NERO 控制器通讯，NERO 机械臂使用 CAN 协议操作各个关节运动。
*<mark style="background: #FF5582A6;">机械臂针对用户的开发提供了 CAN 接口，用户可通过该接口对机械臂进行指令控制</mark>*。
