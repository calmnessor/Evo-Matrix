# Grasp 方向综述：从力闭合到通用机器人抓取

> Robot Grasping — 机器人操作中最基础、研究最久、也是至今仍未完全解决的问题。本文梳理抓取研究 40 年的演进脉络与最新进展。

## 1. 定义与直觉

**一句话**：抓取 = 确定机械手与物体的接触点/位姿，使得能稳定拾取物体并完成后续任务。

**生活化类比**：你拿起一个杯子喝水——你不会去握杯口（会烫），不会捏杯底（拿不起来），你会自然握住杯柄或杯身中段。这涉及：选择接触位置（杯柄）、施加合适的力（不碎不掉）、为后续任务做好准备（握法方便倾斜喝水）。

```
抓取的三个层次:

Level 1 — 稳定性: "抓住不掉"
  → 力闭合, 摩擦锥, 接触点几何分析

Level 2 — 通用性: "什么都能抓"
  → 数据驱动, 从 2D 框到 6-DoF 位姿, 大规模训练

Level 3 — 功能性: "抓了之后还能做任务"
  → 任务导向抓取, 知道抓哪里才能完成后续操作
```

## 2. 为什么重要

抓取是机器人操作的**前提**。如果一个机器人连杯子都抓不住，它就不可能倒水、不可能清理桌面、不可能做任何操作任务。

| 为什么抓取仍然没有完全解决？ | 原因 |
|--------------------------|------|
| 物体形状无限多样 | 无法枚举所有抓取方式 |
| 物理属性未知 | 软硬、光滑/粗糙、重量 → 影响抓取策略 |
| 传感器噪声 | 视觉 3D 重建精度 ~mm 级，不是完美的 |
| 任务上下文 | "抓杯子" 和 "抓杯子然后倒水" 的最佳抓点不一样 |
| 夹爪形态多样 | 平行夹爪 vs 灵巧手 vs 吸盘 → 抓取策略完全不同 |

## 3. 技术演进时间线

```
经典时代 (1980s-2010): 分析抓取
├─ 1985: Salisbury 手 — 灵巧抓取的理论基础
├─ 2004: Ferrari & Canny — 力闭合形式化分析
├─ 2010: ———

深度学习时代 (2015-2020): 数据驱动崛起
├─ 2015: GG-CNN → 从深度图实时预测抓取质量热力图
├─ 2017: Dex-Net 2.0 → 大规模仿真抓取数据集 + 质量评估
├─ 2018: Dex-Net 4.0 → 通用抓取的工业级方案 (吸盘+夹爪)
├─ 2018: QT-Opt → RL 训练闭环视觉运动抓取策略
├─ 2019: 6-DOF GraspNet → 从部分点云预测 6-DoF 抓取
└─ 2020: GraspNet-1Billion → 10 亿级抓取标注

VLA 时代 (2021-2024): 语言+通用
├─ 2021: CLIPPort → CLIP + 抓取 → 语言指定抓取目标
├─ 2022: RT-1 → VLA 中的抓取原语
├─ 2023: AnyGrasp → 7-DoF 通用抓取, 开放世界, 实时
├─ 2023: DexGraspNet → 五指灵巧手抓取
├─ 2024: InstructGrasp → 语言引导可泛化抓取
└─ 2024: GraspGPT → LLM + 常识推理 → 任务级抓取

大融合时代 (2025-): 抓取 + VLA + RL
├─ 2025: π₀.₅ → VLA 中的统一抓取/放置/操作
├─ 2025: ReKep → 从语义关键点到抓取约束
└─ 2025: π*₀.₆ → RL 优化包括抓取在内的整个操作链
```

## 4. 方法分类学

```
抓取方法
│
├── 路线 A: 分析抓取 (Analytic Grasping)
│   思路: 基于物理模型 (力闭合, 摩擦锥) → 数学保证抓取稳定性
│   输入: 物体完整 3D 模型
│   输出: 满足力闭合的接触点对
│   代表: Dex-Net 系列, GPD
│   优势: 数学保证, 可解释
│   劣势: 需要完整 3D 模型 (实际中很难获得)
│   现状: 更多作为"质量评估"组件而非单独使用
│
├── 路线 B: 2D 平面抓取 (Planar Grasping)
│   思路: 从图像/深度图 → 预测 (x, y, θ, w) 矩形抓取框
│   代表: GG-CNN, Cornell Grasp, Jacquard
│   优势: 极快 (>100fps), 简单, 适合桌面场景
│   劣势: 假设物体在一个平面上, 无法处理复杂 3D 姿态
│   适用: 桌面操作, 传送带分拣
│
├── 路线 C: 6-DoF 抓取 (6-DoF Grasping)
│   思路: 从 RGB-D/点云 → 预测 6-DoF (x,y,z,roll,pitch,yaw) 抓取位姿
│   代表: GraspNet, AnyGrasp, Contact-GraspNet
│   优势: 通用性强, 能处理任意姿态的物体
│   劣势: 比 2D 慢, 需要好质量点云, 成功率依赖 3D 重建质量
│   适用: 通用操作, 开放世界场景
│
├── 路线 D: 语言引导抓取 (Language-Guided Grasping)
│   思路: 用户说"抓红色的杯子" → 模型结合视觉+语言定位抓取目标
│   代表: CLIPPort, InstructGrasp, GraspGPT
│   优势: 解决"在杂乱场景中抓哪个"的问题
│   劣势: 依赖 VLM 质量, 复杂指令可能理解偏差
│   适用: 人机交互, 杂乱环境, 开放世界
│
├── 路线 E: RL 闭环抓取 (RL-based Grasping)
│   思路: 不是预测一个抓取位姿，而是学习一个闭环策略 (看→动→调→抓)
│   代表: QT-Opt, RL-Grasp, Dactyl
│   优势: 能适应动态变化, 可处理初见物体
│   劣势: 训练成本高, 需要大量仿真/真机交互
│   适用: 动态环境, 灵巧手, 需要适应性调整的场景
│
└── 路线 F: 灵巧手抓取 (Dexterous Grasping)
    思路: 五指/多指手的抓取合成 → 比平行夹爪复杂得多
    代表: DexGraspNet, TAX-Pose, DGTR
    优势: 能完成人手级别的灵巧抓取
    劣势: 搜索空间极大, 硬件复杂, 尚在早期
    适用: 精细操作, 多用途抓取
```

| 维度 | Dex-Net 4.0 | GraspNet-1B | AnyGrasp | InstructGrasp | DexGraspNet |

| **输出** | 4-DoF 抓取 | 6-DoF 抓取 | 7-DoF 抓取 | 6-DoF + 语言 | 五指接触点 |

| **推理速度** | <1s | ~2s | >30fps | ~1s | ~5s |
| **泛化** | 已知物体 | 已知物体 | 开放世界 | 语言引导 | ~1500 物体 |
| **开源** | ✅ | ✅ | ✅ | ❌ | ✅ |

### 为什么 AnyGrasp 这么重要？

AnyGrasp 是首个达到实时 (>30fps)、开放世界（未见过的物体）、7-DoF（包括夹爪开合宽度）的抓取预测系统。它的成功来自：
1. **大规模训练**：在 1B+ 标注的抓取数据上训练
2. **几何感知架构**：同时利用点云全局特征和局部几何
3. **多方向评估**：不只预测一个"最佳抓取"，而是输出多种抓取方案并排序

## 6. 当前 SOTA 与趋势 (2025)

### 已解决的问题
- ✅ 已知物体的桌面抓取（单一物体、良好光照）→ 成功率 >90%
- ✅ 大规模仿真中生成抓取标注 → 已成熟
- ✅ 简单场景的 6-DoF 抓取 → AnyGrasp 级方案可用

### 正在突破的方向
- 🔥 **杂乱场景抓取**：多个物体堆叠/重叠 → 需要"拨开"或选择可触及的
- 🔥 **功能性抓取**：不仅抓住，还要抓得对（抓杯柄 vs 杯口 = 完全不同）
- 🔥 **灵巧手抓取**：从平行夹爪走向五指手 → 接触点优化
- 🔥 **动态抓取**：物体在移动中（传送带/人递过来）
- 🔥 **VLA 集成**：抓取不再是独立模块，而是 VLA 动作原语

### 三大趋势
1. **从几何到功能**：不只问"能抓住吗"（稳定性），更要问"抓得对吗"（任务适应性）
2. **从独立到集成**：Grasp 逐渐被吸收进 VLA，作为统一动作空间的一部分
3. **从单模态到多模态**：视觉 + 语言 + 触觉联合建模抓取

## 7. 关键挑战与开放问题

| 挑战 | 现状 | 可能突破方向 |
|------|------|------------|
| **透明/反光物体** | 深度相机失效 → 抓取盲区 | NeRF/3DGS 重建, 偏振成像 |
| **软/柔性物体** | 几何模型不适用 | 基于物理仿真的在线适应 |
| **超杂乱场景** | 物体间无间隙 → 无处下手 | 非抓取原语 (推/拨) 配合抓取 |
| **功能性抓取** | 缺乏带任务标注的抓取数据 | 人类视频迁移, VLM 常识推理 |
| **少样本新物体** | 每个新物体都需要数据 | 基础模型 + few-shot 适应 |
| **触觉融合** | 触觉不用于闭环抓取 | 触觉传感器小型化 + 多模态学习 |
| **Benchmark 碎片化** | 各论文用不同场景/物体评估 | 需要 LIBERO-grasp 级标准化 |
| **从抓取到操作** | 抓取后的操作轨迹不被优化 | VLA 统一优化整个操作链 |

## 8. 与其它方向的关系

```
                    ┌──────────────┐
                    │     VLA      │
                    │  (端到端)    │
                    └──────┬───────┘
                           │ "抓取"作为 VLA 的一个动作原语
                           ↓
              ┌─────────────────────────┐
              │      Affordance          │
              │  "这个物体能做什么操作?"  │
              └──────────┬──────────────┘
                         │ "可以抓"是 affordance 的核心子集
                         ↓
              ┌─────────────────────────┐
              │        Grasp            │ ← 我们在这里
              │  "具体怎么抓?"          │
              └──────────┬──────────────┘
                         │
              ┌──────────┼──────────┐
              ↓          ↓          ↓
        [几何分析]  [数据驱动]  [RL 探索]
        力闭合      深度学习     试错学习
```

- **Grasp ⊂ Affordance**: "抓取"是 afforadance 的一个特定动作类型。Grasp 社区的方法（如抓取质量评估）可直接用于 affordance 预测
- **Grasp ← VLA**: 在 VLA 中，抓取逐渐被整合为一个动作原语而非独立模块。"抓取→拿起→放置"变成 VLA 的一个连续动作序列
- **Grasp → 世界模型**: 世界模型预测"抓这个位置 vs 那个位置"的后续状态差异，帮助选择功能性最佳抓取

## 10. 新手学习路径

### 第 1 周：建立直觉
- Day 1-2: 读 GG-CNN 论文, 理解 2D 抓取的基本框架
- Day 3-4: 跑通 GG-CNN demo（CAM 可视化抓取热力图）
- Day 5-7: 读 Dex-Net 4.0, 理解力闭合和抓取质量评估

### 第 2 周：深入 3D 抓取
- Day 1-3: 读 GraspNet-1B, 理解从 2D 到 6-DoF 的变化
- Day 4-5: 运行 AnyGrasp, 在自己的场景上看到抓取候选
- Day 6-7: 对比分析抓取和 6-DoF 抓取的优劣

### 第 3 周：语言+功能
- Day 1-3: 读 CLIPPort + InstructGrasp, 理解语言如何引导抓取
- Day 4-5: 读 ReKep, 理解功能性抓取的最新进展
- Day 6-7: 思考：你关注的抓取场景是什么？哪种方法最适合？

### 第 4 周：动手实践
- Day 1-3: 在 robosuite/MuJoCo 中尝试不同抓取策略
- Day 4-5: 训练一个简单的 6-DoF 抓取预测器
- Day 6-7: 写 mini-review：抓取领域的"最后 10%"是什么？
