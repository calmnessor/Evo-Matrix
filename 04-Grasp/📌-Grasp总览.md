# Grasp 研究方向

> Robot Grasping — 让机器人"拿得起、握得稳"

## 方向简介

抓取（Grasping）是机器人操作中最基础也最核心的能力。一个好的抓取需要同时满足：抓取点稳定性、任务功能性、场景适应性。

## 核心概念

### 抓取范式

| 范式 | 流程 | 代表工作 |
|------|------|---------|
| **分析抓取** | 3D 重建 → 力闭合分析 → 抓取合成 | Dex-Net |
| **数据驱动** | 图像/点云 → 端到端网络 → 抓取位姿 | GraspNet, AnyGrasp |
| **模仿学习** | 人类示教 → 策略学习 | BC + grasp |
| **RL 抓取** | 试错 → 抓取成功奖励 → 优化策略 | QT-Opt, RL-Grasp |
| **VLA 抓取** | 语言指令 → VLA → 抓取动作 | RT-2 grasping |

### 抓取表征

| 表示方式 | 含义 | 自由度 |
|---------|------|--------|
| 2D 矩形框 | (x, y, θ, w) 在图像上 | 4-DoF |
| 6-DoF 位姿 | (x, y, z, roll, pitch, yaw) | 6-DoF |
| 抓取点+方向 | (p, d) 点+接近方向 | 可变 |
| 接触点 | 手指与物体接触位置 | 多点 |

### 抓取质量评估

- **力闭合 (Force Closure)**: 能否抵抗任意方向的外力
- **摩擦力锥 (Friction Cone)**: 摩擦角约束
- **任务适应性**: 不仅要抓稳，还要能执行后续任务

## 主流方法

### 经典方法

| 方法 | 输入 | 特点 |
|------|------|------|
| Dex-Net 4.0 | 深度图 | 大规模仿真训练 |
| GG-CNN | 深度图 | 实时生成抓取图 |
| GraspNet | 点云 | 通用物体抓取 |

### 大模型时代

| 方法 | 输入 | 特点 |
|------|------|------|
| AnyGrasp | 点云 | 7-DoF 通用抓取 |
| InstructGrasp | RGB + 文本 | 语言引导抓取 |
| GraspGPT | 文本 + 场景 | LLM 辅助抓取规划 |

## 与 Affordance 和 VLA 的关系

```
Grasp ⊂ Affordance ⊂ VLA

Grasp = affordance 中"抓取"这个动作子集
VLA 需要 grasp 作为其核心动作原语之一
Affordance 告诉 VLA "哪里能抓"，Grasp 执行"怎么抓"
```
