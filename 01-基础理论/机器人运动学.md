# 机器人运动学

> VLA 输出动作 → 理解动作控制的物理意义

## 核心概念

### 自由度 (DOF)
- 每个独立控制的关节 = 1 DOF
- 典型 6-DOF 机械臂：6 个旋转关节 → 任意位置 + 姿态
- 常见 7-DOF（如 Franka Panda）：增加冗余度

### 动作空间表示

| 表示方式 | 含义 | VLA 使用 |
|---------|------|---------|
| 关节空间 | [θ₁, θ₂, ..., θ₆] | 直接控制电机 |
| 笛卡尔空间 | [x, y, z, roll, pitch, yaw] | OpenVLA/RT-2 常用 |
| 增量控制 | [Δθ₁, ...] 或 [Δx, Δy, ...] | 相对运动 |

### 坐标系
- **世界坐标系**: 固定参考系
- **基座坐标系**: 机械臂底座
- **工具坐标系**: 末端执行器
- **相机坐标系**: Eye-in-Hand vs Eye-to-Hand

## 正运动学 (FK)

> 已知关节角度 → 求末端位姿

```
F K: [θ₁, ..., θ₆] → [x, y, z, roll, pitch, yaw]
```

### DH 参数法
每个关节用 4 个参数描述: **(a, α, d, θ)**
- a: 连杆长度
- α: 连杆扭转
- d: 关节偏移
- θ: 关节角度（旋转关节的变量）

## 逆运动学 (IK)

> 已知目标末端位姿 → 求关节角度

IK 比 FK 难：
1. 非线性 → 可能无解析解
2. 多解 → "肘向上"vs"肘向下"
3. 可能无解 → 超出工作空间

### 数值解法: 雅可比伪逆
```
ẋ = J(θ) · θ̇
Δθ = J⁺ · error  (迭代更新)
```

## 奇异性 (Singularity)

⚠️ VLA 部署时最容易踩的坑！

在某些关节配置下，雅可比秩亏 → 小末端速度需要巨大关节速度
- 边界奇异性: 完全伸直/折叠
- 腕部奇异性: 关节 4 和 6 共线

**应对**: 限制动作范围 / 阻尼最小二乘 / 用关节空间控制

## VLA 与运动学的关系

```
VLA 输出笛卡尔空间动作 → IK → 关节指令 → 电机
                        ↑
                  最容易出错的一环
```
