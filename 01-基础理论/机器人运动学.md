# 机器人运动学

> VLA 输出动作 → 理解这些动作的物理意义。运动学是连接"神经网络输出数字"和"机械臂真实运动"的翻译层。

## 为什么 VLA 需要运动学？

VLA 模型输出的是一串数字，比如 $[\Delta x, \Delta y, \Delta z, \Delta r, \Delta p, \Delta y]$。但这串数字怎样变成机械臂各关节的旋转角度？怎样确保机械臂不会打到桌子或自己？

**运动学回答三个核心问题**：
1. 给定关节角度，末端在什么位置？（**正运动学 FK**）
2. 给定目标位置，关节该转多少度？（**逆运动学 IK**）
3. 哪些姿态是达不到/危险的？（**奇异性分析**）

## 1. 核心概念

### 1.1 自由度 (DOF — Degrees of Freedom)

**DOF = 能独立控制的运动维度数**

| 机械臂 | DOF | 特点 |
|--------|-----|------|
| 简易桌面臂 (myCobot) | 6 | 标准，可达空间中任意位姿 |
| **Franka Emika Panda** | 7 | 冗余 1 个 DOF，可避开障碍 |
| KUKA iiwa | 7 | 人机协作，力矩传感器 |
| 人形手臂 | 7+ | 肩3 + 肘1 + 腕3 |
| Delta 并联臂 | 3 | 只有平移，速度快 |

**为什么 6 DOF 是"标配"？** 空间中描述一个刚体的位姿恰好需要 6 个参数：(x, y, z) 描述位置 + (roll, pitch, yaw) 描述姿态。6-DOF 臂刚好覆盖全部 6 个自由度。

**为什么需要 7-DOF (冗余)？** 从 A 到 B 有无穷多种路径，冗余 DOF 可以选一条避开障碍物的路径——就像人的手臂肘部可以抬高或放低来绕开桌上的杯子。

### 1.2 动作空间表示

| 表示方式 | 例子 | 优点 | 缺点 | VLA 使用 |
|---------|------|------|------|---------|
| **关节空间** | $[\theta_1, \theta_2, ..., \theta_6]$ | 无奇异性问题，直接控制电机 | 不直观，轨迹难以预测 | ACT, Diffusion Policy |
| **笛卡尔空间** | $[x, y, z, roll, pitch, yaw]$ | 直观，符合任务描述 | 需要 IK 求解 | OpenVLA, RT-2 |
| **增量 (delta)** | $[\Delta x, \Delta y, \Delta z, ...]$ | 适合闭环控制 | 累积误差 | 大多数 VLA 的做法 |

> **课题组推荐**：仿真训练时用关节空间（无 IK 失败风险），真实部署时可视情况用笛卡尔 + IK。

### 1.3 坐标系：机器人的多重身份

```
世界坐标系 (World)
  └── 基座坐标系 (Base)：机械臂的"根"
       └── 关节坐标系 (Joint_i)：每个关节自己的坐标系
            └── 工具坐标系 (Tool/EE)：夹爪或吸盘的中心
                 └── 相机坐标系 (Camera)
```

**手眼标定 (Hand-Eye Calibration)**：
- **Eye-in-Hand**：相机装在机械臂末端 → 相机随臂移动
- **Eye-to-Hand**：相机固定在工作台上方 → 全局视角
- **标定目标**：求出坐标系之间的齐次变换矩阵 $T$

### 1.4 姿态表示

| 表示 | 参数数 | 优点 | 缺点 |
|------|--------|------|------|
| **欧拉角** (roll, pitch, yaw) | 3 | 直观，VLA 常用 | 万向节死锁 (Gimbal Lock) |
| **旋转矩阵** $R^{3×3}$ | 9 | 无歧义 | 冗余，需正交约束 |
| **四元数** $(w, x, y, z)$ | 4 | 无死锁，平滑插值 | 不直观 |
| **轴角** $(\vec{v}, \theta)$ | 4 (3+1) | 物理含义清晰 | 表示不唯一 |
| **6D 旋转** (Gram-Schmidt) | 6 | 连续，适合神经网络输出 | 需要后处理 |

> **VLA 中常见做法**：训练时用 6D 或欧拉角（方便神经网络输出），部署时转为四元数做插值。

## 2. 正运动学 (Forward Kinematics)

> **已知关节角度 → 求末端在三维空间中的位姿**

### 2.1 DH 参数法

每个关节-连杆对用 **4 个 DH 参数** 描述：

| 参数 | 符号 | 含义 | 旋转关节变化？ |
|------|------|------|-------------|
| 连杆长度 | $a_i$ | $Z_{i-1}$ 到 $Z_i$ 沿 $X_i$ 的距离 | 不变 |
| 连杆扭转 | $\alpha_i$ | $Z_{i-1}$ 到 $Z_i$ 绕 $X_i$ 的转角 | 不变 |
| 关节偏移 | $d_i$ | $X_{i-1}$ 到 $X_i$ 沿 $Z_{i-1}$ 的距离 | 平移关节变 |
| 关节角度 | $\theta_i$ | $X_{i-1}$ 到 $X_i$ 绕 $Z_{i-1}$ 的转角 | **旋转关节变** |

每个关节的齐次变换矩阵：

$$T_i = \begin{bmatrix} c\theta_i & -s\theta_i c\alpha_i & s\theta_i s\alpha_i & a_i c\theta_i \\ s\theta_i & c\theta_i c\alpha_i & -c\theta_i s\alpha_i & a_i s\theta_i \\ 0 & s\alpha_i & c\alpha_i & d_i \\ 0 & 0 & 0 & 1 \end{bmatrix}$$

最终末端位姿：$T_{\text{EE}} = T_1 \cdot T_2 \cdot ... \cdot T_n$

### 2.2 动手：2 连杆臂的正运动学

```python
import numpy as np

def dh_transform(a, alpha, d, theta):
    """计算单个 DH 参数的齐次变换矩阵"""
    ct, st = np.cos(theta), np.sin(theta)
    ca, sa = np.cos(alpha), np.sin(alpha)
    return np.array([
        [ct, -st * ca,  st * sa, a * ct],
        [st,  ct * ca, -ct * sa, a * st],
        [ 0,       sa,      ca,      d],
        [ 0,        0,       0,      1]
    ])

# 2 连杆臂的 FK
L1, L2 = 1.0, 0.8  # 连杆长度 (m)
theta1, theta2 = np.pi / 4, np.pi / 6  # 45°, 30°

T1 = dh_transform(L1, 0, 0, theta1)
T2 = dh_transform(L2, 0, 0, theta2)
T_ee = T1 @ T2  # 末端在基座坐标系中的位姿

position = T_ee[:3, 3]
print(f"末端位置: x={position[0]:.3f}, y={position[1]:.3f}, z={position[2]:.3f}")
# 输出: 末端位置: x=0.871, y=1.399, z=0.000
```

## 3. 逆运动学 (Inverse Kinematics)

> **已知目标末端位姿 → 求关节角度**。这是 VLA 部署时最关键的环节。

### 3.1 IK 比 FK 难在哪？

1. **非线性方程** → 对 6-DOF 臂，没有通用的解析解 (但特定结构如 PUMA 型有解)
2. **多解** → 同一个末端位姿对应多组关节角 ("肘向上" vs "肘向下")
3. **无解** → 目标太远，超出工作空间
4. **奇异性** → 在特定姿态下，雅可比矩阵降秩

### 3.2 三种求解方法

| 方法 | 原理 | 速度 | 优点 | 缺点 |
|------|------|------|------|------|
| **解析法** | 几何推导封闭公式 | 极快 (μs) | 精确、可靠 | 只对特定臂结构有解 |
| **数值法 (梯度)** | 雅可比伪逆迭代 | 中 (ms) | 通用、简单 | 可能发散、陷入局部最小 |
| **学习法** | 神经网络学 IK 映射 | 快 | 通用、可处理冗余 | 需要训练数据、存在误差 |

### 3.3 数值 IK：雅可比伪逆法

雅可比矩阵 $J(\theta) \in \mathbb{R}^{6 \times n}$ 把关节速度映射为末端速度：

$$\dot{\mathbf{x}} = J(\theta) \cdot \dot{\theta}$$

求逆：$$\Delta\theta = J^+ \cdot \mathbf{e}$$，其中 $J^+$ 是伪逆，$\mathbf{e}$ 是位姿误差。

```python
# 简化版 IK (伪代码)
theta = initial_guess
for step in range(max_iter):
    T_current = FK(theta)
    error = pose_difference(target_pose, T_current)  # 6D 误差向量
    if norm(error) < tolerance: break
    
    J = compute_jacobian(theta)
    delta_theta = np.linalg.pinv(J) @ error  # 伪逆
    theta = theta + delta_theta * step_size
```

**阻尼最小二乘 (Damped Least Squares)**：$J^+ \rightarrow (J^T J + \lambda^2 I)^{-1} J^T$

在接近奇异点时，$\lambda$ 变大，抑制过大的关节速度，避免关节飞转。

## 4. 奇异性 (Singularity)

> VLA 部署时最容易踩的坑！

### 4.1 什么是奇异性？

当雅可比矩阵 $J$ 秩亏 (rank < 6) 时，某些方向的末端运动需要 ∞ 大的关节速度才实现 → 意味着该方向"瞬时可动自由度缺失"。

```
检查方法:
  det(J·J^T) ≈ 0  → 接近奇异点
  条件数(J) 很大  → 接近奇异点
```

### 4.2 三类典型奇异性

| 类型 | 例子 | 现象 |
|------|------|------|
| **边界奇异性** | 臂完全伸直 | 无法沿伸直方向继续前进 |
| **腕部奇异性** | 关节 4 和 6 的旋转轴共线 | 手腕"锁住" |
| **肩部奇异性** | 腕心经过关节 1 的旋转轴 | 无法侧向移动 |

### 4.3 应对策略

1. **动作空间限制**：VLA 输出 joint limits / safe Cartesian bounds
2. **阻尼最小二乘**：牺牲一点精度，换取关节速度平滑
3. **冗余臂**：7-DOF 臂在奇异时可用额外自由度逃脱
4. **笛卡尔 → 关节空间**：退而训练 VLA 直接输出关节角（绕开 IK）

## 5. VLA 部署中的运动学链路

```
神经网络输出 Δx  (笛卡尔空间增量，VLA 常用输出格式)
    ↓
当前末端位姿 + Δx → 目标末端位姿
    ↓
逆运动学 (IK)  → 目标关节角   ← 最容易出问题的环节!
    ↓
关节轨迹插值 (线性/S-curve) → 平滑运动
    ↓
关节位置控制器 (PID/阻抗) → 电机指令
    ↓
机械臂实际运动
```

**课题组常见问题与解决**：

| 问题 | 原因 | 解决 |
|------|------|------|
| 机械臂突然飞转 | IK 接近奇异点 | 加阻尼最小二乘 / 限制关节速度 |
| 末端位置不准确 | IK 收敛到局部最优 | 换初始猜测 / 用解析 IK (如有) |
| 动作抖动 (chattering) | 相邻帧 IK 解不一致 | 加关节空间平滑滤波 |
| 目标点超出工作空间 | VLA 输出不合法值 | 输出层加 sigmoid/clip 约束范围 |
