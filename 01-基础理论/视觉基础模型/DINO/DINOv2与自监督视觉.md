# DINOv2 与自监督视觉

> 不需要文本标注的视觉预训练——学到的特征捕获了极强的语义和几何结构。

---

## 1. 为什么需要自监督视觉？

CLIP/SigLIP 依赖文本-图像配对数据。但文本描述是有偏的——人类倾向于描述"物体是什么"而非"物体在什么位置、什么朝向、表面什么几何结构"。

DINOv2 纯靠图像自监督预训练，学到的特征：
- 无需文本标注即可做实例分割
- 自动捕获深度信息（特征图的 PCA 看起来像深度图）
- 对纹理变化不敏感（更符合物理世界）

**在 VLA 中的潜力**：
- 比 CLIP/SigLIP 更关注物体几何结构 → 抓取位姿估计更准
- 对光照、纹理域迁移更鲁棒 → Sim-to-Real 更友好
- 新兴 VLA 方案（如 RDT-1B）开始采用

---

## 2. DINOv2 训练原理

```
DINOv2 = DINO (自蒸馏) + iBOT (掩码图像建模) + 大规模数据

步骤:
1. Teacher 网络从全局 crop 看完整物体
2. Student 网络从局部 crop 看部分物体
3. 让 Student 的特征匹配 Teacher 的特征 → 学会"看到局部就推断全局"
4. 同时用 iBOT 做 patch-level 的掩码重建

结果: 特征自动聚类出语义区域，不需要任何标签
```

---

## 3. 对比：三个编码器的特征差异

| 维度 | CLIP/SigLIP | DINOv2 |
|------|-------------|--------|
| 预训练信号 | 文本-图像配对 | 图像自身结构 |
| 强项 | 语义理解，"这是什么" | 几何理解，"这在哪/什么形状" |
| 弱项 | 物体精确边界 | 缺乏语言知识 |
| 纹理敏感度 | 高 | 低 |
| VLA 适配 | 配合语言指令 | 配合精确操作 |

**实践中**：OpenVLA 已经开始支持 DINOv2 作为可选视觉编码器，一些工作尝试融合 CLIP+DINOv2 特征（语义 + 几何互补）。
