# NeRF 神经辐射场

> 用一个 MLP 把 3D 场景"记住"，然后从任意视角渲染。隐式 3D 表示的代表作。

---

## 1. NeRF 一句话

**输入**：一组已知相机位姿的 RGB 图像（比如从不同角度拍的 50 张照片）
**输出**：一个可以从任意新视角渲染出逼真图像的 3D 场景表示

---
## 2. 原理三步走

### 2.1 采样：沿光线取点

对渲染图中的每个像素，从相机光心出发沿该像素方向发射一条光线。在光线上采样 $N$ 个 3D 点。

### 2.2 查询 MLP

$$F_\Theta(\mathbf{x}, \mathbf{d}) \rightarrow (\mathbf{c}, \sigma)$$

- $\mathbf{x} = (x, y, z)$：3D 位置
- $\mathbf{d} = (\theta, \phi)$：视角方向
- $\mathbf{c} = (R, G, B)$：该点的颜色（与视角有关）
- $\sigma$：体密度（与视角无关，只取决于位置）

### 2.3 体渲染 (Volume Rendering)

沿光线积分，把 N 个采样点"合成"为一个像素颜色：

$$\hat{C}(\mathbf{r}) = \sum_{i=1}^N T_i \alpha_i \mathbf{c}_i$$

其中：
- $\alpha_i = 1 - \exp(-\sigma_i \delta_i)$：点 $i$ 的透明度
- $T_i = \prod_{j=1}^{i-1} (1 - \alpha_j)$：光线到达点 $i$ 时的累积透明度
- $\delta_i$：相邻采样点的距离

**物理直觉**：光线穿过雾状的场景，在每一点有一定的概率被"阻挡"（$\alpha$）。越靠近相机且密度越大的点，对最终颜色的贡献越大。

---

## 3. 关键技巧

### 3.1 位置编码 (Positional Encoding)

直接把 $(x, y, z)$ 输入 MLP，渲染结果会很模糊——MLP 倾向于学习低频函数。位置编码把坐标映射到高频空间：

$$\gamma(x) = (\sin 2^0\pi x, \cos 2^0\pi x, \sin 2^1\pi x, \cos 2^1\pi x, ..., \sin 2^{L-1}\pi x, \cos 2^{L-1}\pi x)$$

对位置 $(x,y,z)$ 用 $L=10$，对视角 $(\theta,\phi)$ 用 $L=4$。这样 MLP 就能学到高频细节（纹理、边缘）。

### 3.2 层级采样 (Hierarchical Sampling)

- **粗网络**：均匀采样 $N_c$ 个点 → 粗略估计密度分布
- **细网络**：在密度大的区域额外采样 $N_f$ 个点 → 精细渲染

这样避免了"在空旷区域浪费采样预算"。

## 4. NeRF 的进化

| 方法 | 改进 | 训练时间 | 渲染速度 |
|------|------|---------|---------|
| **原始 NeRF** (2020) | — | ~小时 | 慢 (几十秒/帧) |
| **Instant NGP** (2022) | 多分辨率哈希编码 + 小 MLP | **秒级** | 快 |
| **Mip-NeRF** (2021) | 抗锯齿，用圆锥代替光线 | 小时级 | 慢 |
| **3DGS** (2023) | 放弃 MLP，用显式高斯球 + 光栅化 | 分钟级 | **100+ FPS** |
| **Nerfstudio** | 统一框架，一行命令训练 | 分钟-小时级 | 取决于方法 |

---

## 5. 对机器人的意义

```
NeRF 让机器人能:
  看几张图 → 重建整个 3D 场景 → 从新视角观察

具体应用:
  - 新视角合成: 从人类演示的固定视角，生成机器人视角的图像 → 数据增强
  - 3D 场景理解: NeRF 的密度场 → 物体表面/占据信息 → affordance 推理
  - Sim-to-Real: NeRF 重建真实场景 → 在重建场景中仿真训练策略
```

## 6. Nerfstudio 快速上手

```bash
# 安装
pip install nerfstudio

# 训练 (用手机拍的视频)
ns-train nerfacto --data ./my_scene

# 渲染新视角
ns-render --load-config outputs/my_scene/nerfacto/config.yml
```
