# 自监督学习基础

> Self-Supervised Learning — 不靠人工标注，从数据自身构造监督信号。这是 DINOv2、CLIP、SigLIP 背后的训练范式，也是 VLA 视觉编码器强大的根本原因。

## 1. 为什么需要自监督学习？

### 1.1 标注的困境

```
ImageNet:      100 万张图，人工标注 → 花几个月、几十万美元
LAION-5B:      58 亿张图文对，自动抓取 → 免费
机器人数据:    真机采集 1 小时 ≈ 数千元成本
```

**核心矛盾**：标注昂贵且不可扩展。自监督学习让模型从数据本身构造"免费"的监督信号。

### 1.2 三种训练范式对比

| 范式 | 标签来源 | 例子 | 限制 |
|------|---------|------|------|
| **监督学习** | 人工标注 | ImageNet 分类、COCO 检测 | 标注成本高、覆盖范围有限 |
| **自监督学习** | 数据自身构造 | DINOv2、MAE、BERT | 需要巧妙的任务设计 |
| **多模态对齐** | 天然共现 (图文对) | CLIP、SigLIP | 依赖互联网数据的质量 |

**核心洞察**：自监督预训练学到的表示比监督预训练**更通用**——因为模型不是为"区分 1000 个 ImageNet 类别"而优化，而是为"理解视觉世界"而优化。

## 2. 三大自监督范式

### 2.1 对比学习 — "拉近相似的，推开不相似的"

**核心思想**：同一张图的两个不同裁剪（正样本对）在表示空间中应当接近，不同图的裁剪（负样本对）应当远离。

```
输入: 一批图像 {x₁, x₂, ..., x_N}
  
对每张图 x_i:
  裁剪两次 → (x_i^A, x_i^B)   ← 正样本对 (同一张图)
  
编码器 f(·) 提取表示:
  z_i^A = f(x_i^A),  z_i^B = f(x_i^B)

对比损失 (InfoNCE):
  L_i = -log( exp(sim(z_i^A, z_i^B) / τ) / Σ_{j≠i} exp(sim(z_i^A, z_j^B) / τ) )
        └── 分子: 正样本对相似度 ──┘   └───── 分母: 所有负样本 ──────┘
```

**三大经典方法**：

| 方法 | 年份 | 核心创新 | 负样本来源 |
|------|------|---------|-----------|
| **SimCLR** | 2020 | 大 batch + 强数据增强 | 同一 batch 内其他样本 |
| **MoCo v2** | 2020 | 动量队列 + 动态字典 | 历史上所有样本（队列存储） |
| **CLIP** | 2021 | 图文跨模态对比 | 同一 batch 内其他图文对 |

**CLIP 的特殊之处**（图文对比）：

```
图像编码器             文本编码器
  ↓                      ↓
"一只猫"图 → v_i      "a cat" → t_i    ← 正样本对 (匹配)
"一只狗"图 → v_j      "a dog" → t_j    ← 正样本对
                  但 v_i 和 t_j 是负样本 (不匹配)

L = 图像→文本对比 + 文本→图像对比 (双向)
```

**为什么 CLIP 对 VLA 至关重要**：训练后的表示空间中，"抓取红色杯子"这句话的向量，天然靠近"红色杯子的图片"的向量。这为语言引导机器人提供了数学基础。

### 2.2 掩码建模 — "遮住一部分，让模型猜"

**核心思想**：故意遮住输入的一部分，让模型预测被遮住的内容。模型必须理解"上下文"才能补全。

```
BERT (文本):
  输入: "机器人 [MASK] 了杯子"  →  预测: "抓取"
  
MAE (图像):
  输入: 只保留 25% 的 patch (可见部分)
  目标: 重建被遮住的 75% 的 patch
```

```python
# MAE 的核心思路 (伪代码)
def mae_forward(image):
    patches = patchify(image)          # [196, patch_dim]  14×14 patches
    
    # 随机遮住 75%
    visible_mask = random_mask(196, ratio=0.25)
    visible_patches = patches[visible_mask]
    
    # 编码器只看可见部分
    encoded = encoder(visible_patches)  # 轻量，因为只处理 25%
    
    # 解码器重建所有 patch
    all_encoded = insert_mask_tokens(encoded, mask_positions)
    reconstructed = decoder(all_encoded)  # 重建被遮住的部分
    
    loss = MSE(reconstructed, patches)   # 只在被遮住的位置计算 loss
    return loss
```

**为什么 MAE 有效**：图像有大量冗余（天空的一个 patch 和相邻 patch 几乎相同），随机遮住高比例（75%）强迫模型学习**高层次理解**而非低层级纹理记忆。

### 2.3 Teacher-Student 蒸馏 — "老师教学生"

**核心思想**：一个"老师"网络（EMA 更新）指导一个"学生"网络学习。不需要负样本！

```
DINO/DINOv2 训练流程:
  
  输入: 同一张图的两个裁剪 (全局大图 + 局部小图)
  
  Student (可训练):                Teacher (EMA 更新):
    g_s = Student(global_crop)        g_t = Teacher(local_crop)
    l_s = Student(local_crop)
  
  损失: 让 Student 的输出匹配 Teacher 的输出
    L = CrossEntropy(softmax(g_s), softmax(g_t).detach())
      + CrossEntropy(softmax(l_s), softmax(g_t).detach())
  
  更新:
    Student: SGD/AdamW 优化
    Teacher: θ_t ← α·θ_t + (1-α)·θ_s   (指数移动平均)
```

| 方法 | 年份 | 核心 | 不需要负样本 |
|------|------|------|-----------|
| **DINO** | 2021 | ViT + teacher-student → 注意力自发定位物体 | ✅ |
| **DINOv2** | 2023 | 更大规模、更稳定训练 | ✅ |
| **iBOT** | 2022 | DINO 思路 + 掩码建模 | ✅ |

**DINOv2 为什么让 VLA 社区兴奋**：
- 无需任何标注，注意力图自动定位物体（自发的"分割"能力）
- 特征对视角、光照、遮挡鲁棒——这正是机器人需要的
- VGGT 直接用它做骨架，3DGS affordance 用它做特征蒸馏

## 3. 自监督学习在组内各方向的位置

```
自监督预训练 (互联网规模数据)
│
├── 视觉: DINOv2, MAE
│   ├── VGGT (前馈 3D 重建)
│   ├── 3DGS Feature Distillation (特征蒸馏)
│   └── AnyGrasp (抓取检测)
│
├── 图文对齐: CLIP, SigLIP
│   ├── OpenVLA (VLA 视觉编码)
│   ├── MVGGT (语言引导 3D 分割)
│   └── FoundationGrasp (语言引导抓取)
│
└── 视频: VideoMAE, TimeSformer
    ├── 世界模型 (未来帧预测)
    └── 动作识别 (操作动作分类)
```

> **核心认知**：课题组几乎所有视觉模型都不是从头训练的——它们从自监督预训练权重出发，然后用少量领域数据微调（或直接冻结使用）。理解预训练表示决定了你能用这些"开箱即用"的特征做什么。
