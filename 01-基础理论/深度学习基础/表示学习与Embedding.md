# 表示学习与 Embedding

> 神经网络真正的能力不在于"拟合训练数据"，而在于学会了一种**有用的内部表示**。本文帮你建立对"表示"的直觉，这是理解 VLA 视觉编码器、世界模型潜空间、3DGS Feature Field 的前提。

## 1. 什么是"表示"？

**一句话**：表示 = 把原始数据（像素/文字/点云）映射到一个新空间，使在这个空间中"相似的东西距离近，不同的东西距离远"。

```
原始空间（像素）                    表示空间（Embedding）
  
  图1: 红杯子               →        ● (0.8, 0.3, -0.1)
  图2: 蓝杯子               →        ● (0.7, 0.4, -0.2)   ← 都在"杯子"区域
  图3: 猫                   →        ■ (-0.5, 0.9, 0.6)   ← 远离杯子区域
```

**关键洞察**：一个好的表示让下游任务变得简单。如果"红杯子"和"蓝杯子"在表示空间中紧挨着，抓取动作就可以共享——你不需要为每种颜色的杯子重新学习怎么抓。

### 1.1 生活化类比

你向一个从未见过猫的外星人描述你家猫。你有两个选择：
- **原始像素方案**：发一张 1024×1024 的照片。外星人需要自己找出"这堆像素中哪些属于猫、哪些是沙发"
- **表示方案**：告诉外星人"毛茸茸、四条腿、尖耳朵、会喵喵叫、爱推东西下桌"。这就是一种紧凑的"语义表示"

神经网络做的就是这个：把高维原始数据压缩成紧凑的、富含语义的向量。

---

## 2. Embedding = 学到的表示向量

### 2.1 什么是 Embedding？

Embedding 就是把一个离散或连续的东西（图片、词、3D 点）映射为一个**固定长度的稠密向量**。

```
图像 (224×224×3 = 150,528 维)  →  ViT  →  Embedding (768 维)
文字 "杯子"                     →  BPE   →  Token ID [15234]
                                →  LLM   →  Embedding (4096 维)
3D 点 (x, y, z)                →  MLP   →  Embedding (256 维)
```

### 2.2 Embedding 空间的几何直觉

在好的 Embedding 空间中：

```
语义相似 → 余弦相似度高 → 向量夹角小

cos_sim(a, b) = a·b / (|a|·|b|)  ∈ [-1, 1]

红杯子 vs 蓝杯子: cos_sim = 0.92   ← 非常近
红杯子 vs 红汽车: cos_sim = 0.31   ← 都是红色，但不是同类
红杯子 vs 苹果:   cos_sim = 0.45   ← 形状像、用途像"容器"，中等相似
红杯子 vs 猫:     cos_sim = -0.12  ← 完全不相关
```

**这就是 CLIP/DINOv2/SigLIP 在 VLA 中的核心价值**——它们的 Embedding 空间已经内化了语义关系，VLA 只需要从中"读取"信息。

## 3. 流形假设 (Manifold Hypothesis)

### 3.1 核心思想

自然数据（图像、语音、文本）虽然表面上是高维的（一张图几百万个像素），但实际上分布在远低于像素维度的低维流形上。

```
所有可能的 256×256 图像的数量: 256^(256×256×3) ≈ 天文数字
其中"有意义"的图像              分布在极低维流形上

举例: 把相机绕杯子转一圈，拍了 360 张照片
  → 像素空间中这是 360 个"完全不同"的图像
  → 但描述它们的本质只需要一个参数: 相机角度 θ ∈ [0°, 360°]
  → 这 360 张图在像素空间中形成了一个"一维圆圈"——这就是流形
```

### 3.2 为什么这对 VLA 重要？

- **数据效率**：流形假设解释了为什么少量机器人演示就能泛化——机器人动作的"本质变化维度"很少（物体位置 × 物体姿态 × 任务类型），不需要覆盖所有像素组合
- **世界模型**：潜空间 (latent space) = 对真实物理世界的低维流形近似。Dreamer 的 RSSM 就是在学这个流形
- **3DGS Feature Field**：把 DINOv2 高维特征蒸馏到高斯球上 = 把 2D 视觉流形映射到 3D 几何

## 4. 三类关键表示（与课题组直接对应）

### 4.1 视觉表示 — VLA 的眼睛

```
演进:
  监督 CNN (ResNet)  →  自监督 ViT (DINOv2)  →  多模态对齐 (SigLIP/CLIP)
   "识别物体"              "理解视觉世界"           "连接视觉和语言"
```

| 模型 | 特征维度 | 训练方式 | 在组里的使用 |
|------|---------|---------|-----------|
| **ResNet-50** | 2048 | ImageNet 监督 | 早期 VLA 骨干 |
| **DINOv2** | 768 (ViT-B) | 自监督 teacher-student | VGGT 默认骨架，3DGS 特征蒸馏 |
| **SigLIP** | 768/1024 | 对比学习 (图-文) | OpenVLA 视觉编码 |
| **CLIP** | 512/768 | 对比学习 (图-文) | MVGGT 文本分支，零样本 affordance |

### 4.2 语言表示 — VLA 的语义理解

```
词 → Tokenizer → Token ID → Embedding Layer → 上下文相关表示

"杯子" 在不同上下文中的表示:
  "拿起杯子"    → 强调功能性 (容器)，接近"碗""瓶"
  "杯子碎了"    → 强调物理性 (易碎)，接近"盘子""玻璃"
  "红色杯子"    → 强调视觉属性，接近"红色马克杯"
```

LLM 的核心魔力：同一个词根据**上下文**获得不同的 Embedding 向量——这就是"理解"的数学本质。

### 4.3 3D 表示 — 几何+语义的双重编码

```
2D 像素             3D 空间               多模态 3D
[224×224×3]   →    [N_cam × intrinsics]   (VGGT)
                  [N_pts × (xyz+feature)]  (3DGS + DINOv2)
                  [N_pts × (xyz+semantic)] (MVGGT 语言引导)
```

**课题组核心范式**：3D Gaussian Splatting 不仅是几何表示（xyz+协方差），还是语义载体——每颗高斯球携带 DINOv2/CLIP 特征 → 语言查询直接定位 3D 位置。

见 [[../3D视觉/3DGS|3DGS 完整展开]] 和 [[../../03-Affordance/Affordance方向综述|Affordance 综述]]。

## 5. 表示的评估

如何知道一个表示好不好？不用等到下游任务跑完：

| 方法 | 做法 | 指标 |
|------|------|------|
| **线性探测** | 冻结表示 + 训练线性分类器 | 分类准确率 → 表示的可分性 |
| **kNN 检索** | 用 Embedding 做最近邻搜索 | 检索准确率 → 表示的语义结构 |
| **t-SNE/UMAP 可视化** | 降维到 2D 观察 | 同类是否聚在一起 |
| **注意力可视化** | 看 ViT attention map | 模型在"看"哪里 |
| **余弦相似度矩阵** | 同类内 vs 类间相似度 | 类内高、类间低 → 好表示 |

```python
# 最简单的表示评估：线性探测
import torch.nn as nn

class LinearProbe(nn.Module):
    def __init__(self, embed_dim, num_classes):
        super().__init__()
        self.fc = nn.Linear(embed_dim, num_classes)  # 只训练这层!

    def forward(self, x):
        with torch.no_grad():
            x = frozen_encoder(x)  # 冻结的表示提取器
        return self.fc(x)          # 线性头
```

## 6. 课题组中的表示学习全景

```
                    互联网数据 (ImageNet, LAION, ...)
                              │
                    ┌─────────┼─────────┐
                    ↓                   ↓
             视觉预训练             语言预训练
           (DINOv2/SigLIP)         (LLaMA/Qwen)
                    │                   │
                    └─────────┬─────────┘
                              ↓
                      多模态对齐 (CLIP/OpenVLA)
                              │
                    ┌─────────┼─────────┐
                    ↓         ↓         ↓
                  VLA      3DGS     Affordance
            视觉+语言→动作  特征蒸馏   语义定位
```

所有箭头**可以反向传播**——这就是 LoRA 微调干的事：让下游任务的数据调整上游表示，但只动极少参数。
