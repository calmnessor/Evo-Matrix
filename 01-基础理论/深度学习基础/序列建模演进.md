# 序列建模演进：RNN → LSTM → Transformer

> 理解序列建模的历史脉络，才能理解为什么 Transformer 是革命性的，以及世界模型中的 RSSM 为什么还在用 RNN。

## 1. 为什么需要序列建模？

机器人本质上是一个**时间序列**系统：

```
观测₀  →  动作₀  →  观测₁  →  动作₁  →  观测₂  →  ...
```

- 当前动作依赖过去所有的观测（历史信息）
- 动作有长期后果（推一下 → 几秒后物体滑到桌沿才掉下去）
- 需要模型能记住"早已发生但重要"的事件

MLP 一次只能处理定长向量——它没有"记忆"，无法自然处理变长序列。

---

## 2. RNN：循环的朴素之美

### 2.1 核心思想

RNN 只有一个隐藏状态 $h_t$，每次读入新输入 $x_t$，更新这个隐藏状态：

$$h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$$

$$y_t = W_y h_t + b_y$$

```
展开来看:

  x₀ → [h₀] → x₁ → [h₁] → x₂ → [h₂] → ...
        ↑            ↑            ↑
        └────────────┘            └── h_t 累积了之前所有输入的信息
```

**RNN 的秘密武器**：$h_t$ 是一个**可微的记忆单元**。通过反向传播，网络学会了"什么值得记住，什么可以遗忘"。

### 2.2 RNN 的致命问题：梯度消失/爆炸

```
BPTT (Back-Propagation Through Time):

  ∂L/∂h₀ = ∂L/∂h_T · ∂h_T/∂h_{T-1} · ∂h_{T-1}/∂h_{T-2} · ... · ∂h₁/∂h₀
          └─────────────────── T 次乘法 ────────────────────┘

每次乘法包含 W_h。如果 W_h 的特征值:
  > 1 → 梯度爆炸 (T 步后巨大)
  < 1 → 梯度消失 (T 步后趋近于 0 → 无法学习长程依赖)
```

**后果**：RNN 只能记住最近 ~10-20 步的信息。对于需要跨越几十步的因果推理（"我 30 秒前把杯子放在了桌上，现在它在哪儿？"），基本 RNN 完全失效。

## 3. LSTM/GRU：带"门"的记忆升级

### 3.1 LSTM 的三个门

LSTM 引入了**显式的记忆操作**——不再把一切压缩到 $h_t$ 中，而是分开维护"长期记忆" $c_t$ 和"短期输出" $h_t$。

```
遗忘门 f_t = σ(W_f·[h_{t-1}, x_t])   → 从长期记忆中删掉不重要的
输入门 i_t = σ(W_i·[h_{t-1}, x_t])   → 挑选新信息写入记忆
输出门 o_t = σ(W_o·[h_{t-1}, x_t])   → 从记忆中读出需要输出的部分

候选记忆 c̃_t = tanh(W_c·[h_{t-1}, x_t])
新长期记忆 c_t = f_t ⊙ c_{t-1}  +  i_t ⊙ c̃_t
              └── 选择性遗忘 ─┘   └── 选择性写入 ─┘
新输出     h_t = o_t ⊙ tanh(c_t)
```

**直观理解**：
- 遗忘门 = "毕业了，我不用再记高考数学公式了"
- 输入门 = "刚发现抓取力 < 0.1N 是个危险信号，我得记住"
- 输出门 = "现在需要用到力觉信息来判断是否脱手"

### 3.2 GRU：LSTM 的简化版

GRU 把遗忘门和输入门合并成一个"更新门"，更简洁但表达力稍弱：

$$z_t = \sigma(W_z·[h_{t-1}, x_t]) \quad \text{(更新门: 旧的留多少 vs 新的加多少)}$$
$$r_t = \sigma(W_r·[h_{t-1}, x_t]) \quad \text{(重置门: 是否忽略旧历史)}$$
$$\tilde{h}_t = \tanh(W_h·[r_t ⊙ h_{t-1}, x_t])$$
$$h_t = (1-z_t) ⊙ h_{t-1} + z_t ⊙ \tilde{h}_t$$

### 3.3 即便有门控，RNN 家族仍有三个硬伤

| 痛点 | 原因 | 后果 |
|------|------|------|
| **串行依赖** | $h_t$ 必须先算出才能算 $h_{t+1}$ | 无法并行训练，速度慢 |
| **长程依赖仍弱** | 门控只能缓解梯度消失，不能根除 | 超过 ~100 步的信息仍会衰减 |
| **显存效率低** | BPTT 需要存每个时间步的中间结果 | 长序列训练显存爆炸 |

**这三个硬伤 → Transformer 诞生 → RNN 家族在大多数领域被取代。**

但在世界模型中，**RSSM 仍然用 GRU 风格的递归单元**——为什么？见 [[#5. RNN 在世界的复活|第 5 节]]。

## 4. Transformer 的序列处理

> 详见 [[../Transformer与注意力/Transformer与注意力|Transformer与注意力]]。这里只从"序列建模演进"的视角讲核心差异。

### 4.1 一句话：Self-Attention 消除了循环

```
RNN:  每步依赖上一步 → 串行
      x₀ → x₁ → x₂ → x₃ → ...

Transformer: 所有位置两两直接通信 → 并行
      x₀ ←→ x₁
      ↕      ↕
      x₂ ←→ x₃
```

Self-Attention 让序列中**任意两个位置**之间都有一条"高速公路"——信息不需要经过中间所有时间步，梯度也不需要。

### 4.2 关键对比

| 维度 | RNN/LSTM | Transformer |
|------|----------|-------------|
| **训练并行度** | 串行 (O(T)) | 并行 (O(1)) |
| **长程依赖** | 随距离衰减 | 任意距离的直接连接 |
| **推理速度** | O(1) 每步（只更新 h_t） | O(T) 每步（需要算所有 past token） |
| **长序列显存** | 线性增长 | 平方增长（attention map） |
| **归纳偏置** | 时间序（位置就是顺序） | 无时间序 → 需要位置编码 |

### 4.3 为什么位置编码是必须的

Transformer 的 Self-Attention 是**置换等变**的——如果打乱输入顺序，输出也跟着打乱。这"真空中的球形鸡"特性意味着它天然**不知道**什么是"先后"。

位置编码（Sinusoidal / RoPE / Learned）强行注入位置信息 → Transformer 才能处理序列。见 [[../Transformer与注意力/位置编码与归一化|位置编码详解]]。

## 5. RNN 在世界的复活：RSSM

如果 RNN 有那么多缺点，为什么世界模型的 **RSSM (Recurrent State Space Model)** 还在用它？

### 5.1 RSSM = RNN + State Space Model

```
RSSM 的结构:

确定性状态 (GRU 风格):  h_t = GRU(h_{t-1}, s_{t-1}, a_{t-1})
随机状态 (VAE 风格):   s_t ~ p(s_t | h_t)

其中:
  h_t: deterministic → 累积历史确定性信息
  s_t: stochastic → 建模多种可能的未来 (多模态)
```

### 5.2 RNN 在世界中的优势

| 优势 | 为什么重要 |
|------|-----------|
| **推理时只需 O(1)** | 推理时只更新当前隐藏状态，不需要重新处理全部历史 |
| **自然的马尔可夫结构** | 物理世界大多满足 Markov 性——当前状态+动作 → 下一状态 |
| **紧凑的状态表示** | RNN 把历史压缩到固定维度的 h_t → 非常适合潜空间规划 |
| **训练内存低** | 不需要存 attention matrix → 可以做更长的 rollout |

### 5.3 融合趋势：Transformer + RNN 混合

```
最前沿: Transformer 世界模型 (TWM)  +  RNN 动力核心
  
  Transformer: 并行编码观测 → 丰富的视觉表示
        ↓
  RNN (RSSM): 在潜空间做序列动力学 → 高效 rollout
        ↓
  规划 (MPC/Actor-Critic): 在潜空间中想象未来
```

这就是 [[../../06-世界模型/世界模型方向综述|世界模型方向综述]] 中 Dreamer 系列的核心设计。
