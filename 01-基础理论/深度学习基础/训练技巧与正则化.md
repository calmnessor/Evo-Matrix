# 训练技巧与正则化

> 让深度学习模型训练稳定、泛化好的关键技巧。

---

## 1. 归一化 (Normalization)

| 方法 | 归一化轴 | 使用位置 | 适用 |
|------|---------|---------|------|
| **Batch Norm** | 沿 batch 维度 | CNN 的卷积层后 | CV (大 batch) |
| **Layer Norm** | 沿 feature 维度 | Transformer 每个子层后 | NLP/**VLA** |
| **Group Norm** | 沿 channel 分组 | CNN (小 batch 替代 BN) | 检测/分割 |
| **RMS Norm** | Layer Norm 简化版 | LLaMA 中替代 LN | 大模型加速 |

**为什么 Transformer 用 Layer Norm 而不用 Batch Norm？**
- Batch Norm 的统计量依赖 batch size，batch 小 → 统计不稳定
- Layer Norm 对每个样本独立归一化，不依赖 batch
- Transformer 序列长度可变 → Layer Norm 天然处理

## 2. 激活函数

| 激活函数 | 公式 | 特点 | 使用 |
|---------|------|------|------|
| **ReLU** | $\max(0, x)$ | 简单高效，但负数端"死亡" | CNN/MLP |
| **GELU** | $x \cdot \Phi(x)$ | 平滑的 ReLU，处处可导 | **Transformer/LLM 标配** |
| **SiLU/Swish** | $x \cdot \sigma(x)$ | GELU 的近似 | LLaMA 使用 |
| **GeLU vs ReLU** | GELU 在负数端保留小梯度 | 更多信息流 | ViT/BERT/GPT |

## 3. 学习率调度

```python
# Warmup + Cosine Decay — LLM/VLA 训练标配
scheduler = torch.optim.lr_scheduler.SequentialLR(
    optimizer,
    [
        LinearLR(optimizer, start_factor=0.1, total_iters=1000),   # warmup
        CosineAnnealingLR(optimizer, T_max=99000),                  # cosine decay
    ],
    milestones=[1000]
)
```

**为什么需要 warmup？** 训练初期，梯度的方向和尺度都不稳定 → 直接大步长容易训练崩溃。warmup 让模型"小步探索"找到合适的方向，然后逐步加大步伐。

## 4. 常用技巧汇总

| 技巧 | 作用 | 使用场景 |
|------|------|---------|
| **Gradient Clipping** | 防止梯度爆炸 | RNN/Transformer 训练标配 |
| **Dropout** | 随机丢弃神经元 → 防过拟合 | 小数据微调时推荐 |
| **Weight Decay** | L2 正则，鼓励小权重 | AdamW 标配 |
| **Gradient Accumulation** | 多步累加梯度再更新 → 模拟大 batch | 显存不够时的救命稻草 |
| **Mixed Precision (fp16/bf16)** | 半精度训练，加速 + 省显存 | 所有 VLA 训练几乎都用 |
| **EMA (指数移动平均)** | 模型参数平滑平均 | 提升模型稳定性 |

### 4.1 Gradient Clipping 细节

```python
# 在 loss.backward() 之后，optimizer.step() 之前
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

梯度裁剪将梯度向量缩放到 max_norm 以内，防止单步更新过大导致训练崩溃。Transformer 天然需要这个——长序列中 attention 的梯度容易爆炸。

### 4.2 Mixed Precision 原理

```
fp32: 1-bit sign + 8-bit exponent + 23-bit mantissa (4 bytes)
fp16: 1-bit sign + 5-bit exponent + 10-bit mantissa (2 bytes)
bf16: 1-bit sign + 8-bit exponent + 7-bit mantissa (2 bytes)
```

- fp16：指数范围小（max 65504），容易溢出，需要 loss scaling
- bf16：指数范围和 fp32 一样，不需要 loss scaling，但精度低
- **推荐**：能用 bf16 就用 bf16（A100/4090 支持），否则用 fp16 + gradient scaling

### 4.3 EMA 公式

$$\theta_{EMA} \leftarrow \alpha \cdot \theta_{EMA} + (1-\alpha) \cdot \theta_{current}$$

$\alpha$ 通常取 0.999-0.9999。EMA 模型通常比最新 checkpoint 更稳定，适合做最终评测。
