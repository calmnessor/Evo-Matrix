# 大语言模型与微调

> VLA 中 L = Language——理解指令，推理任务

## 核心概念

### 自回归语言模型
- 给定前文预测下一个 token: P(x_t | x_{<t})
- GPT 系列 / LLaMA 系列 都属此类
- 训练: Cross-Entropy Loss on next-token prediction

### Tokenizer
- 文本 → token id 序列
- BPE (Byte-Pair Encoding) 是主流
- VLA 中扩展了 "动作 token" 到词表

### Scaling Law
- Loss ∝ C^(-0.154) × N^(-0.074) × D^(-0.095)
- 更大的模型 + 更多数据 + 更多计算 = 更好的性能
- 也是 VLA 的核心问题：怎么 scale？

## 微调方法

### Full Fine-Tuning
- 全参数更新 → 最大效果，最大成本

### LoRA (Low-Rank Adaptation)
- 在权重旁加低秩矩阵: W' = W + B·A
- 只训练 B 和 A → 参数极小
- **VLA 微调标配**: OpenVLA 用 LoRA 做少量机器人数据自适应

### QLoRA
- LoRA + 4-bit 量化 → 消费级 GPU 微调大模型

## 在 VLA 中的角色

```
RT-2: PaLI-X / PaLM-E 作为 Backbone → 自回归生成动作 token
OpenVLA: LLaMA-7B 作为 Backbone → 处理视觉+语言 token
π₀: 自己的 VLM → Flow Matching 生成动作
```
