# 3D Gaussian Splatting

> 2024-2025 年最热的 3D 场景表示。显式高斯球 + 光栅化 = 100+ FPS 实时渲染 + 天然适合 affordance 定位和场景编辑。

---

## 1. 为什么 3DGS 替代了 NeRF？

| | NeRF | 3DGS |
|------|------|------|
| 表示 | 隐式 MLP（神经网络存场景） | 显式高斯球（参数直接存场景） |
| 渲染方式 | 体渲染（沿光线积分，需推理 MLP） | 光栅化（投影 + α-blending） |
| 渲染速度 | 慢（几十秒/帧） | **100+ FPS** (实时) |
| 训练时间 | 小时级 | **分钟级** |
| 编辑能力 | 困难（隐式，不知道改哪个神经元） | **容易**（直接移动/删除/复制高斯球） |
| 与 affordance 结合 | 间接（需提取表面） | 天然（每个高斯球可附加 affordance 标签） |

**一句话**：3DGS 把场景表示为**数百万个有颜色的、半透明的 3D 椭球**。每个椭球有明确的位置和形状——你可以直接看见它、移动它、删除它。

## 2. 核心原理

### 2.1 每个高斯球的参数（59 个浮点数）

| 参数 | 维度 | 含义 |
|------|------|------|
| 中心 $\mu$ | 3 | 高斯球的 3D 位置 $(x, y, z)$ |
| 协方差 $\Sigma$ | 7 | 缩放(3) + 旋转四元数(4) → 椭球形状和朝向 |
| 透明度 $\alpha$ | 1 | 0=完全透明, 1=完全不透明 |
| 球谐系数 (SH) | 48 | 4阶×3通道(RGB)×4系数 → 视角相关的颜色 |

### 2.2 渲染流程

```
1. 把所有 3D 高斯球投影到 2D 图像平面
   → 3D 椭球 → 投影 → 2D 椭圆
   
2. 按深度排序所有 2D 椭圆（从远到近）

3. α-blending 逐像素合成：
   C_pixel = Σ_i c_i · α_i · Π_{j=1}^{i-1} (1 - α_j)
   
   这和 NeRF 的体渲染公式一样，但：
   - NeRF: 每个采样点都要过 MLP → 慢
   - 3DGS: 直接用高斯参数算 → 快
```

### 2.3 训练：自适应密度控制

```
从 SfM 稀疏点云初始化 N 个高斯球

训练循环:
  1. 渲染一个视角
  2. 计算与真实图像的 L1 + D-SSIM loss
  3. 反向传播更新高斯参数
  4. 自适应密度控制:
     - 梯度大的区域 → Split (一分为二) 或 Clone (复制一份)
     - α 太小的 → 删除
     
最终: 从几千个高斯球增长到几百万个，精确覆盖场景
```

Split vs Clone 的区别：
- **Clone**（小梯度）：在高斯球旁边生成一个副本 → 覆盖欠重建区域
- **Split**（大梯度）：一个高斯球分裂成两个小的 → 增加细节分辨率

## 3. 在具身智能中的应用

### 3.1 Affordance + 3DGS（2024-2025 热点）

3DGS 的显式结构天然适合 affordance 推理：

```
输入: 多视角 RGB-D → 3DGS 重建 → 每个高斯球有一个特征向量

Affordance 预测:
  方法 A: 用 PointNet++ 处理高斯中心 → 逐点 affordance label
  方法 B: 用 VLM 引导 → 语言查询"哪里能抓" → 特征相似度检索

输出: 每个高斯球的 affordance score → 渲染 affordance map
```

**代表工作**：
- **ManiGaussian** (ECCV 2024)：3DGS + 动态场景 affordance
- **3DAffordSplat** (CVPR 2025)：首个大规模 3DGS affordance 数据集 + AffordSplatNet
- **SeqAffordSplat** (AAAI 2026)：场景级序列化 affordance 推理，LLM 规划 + 3DGS 执行
- **GauTOAO** (2024)：3DGS 任务导向 affordance，零样本 VLM 引导
- **Splat-MOVER** (2024)：3DGS 语义 + 抓取 affordance + 场景编辑

### 3.2 VLA 数据增强

```
真实场景 → 3DGS 重建 → 渲染无穷多新视角 → 训练 VLA

优势:
  - 视角不变性: 从 10 张照片生成 1000 个视角的训练数据
  - 光照/背景编辑: 移除背景物体、改变光照
  - 动作标注复用: 在 3DGS 中标注一次动作，渲染到各视角
```

### 3.3 抓取位姿评估

在 3DGS 重建的场景中：
1. 采样候选抓取位姿 → 投影到多视角
2. 在渲染图上评估抓取质量
3. 选最优抓取 → 执行

**优势**：不需要在真实机器人上反复试错，在"数字孪生"中验证。

## 4. 当前局限

| 局限 | 说明 | 缓解方向 |
|------|------|---------|
| 对动态场景不稳定 | 物体移动后高斯球还是老位置 | 动态 3DGS / 增量更新 |
| 依赖 SfM 初始化 | COLMAP 慢了就卡脖子 | 前馈网络直接预测高斯 (pixelSplat) |
| 存储量大 | 百万级高斯球 = 几百 MB | 压缩/剪枝/VQ |
| 镜面/透明物体 | 高斯球假设漫反射 | 改进颜色表示 |
