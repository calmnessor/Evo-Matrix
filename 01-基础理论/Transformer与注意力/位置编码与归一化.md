# 位置编码与归一化

> Transformer 看不到 token 的顺序——位置编码补上这份信息。归一化保证深层网络训练稳定。

---

## 1. 位置编码的三种方案

### 1.1 Sinusoidal (原始论文)

$$PE_{(pos, 2i)} = \sin\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$
$$PE_{(pos, 2i+1)} = \cos\left(\frac{pos}{10000^{2i/d_{model}}}\right)$$

- 每个维度的频率按几何级数递减（从 $2\pi$ 到 $10000 \cdot 2\pi$）
- 优点：可以外推到训练时没见过的长度（不需要学，纯数学函数）
- 缺点：固定不可学习，不能根据数据自适应

### 1.2 Learnable Position Embedding

把位置当作可学习参数：`nn.Embedding(max_seq_len, d_model)`

- BERT、GPT-2、ViT 使用
- 优点：灵活，数据驱动
- 缺点：无法外推序列长度（超过 max_seq_len 就报错）

### 1.3 RoPE (Rotary Position Embedding)

**现代 LLM 的主流方案**（LLaMA、Qwen、Mistral 都用）。

核心思想：不把位置加到 embedding 上，而是用旋转矩阵改造 attention 计算中的 Q 和 K：

$$\tilde{q}_m = q_m \cdot R_m, \quad \tilde{k}_n = k_n \cdot R_n$$

其中 $R_m$ 是角度为 $m\theta$ 的旋转矩阵。这样 Q 和 K 的点积自然包含相对位置信息：

$$\tilde{q}_m^T \tilde{k}_n = q_m^T R_{n-m} k_n$$

**优势**：
- 自然地融入了相对位置信息
- 可外推到更长序列（通过插值 $\theta$）
- 不增加参数量

| 方案 | 外推能力 | 参数量 | 代表模型 |
|------|---------|--------|---------|
| Sinusoidal | 好 | 0 | 原始 Transformer |
| Learnable | 差（固定 max_len） | len×d | BERT, ViT |
| RoPE | 好（通过插值） | 0 | LLaMA, Qwen, Mistral |

## 2. 归一化位置的选择

### 2.1 Post-Norm (原始论文)

```
x = Norm(x + Sublayer(x))
```

归一化在残差之后。原始 Transformer 用的方案。问题：深层时梯度主要流过归一化，残差路径被"稀释" → 训练不稳定。

### 2.2 Pre-Norm (现代标配)

```
x = x + Sublayer(Norm(x))
```

归一化在残差之前。GPT、LLaMA、ViT 都用这个。

**为什么 Pre-Norm 更好？**
- 残差路径保持"干净"的恒等映射 → 梯度可以从顶层直通底层
- 训练更稳定，warmup 要求更低
- 这是 LLaMA 能训练到 70B+ 的关键设计之一

### 2.3 各模型归一化选择

| 模型 | 归一化方案 | 归一化类型 |
|------|----------|----------|
| 原始 Transformer | Post-Norm | Layer Norm |
| BERT | Post-Norm | Layer Norm |
| GPT-2/3 | Pre-Norm | Layer Norm |
| LLaMA | Pre-Norm | **RMS Norm** |
| ViT | Pre-Norm | Layer Norm |

### 2.4 RMS Norm

LLaMA 用的简化版 Layer Norm：

$$\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum x_i^2 + \epsilon}} \cdot \gamma$$

相比 Layer Norm：去掉了均值中心化（$\mu=0$ 假设），只保留缩放。速度更快，效果几乎一致。
