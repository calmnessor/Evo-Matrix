# 深度学习基础

> VLA 的地基——理解神经网络如何从数据中学习

## 核心概念

### 多层感知机 (MLP)
- 线性层 + 激活函数堆叠
- 万能近似定理：足够宽的 MLP 可以逼近任意连续函数

### 卷积神经网络 (CNN)
- 局部感受野、权重共享、池化
- 从图像中提取层次化特征
- VLA 中逐渐被 ViT 替代，但仍是重要的基础

### 反向传播
- 链式法则自动求梯度
- 梯度下降更新参数
- 理解 loss → grad → update 的闭环

### 训练技巧
- Batch Normalization / Layer Normalization
- Dropout 正则化
- 学习率调度 (Cosine, Warmup)
- 梯度裁剪

## 在 VLA 中的角色

```
VLA 的每个模块都是神经网络:
  视觉编码器 = ViT (特殊的 Transformer)
  语言编码器 = Transformer / LLM
  动作解码器 = MLP / Transformer
```
