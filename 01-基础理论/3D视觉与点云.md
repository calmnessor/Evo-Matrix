# 3D 视觉与点云

> VLA 的 Vision 不应止于 2D——机器人在 3D 世界中行动，必须理解深度、空间关系和 3D 结构。

## 为什么具身智能需要 3D 视觉？

2D 视觉告诉你"图像里有一只杯子"，但机器人需要知道："杯子在我前方 0.5 米处，杯口朝上，距离桌沿 3cm"。这些是 **2D 图像无法直接提供** 的信息：

| 任务 | 2D 能做的 | 必须 3D 才能做的 |
|------|----------|----------------|
| 抓取杯子 | 识别杯子类别 | 估计杯柄的 6-DoF 抓取位姿 |
| 推开障碍物 | 检测障碍物存在 | 判断障碍物在物体前方还是后方 |
| 插拔 USB | 识别 USB 口 | 对齐插头的 3D 朝向和深度 |
| 叠放物品 | 检测物体 | 理解物体的 3D 体积和堆叠关系 |

**一句话**：2D 负责"是什么"，3D 负责"在哪里、怎么操作"。

## 1. 机器人怎么"看"3D 世界？——传感器

在进入算法之前，先了解数据从哪里来。

### 1.1 深度相机 (RGB-D)

| 传感器 | 原理 | 精度 | 典型距离 | 缺点 |
|--------|------|------|----------|------|
| **RealSense D435** | 主动立体红外 | mm 级 | 0.1-10m | 阳光下失效，透明物体不行 |
| **Kinect v2** | ToF (飞行时间) | cm 级 | 0.5-4.5m | 已停产，但学术界还在用 |
| **ZED 2** | 被动双目立体 | cm 级 | 0.2-20m | 依赖纹理，低纹理场景差 |
| **iPhone LiDAR** | dToF | mm-cm 级 | 0.1-5m | 范围有限 |

### 1.2 LiDAR (激光雷达)

- **机械式 LiDAR** (Velodyne, Ouster)：360° 扫描，自动驾驶标配，精密但贵
- **固态 LiDAR** (Livox, 禾赛)：非重复扫描，更便宜，机器人领域增长快
- **输出**：点云 (point cloud)，每秒可达百万点

### 1.3 多视角 (Multi-view)

- 多个普通 RGB 相机从不同角度拍摄
- 通过 **Structure from Motion (SfM)** 或 **Multi-View Stereo (MVS)** 重建 3D
- 成本低但计算量大，需要重叠视场

> **课题组常用**：RealSense D435（桌面操作）+ ZED 2（移动操作）。仿真中直接用 MuJoCo/IsaacSim 的渲染深度图。

## 2. 核心 3D 表示

### 2.1 点云 (Point Cloud)
- **定义**：无序点集 $\{(x_i, y_i, z_i, f_i)\}$，$f_i$ 可以是 RGB、法向量、强度等
- **来源**：深度相机 / LiDAR / SfM 重建
- **三大特性**（理解这三个才能理解 PointNet 的设计）：
  1. **无序性 (Unordered)**：点云是集合而非序列，$\{A,B,C\}$ 和 $\{C,A,B\}$ 是同一个点云
  2. **稀疏性 (Sparse)**：大部分空间是空的，只有物体表面有点
  3. **旋转不变性需求**：同一个杯子，换个角度看到的点云坐标完全不同，但语义应该一致

| 优点 | 缺点 |
|------|------|
| 原始数据，无信息损失 | 无拓扑结构，邻域搜索需 KNN/半径查询 |
| 存储高效（只存有点的地方） | 采样密度不均匀 |
| 直接反映传感器输出 | 缺少面/体积信息 |

### 2.2 深度图 (Depth Map)
- **定义**：每个像素值 = 该点到相机的距离，本质是 2.5D
- **优点**：2D 卷积可直接用，实时性好，与 RGB 天然对齐
- **缺点**：遮挡区域无信息（背面看不到），单视角不完整
- **典型分辨率**：640×480 (RealSense)，1280×720 (ZED 2)

### 2.3 体素 (Voxel Grid)
- **定义**：3D 空间的规则网格，每个格子存"是否被占据"或特征
- **优点**：3D 卷积直接套用，有规则拓扑
- **致命缺点**：内存 $O(n^3)$，$32^3=32768$ 个体素，$128^3=2097152$，指数爆炸
- **缓解方案**：稀疏体素 (sparse voxel) / 八叉树 (octree)，只存有内容的格子

### 2.4 TSDF / Occupancy (截断符号距离函数)

- **TSDF (Truncated Signed Distance Function)**：
  - 空间中每个点的值 = 到最近表面的距离（正=在表面前，负=在表面后），超过截断值就截断
  - 融合多帧深度图时特别好用（KinectFusion 的基础）
  - 零值面 (zero level-set) = 物体表面

- **Occupancy Grid**：
  - 简化版：每个格子存三个概率 {occupied, free, unknown}
  - 机器人导航中大量使用 (OctoMap)

### 2.5 隐式表示 (Implicit Representation)

不是显式存储 3D 形状，而是一个神经网络 $f(x,y,z) \rightarrow$ (是否在表面上, 颜色, 特征)。

- **NeRF**：$f(x,y,z,\theta,\phi) \rightarrow (RGB, \sigma)$
- **Occupancy Network**：$f(x,y,z) \rightarrow [0,1]$
- **NeuS / VolSDF**：引入 SDF 到 NeRF 框架
- **优缺点**：连续且有表达能力，但推理慢，需要额外步骤提取 mesh

### 2.6 3D 高斯泼溅 (3D Gaussian Splatting)

- 用数百万个 3D 高斯椭球表示场景
- 每个高斯：中心 $\mu$ + 协方差 $\Sigma$ + 透明度 $\alpha$ + 球谐系数（颜色）
- **核心优势**：实时渲染 (100+ FPS)，显式表示方便编辑
- **与 NeRF 对比**：

| | NeRF | 3DGS |
|------|------|------|
| 表示 | 隐式 MLP | 显式高斯球 |
| 渲染速度 | 慢 (需要网络推理) | 快 (光栅化) |
| 编辑能力 | 困难 | 容易 (直接操作高斯球) |
| 训练速度 | 小时级 | 分钟级 |

> **课题组相关**：参见 `2025.06高斯泼溅/` 目录中课题组已有积累。

### 选型速查

| 场景 | 推荐表示 |
|------|---------|
| 实时避障 / 导航 | 体素 / OctoMap |
| 精细操作 (抓取) | 点云 + 法向量 |
| 场景重建 / 新视角合成 | NeRF / 3DGS |
| 多传感器融合 | TSDF (如 KinectFusion) |

## 3. 点云处理必备操作

### 3.1 预处理

- **降采样 (Downsampling)**：体素网格滤波器 (VoxelGrid)、最远点采样 (FPS)、随机采样 —— PointNet++ 用 FPS
- **去噪 (Denoising)**：统计滤波 (Statistical Outlier Removal)、半径滤波
- **法向量估计**：对每个点取 K 近邻拟合平面，法向量 = 平面法向。后续特征描述子 (FPFH, SHOT) 都依赖法向量

### 3.2 配准 (Registration) — ICP 算法

**问题**：你有两个不同视角的点云，怎么把它们拼在一起？

**ICP (Iterative Closest Point)** —— 点云配准的"手写数字识别"级经典算法：

```
Repeat:
  1. 对 A 中每个点，找 B 中最近点（对应关系）
  2. 计算最优刚体变换 (R, t) 最小化对应点距离
  3. A ← R*A + t
Until 收敛
```

**变体**：
- **Point-to-Plane ICP**：利用法向量，收敛更快
- **ICP 的局限**：需要好的初始位姿，否则陷入局部最优

**实际使用**：先 RANSAC + FPFH 特征匹配做粗配准，再 ICP 做精配准。

### 3.3 分割 (Segmentation)

- **语义分割**：每个点打类别标签（桌子、杯子、人手…）
- **实例分割**：区分同一类别的不同个体（桌子上有 3 个杯子 → 分别标注杯子1/2/3）
- **经典方法**：PointNet++ 做语义分割，3D-BoNet 做实例分割
- **现代方法**：Mask3D, SAM-3D（把 SAM 的思路搬到 3D）

### 3.4 目标检测与位姿估计

- **6-DoF 位姿估计**：给定物体 3D 模型，估计它当前在世界坐标系中的 (x, y, z, roll, pitch, yaw)
- **常用方案**：
  - **PPF (Point Pair Feature)**：工业级，全局描述子匹配
  - **DenseFusion**：RGB + 点云融合，端到端学习
  - **FoundationPose**：2024 年 SOTA，基于大模型
- **对抓取的意义**：抓取位姿 = 物体位姿 × 抓取点偏移

## 4. 点云深度学习

### 4.1 PointNet (CVPR 2017) — 开山之作

**核心思想**：用一个对称函数 (Max Pooling) 解决点云的无序性。

```
输入: N×3 点云
  ↓
T-Net (3×3) —— 学习旋转矩阵，对齐点云
  ↓
MLP (3→64→64) —— 逐点升维
  ↓
T-Net (64×64) —— 特征空间对齐
  ↓
MLP (64→128→1024) —— 逐点升维
  ↓
Max Pooling (对称函数) —— ∀顺序 → 同一个全局特征向量
  ↓
MLP (1024→512→256→K) —— 分类/分割输出
```

**两个 T-Net 的作用**：
1. **输入 T-Net**：输出 3×3 矩阵，预测一个旋转变换把原始点云"摆正"——让网络对刚体旋转具有等变性
2. **特征 T-Net**：输出 64×64 矩阵（很大会过拟合），在特征空间做对齐——实际中贡献有限，很多实现直接省略

**为什么 Max Pooling 解决无序性**：$\max\{a,b,c\} = \max\{c,a,b\}$，无论输入顺序怎么变，max 结果不变。所以 PointNet 的关键方程是：

$$f(\{x_1, ..., x_n\}) \approx g(h(x_1), ..., h(x_n))$$

其中 $h$ 是 MLP（逐点特征提取），$g$ 是对称函数（Max Pooling）。

**局限**：只提取全局特征，缺乏局部结构建模。点之间的空间关系几乎没有利用。

### 4.2 PointNet++ (NeurIPS 2017) — 层次化特征

**核心思想**：模仿 CNN 的"局部感受野 → 逐层扩大"范式：

```
PointNet++ 多层:
  1. Sampling (FPS 选中心点)
  2. Grouping (Ball Query 取邻域点)
  3. PointNet on each group → 局部特征
  ↓
  重复 1-3（抽象层级递增）
  ↓
  全局 PointNet → 最终特征
```

- **Sampling — FPS (Farthest Point Sampling)**：选与已选点距离最远的点作为新中心点。能均匀覆盖点云，但计算量 $O(N \cdot n_{centers})$
- **Grouping — Ball Query**：以每个中心点为圆心，半径 $r$ 内的所有点组成一个 group
- **Multi-scale Grouping (MSG)**：用多个半径 $(r_1, r_2, r_3)$ 分别 group 再 concat，应对密度不均
- **Multi-resolution Grouping (MRG)**：并行用低层局部和高层全局信息，更轻量

**PointNet vs PointNet++ 对比**：

| | PointNet | PointNet++ |
|------|----------|------------|
| 特征层次 | 只有全局 | 局部 → 全局 (多尺度) |
| 局部结构 | 忽略 | Ball Query 显式建模 |
| 密度适应性 | 差 | MSG/MRG 处理 |
| 适合任务 | 分类 | 分割、检测、抓取位姿 |

### 4.3 后续重要工作

- **DGCNN (2019)**：用 EdgeConv 动态构建 KNN 图，在每层根据特征空间距离重构图结构
- **Point Transformer (2021)**：自注意力引入点云，$\text{Attention}(Q, K, V)$ 作用在点云 KNN 邻域上
- **PointNet++ 实战提示**：分类用 1024 点，分割用 4096 点，抓取位姿预测通常用 2048-4096 点

## 5. 3D 重建与场景表示

### 5.1 NeRF (ECCV 2020)

**一句话**：用一个 MLP 把 3D 场景"记住"，然后从任意视角渲染。

**原理分三步**：
1. **采样**：沿每条相机光线采样 N 个 3D 点
2. **查询 MLP**：$F_\Theta(\mathbf{x}, \mathbf{d}) \rightarrow (\mathbf{c}, \sigma)$，其中 $\mathbf{x}$ = 3D 位置，$\mathbf{d}$ = 视角方向，$\mathbf{c}$ = RGB，$\sigma$ = 体密度
3. **体渲染**：沿光线积分，$\hat{C}(\mathbf{r}) = \sum_i T_i \alpha_i \mathbf{c}_i$，其中 $T_i$ = 累积透明度，$\alpha_i = 1-\exp(-\sigma_i\delta_i)$

**关键技巧**（这些让 NeRF 从不好用到好用）：
- **位置编码 (Positional Encoding)**：$\gamma(x) = (\sin 2^0\pi x, \cos 2^0\pi x, ..., \sin 2^{L-1}\pi x, \cos 2^{L-1}\pi x)$，高频映射让 MLP 能学到细节
- **层级采样 (Hierarchical Sampling)**：粗网络定位物体，细网络在物体附近精细采样
- **对机器人的启发**：NeRF 实现"看几张图 → 重建整个 3D 场景 → 新视角观察"

### 5.2 3D Gaussian Splatting (SIGGRAPH 2023)

**为什么替代 NeRF**：NeRF 每次渲染都要过一遍 MLP → 1080p 渲染需要几十秒。3DGS 用光栅化 → 100+ FPS。

**核心原理**：
1. 从 SfM 稀疏点云初始化 3D 高斯球
2. 每个高斯球 59 个参数：$\mu$(3) + $\Sigma$(通过缩放+旋转表示，7) + $\alpha$(1) + 球谐系数(48, 4阶×3通道×4)
3. 渲染：投影到 2D → 按深度排序 → α-blending（类似 NeRF 体渲染）
4. 自适应密度控制：梯度大的区域 Split/Clone 高斯球

**在机器人中的应用**：
- 用高斯泼溅快速重建操作场景 → 从重建的 3DGS 渲染新视角训练 VLA
- 抓取位姿评估：在 3DGS 重建中模拟抓取

### 5.3 其他重要表示

- **Occupancy Network (2019)**：$f(\mathbf{p}, \mathbf{z}) \rightarrow [0,1]$ 判断空间中任意点是否在物体内部。比 NeRF 更早的隐式 3D 表示
- **Instant NGP (2022)**：多分辨率哈希编码 + 小 MLP，NeRF 从小时级加速到秒级
- **ZoeDepth / Depth Anything**：单目深度估计，从单张 RGB 预测深度图。VLA 常用：不依赖深度相机也能获得 3D 信息

## 6. 3D 视觉在 VLA 中的实际应用

### 6.1 当前范式 vs 3D 范式

```
当前 VLA (2D 为主):
  摄像头 → 2D ViT/SigLIP → 语言指令 → Action Head → 末端位姿
  问题: "前推杯子" 和 "避开杯子" 在 2D 特征里可能很相似

加入 3D 后:
  多视角 RGB / 深度图 → 3D Backbone → 3D 特征
                    ↘            ↙
                  2D 特征 + 3D 特征 融合
                    ↓
              Action Head → 6-DoF 动作
  优势: 明确知道物体的空间位置和表面几何
```

### 6.2 关键论文导读

| 论文 | 3D 用法 | 经验 |
|------|---------|------|
| **3D-VLA** (ICML 2024) | 3D 生成式世界模型 | 用 3D 表示统一预测未来状态和动作 |
| **DP3** (3D Diffusion Policy) | 稀疏点云 → 扩散策略 | 点云输入 + 扩散去噪预测动作序列 |
| **3D Diffuser Actor** | 3D 点云 → 扩散 Transformer | 3D 场景 + 语言 → 多步动作 |
| **PerAct** | 体素化场景 → 动作分类 | 利用体素表示做 6-DoF 操作 |
| **RVT** | 多视角 2D → 3D 回归 | 重投影：在 2D 图像平面做推理再反投回 3D |
| **Act3D** | 3D 特征场 → 抓取评分 | 在 3D 空间中直接评估候选动作 |

### 6.3 课题组实际操作链路

```
实验场景:
1. 多角度拍摄操作台 (或用 RealSense 深度图)
2. 3DGS/NeRF 重建 → 场景的完整 3D 表示
3. 采样抓取候选位姿 → 投影到 2D → VLA 模型评估
4. 执行最优抓取

仿真场景:
1. MuJoCo/IsaacSim → 直接获得真实深度图 + 点云
2. 点云 → PointNet++ 骨干 → 特征
3. 特征 + 语言 → 扩散策略 → 动作序列
```

## 7. 新手学习路线

### 第一阶段：建立直觉（1-2 天）
1. 用 Open3D 可视化一个点云：`open3d.io.read_point_cloud("bunny.ply")`
2. 理解深度图、点云、体素的相互转换
3. 动手：把一张 RealSense 深度图转成点云

### 第二阶段：核心算法（3-5 天）
1. **PointNet**：读论文，跑 [官方代码](https://github.com/charlesq34/pointnet)，理解 Max Pooling 如何解决无序性
2. **PointNet++**：理解 FPS + Ball Query，理解"局部→全局"的层次化
3. **ICP 配准**：用 Open3D 把两个点云拼在一起

### 第三阶段：重建与 VLA 结合（5-7 天）
1. Nerfstudio: 用自己的手机拍一段视频 → 训练一个 NeRF → 自由视角漫游
2. 3DGS: 了解高斯泼溅为什么比 NeRF 快
3. 读 **DP3** 或 **3D Diffuser Actor**：理解 3D 点云如何进入扩散策略

### 入门代码示例（Open3D）

```python
import open3d as o3d
import numpy as np

# 1. 读取点云
pcd = o3d.io.read_point_cloud("bunny.ply")
print(f"点云有 {len(pcd.points)} 个点")

# 2. 降采样
pcd_down = pcd.voxel_down_sample(voxel_size=0.01)

# 3. 估计法向量
pcd_down.estimate_normals(search_param=o3d.geometry.KDTreeSearchParamHybrid(radius=0.02, max_nn=30))

# 4. 可视化
o3d.visualization.draw_geometries([pcd_down], point_show_normal=True)

# 5. ICP 配准示例
source = pcd_down
target = pcd_down.translate((0.1, 0, 0))  # 模拟位移
reg_p2p = o3d.pipelines.registration.registration_icp(
    source, target, max_correspondence_distance=0.02,
    init=np.eye(4),  # 初始变换矩阵
    estimation_method=o3d.pipelines.registration.TransformationEstimationPointToPoint()
)
print(f"ICP 收敛: {reg_p2p.inlier_rmse:.6f}")
```
