# 3D 视觉与点云

> VLA 的 Vision 不应止于 2D——理解深度和 3D 结构

## 核心表示

### 点云 (Point Cloud)
- 无序点集: {(x_i, y_i, z_i, f_i)}
- 从深度相机 / LiDAR 获得
- 特点: 无序性、稀疏性、旋转不变性需求

### 深度图 (Depth Map)
- 每个像素 = 距离
- RealSense / Kinect 输出
- 2D 组织但含 3D 信息

### 体素 (Voxel)
- 3D 像素网格
- 内存消耗大 O(n³)

## PointNet 系列

### PointNet (2017)
**首个直接处理点云的深度网络**

核心创新:
1. 用对称函数 (Max Pooling) 处理无序输入
2. 用 T-Net 学习空间变换（对齐输入）

关键性质:
- 排列不变性 (Permutation Invariance)
- 刚体变换等变性 (Rigid Motion Equivariance)

### PointNet++
- 层次化特征学习（类似 CNN 的层次化）
- Sampling + Grouping + PointNet on each group
- 局部特征 → 全局特征

## 3D 重建

### NeRF (Neural Radiance Fields)
- 从 2D 图像学习 3D 场景的隐式表示
- 输入: (x, y, z, θ, φ) → 输出: (RGB, σ) 密度
- 体渲染合成新视角

### 3D Gaussian Splatting
- 用 3D 高斯球表示场景 → 替代 NeRF
- 实时渲染 + 更高质量
- 课题组有相关积累: `2025.06高斯泼溅/`

## 在 VLA 中的应用方向

```
当前 VLA (2D):
  摄像头 → 2D ViT → 动作

未来 VLA (3D):
  多视角 / 深度图 → 3D 特征 → 2D+3D 融合 → 动作
  可能的改进:
    → 更好的空间理解（"把杯子往前推"）
    → 理解遮挡关系
    → 精确的 6-DoF 操作
```
