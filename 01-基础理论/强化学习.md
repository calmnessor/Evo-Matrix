# 强化学习

> 试错学习——机器人通过环境反馈优化策略

## 核心要素

```
智能体 → 执行动作 a → 环境给奖励 r + 新状态 s'
   ↑                                              │
   └──────── 更新策略 π(a|s) ←────────────────────┘
```

| 要素 | 符号 | 含义 |
|------|------|------|
| State | s | 环境状态（观测） |
| Action | a | 智能体动作 |
| Reward | r | 即时奖励信号 |
| Policy | π(a\|s) | 策略：给定状态选动作 |
| Value | V(s) | 状态价值：从 s 出发的预期累积奖励 |
| Q-Value | Q(s,a) | 动作价值：从 (s,a) 出发的预期累积奖励 |

## MDP (Markov Decision Process)

$$(S, A, P, R, \gamma)$$
- S: 状态空间
- A: 动作空间
- P(s'|s,a): 状态转移概率
- R(s,a): 奖励函数
- γ: 折扣因子（权衡短期 vs 长期）

## 主要算法

### Policy Gradient
- 直接学策略 π(a|s)
- REINFORCE: 用轨迹奖励加权梯度
- 方差大，样本效率低

### Actor-Critic
- Actor: 策略 π(a|s) — "怎么做"
- Critic: 价值 V(s) — "做得好不好"
- 减少方差，更稳定

### PPO (Proximal Policy Optimization)
- **机器人 RL 的工业标准**
- 用 clip 限制策略更新幅度
- 配合 GAE 做优势估计

### SAC (Soft Actor-Critic)
- 最大熵 RL → 鼓励探索
- Off-policy → 样本效率更高
- 适合高维连续动作空间

## RL for Robotics 的挑战

1. **样本效率低** — 需要大量试错
2. **安全性** — 真实机器人试错可能损坏
3. **奖励设计** — 什么算"做得好"？
4. **Sim-to-Real Gap** — 仿真学的 → 现实可能不行

## Sim-to-Real Transfer

### Domain Randomization
训练时随机化: 光照、纹理、摩擦、质量、延迟
→ 模型被迫学"本质"而非"表面"

### Domain Adaptation
用少量真实数据微调仿真训练的策略

## 在 VLA 中的角色

```
模仿学习 (BC/IL):  演示数据 → 监督学习（VLA 主要方式）
强化学习 (RL):     试错 → 奖励驱动 → 超越演示
混合 (IL + RL):    BC 初始化 → RL 微调（最实用）
```
