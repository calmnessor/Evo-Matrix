# 行为克隆 (Behavior Cloning, BC)

> VLA 最基础也最核心的学习方法——从人类演示中"抄作业"

## 核心思想

```
人类遥操作 → 收集 (观测, 动作) 对 → 监督学习 → 模仿人类动作
```

## 数学形式

$$\theta^* = \arg\min_\theta \mathbb{E}_{(o, a) \sim \mathcal{D}} \left[ \| \pi_\theta(o) - a \|^2 \right]$$

就是一个回归问题：给定观测 o，预测动作 a，MSE Loss。

## 代码骨架

```python
# BC 训练循环
for obs, action in dataloader:
    pred_action = policy(obs)
    loss = F.mse_loss(pred_action, action)
    loss.backward()
    optimizer.step()
```

就这么简单。RT-1、RT-2、OpenVLA 本质上都在做 BC。

## 核心问题: 分布漂移 (Distribution Shift)

```
训练时: 策略看到的是"专家"的观测分布
测试时: 策略看到的是"自己之前动作"导致的观测分布

误差累积:
  小误差 → 进入没见过的情况 → 更大误差 → 崩溃

  "偏离训练分布越远，错得越离谱"
```

### 缓解方法
1. **DAGGER**: 在线收集策略访问的状态 → 请专家标注 → 加入训练集
2. **Action Chunking**: 一次预测多步 → 减少累积误差 → [[ACT]]
3. **数据增强**: 在观测上加噪声 → 提高鲁棒性
4. **多任务训练**: 见更多场景 → 泛化更好

## 在 VLA 中的应用

| 模型 | 训练方式 | Loss |
|------|---------|------|
| RT-1 | BC | MSE on continuous actions |
| RT-2 | BC | Cross-entropy on action tokens |
| OpenVLA | BC | Cross-entropy on tokenized actions |
| ACT | BC + VAE | Reconstruction + KL divergence |

## 优缺点

**优点**:
- 简单！就是监督学习
- 不需要 reward 函数（RL 的最大难点）
- 训练稳定

**缺点**:
- 分布漂移 → 误差累积
- 需要大量演示数据
- 只能模仿，无法超越专家
- 对数据质量敏感
