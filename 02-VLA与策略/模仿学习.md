# 模仿学习 (Imitation Learning, IL)

> 从人类演示中学习策略——BC 的理论框架及其进阶

## 学习范式对比

```
监督学习:        (数据, 标签) → 学到映射
模仿学习 (BC):   (观测, 专家动作) → 学到策略
强化学习 (RL):   (s, a, r, s') → 学到最优策略
```

## 数据收集方式

| 方式 | 优点 | 缺点 |
|------|------|------|
| **遥操作** | 精确，自然 | 设备昂贵，时间长 |
| **动觉示教** | 直观（手拖机械臂） | 只适合轻量机器人 |
| **手持夹爪** | 便宜，快速 | 精度有限 |
| **VR 控制** | 灵活 | 有延迟 |
| **人类视频** | 数据量大 | 需要动作推断 |

## 行为克隆的局限 → 进阶方法

### DAGGER (Dataset Aggregation)
```
Loop:
  1. 用当前策略跑一遍 → 收集观测
  2. 让专家对这些观测标注正确动作
  3. 加入训练集
  4. 重新训练

→ 让训练分布匹配策略会遇到的分布
```

### IRL (Inverse Reinforcement Learning)
- 从专家演示推断 reward 函数
- 然后用 RL 优化这个 reward
- 比 BC 更难但泛化更好

### GAIL (Generative Adversarial Imitation Learning)
- Discriminator: 区分专家 vs 策略
- Generator (Policy): 生成越来越像专家的行为
- GAN 式的对抗训练

## 在 VLA 中的现状

目前 VLA 主流还是 **BC**：
- 因为大量公开数据（OXE）都用 BC
- 简单、稳定、效果好
- RL 微调是下一步方向
