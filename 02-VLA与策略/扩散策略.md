# 扩散策略 (Diffusion Policy)

> 2023 年机器人学习最大突破之一——用扩散模型生成机器人动作

## 核心思想

```
传统 BC:    观测 → 直接回归 → 动作（单峰，确定性）

扩散策略:   观测 + 纯噪声 → 逐步去噪 → 动作（多峰，可以表达多种可能）
```

**为什么多峰很重要？**

机器人的动作本来就是多峰的：
- 可以从左边绕也可以从右边绕
- BC 会学"平均轨迹" = 撞上去

## 扩散模型三要素

### 1. 正向扩散 (Forward Process)
```
x₀ (真实动作) → 加噪声 → x₁ → 加更多噪声 → ... → x_T (纯噪声)

q(x_t | x_{t-1}) = N(x_t; √(1-β_t)·x_{t-1}, β_t·I)
q(x_t | x_0) = N(x_t; √(ᾱ_t)·x_0, (1-ᾱ_t)·I)
```

### 2. 反向去噪 (Reverse Process)
```
x_T (噪声) → 预测噪声 → x_{T-1} → ... → x₀ (干净动作)

p_θ(x_{t-1} | x_t) = N(x_{t-1}; μ_θ(x_t, t, obs), σ_t²·I)
```

### 3. 训练目标
$$L = \mathbb{E}_{x_0, \epsilon, t} \left[ \| \epsilon - \epsilon_\theta(x_t, t, \text{obs}) \|^2 \right]$$

就是让模型预测"加了什么噪声"，而非直接从噪声生成动作。

## Diffusion Policy 架构

### CNN-based
- 观测 (多帧图像) + 噪声动作 → U-Net → 预测噪声
- FiLM 条件注入
- 适合视觉输入

### Transformer-based
- 观测 token + 噪声 token → Transformer → 预测噪声
- 适合多模态观测

## 关键特性

| 特性 | BC | Diffusion Policy |
|------|-----|-----------------|
| 多模态 | ❌ 单峰 | ✅ 多峰 |
| 动作平滑 | 可能不连贯 | 天然平滑 |
| 推理速度 | 1 step | N steps (可 DDIM 加速) |
| 训练稳定性 | 高 | 中 |
| 时序建模 | 逐步 | Action Chunk (一次 N 步) |

## Action Chunking

一次预测未来 H 步动作:
```
输入: 2 帧观测历史
输出: 未来 16 步动作（一次性）
执行: 取前 K 步（如 K=8），然后重新预测

→ 减少推理频率，保持高执行频率
```

## DDIM 加速

```
DDPM: T 步去噪（如 100 步）
DDIM: 子序列去噪（如 10 步），确定性

在扩散策略中:
  100 步去噪 → 太慢（机器人等不起）
  10 步 DDIM → 可接受（~33ms per step = ~300ms total）
```
